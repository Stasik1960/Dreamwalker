# Необязательная дальнейшая работа

Повторная конвертация карты не требуется. 734 адресные замены и сверку ручных/v12 данных не повторять без новых изменений. Текущая карта — Desktop/bloodborne, а не старые скачанные города.

Холодный запуск требует отдельной оптимизации. В сохранённом thread dump server-3 основной поток находился в CompactStateTransitions, при проверке таблиц новых native-состояний; Property.equals сравнивал множества значений через ImmutableSet.containsAll. Это подтверждённый участок затрат CPU при инициализации. Возможный следующий эксперимент — проверить интернирование семантически равных, но разных экземпляров Property в layouts. В этой работе код таблиц переходов не менялся. Эти данные относятся к запуску, а не к доказательству причин игрового FPS.

Восемь старых функциональных габаритов RP-механизмов не уменьшались: двери, ворота, рычаги, сундук, лифт. Возможное последующее уточнение должно учитывать анимации, связи, рабочие области и авторские collider. Статические резервные коробки исправлены общим правилом; отключения физики нет.

Помощники Windows UI в этой сессии не смогли создать kernel assets, оба вернули ошибку отсутствующего пути. Игровые проверки выполнялись собственным QA через Minecraft API и снимки framebuffer; это не препятствует сборке и продолжению разработки. На другом ПК не повторять ремонт старого UI runtime без необходимости.

Полный source ZIP включает build-dependencies/worldedit-mod-7.2.15.jar для резервной компиляции с `-Pworldedit_api_jar=build-dependencies/worldedit-mod-7.2.15.jar`, если EngineHub Maven недоступен. В обычный мод и клиентский набор этот тестовый/сборочный WorldEdit автоматически не добавляется.
