# Решения по интерактивным исправлениям

* Клавиша «Отключить коллизии у блока в руке» по умолчанию не назначена, чтобы не занять чужую клавишу. Назначается в управлении Minecraft, категория Dreamwalker BB. Она вызывает существующую серверную команду с прежними правами; разрешения сервера не обходятся.
* Подтверждение и сброс режима показываются в строке действий. Режим связан с реальным стеком и слотом; изменение количества предметов его не снимает. Смена стека/слота или потеря действительности режима снимает его с однократным уведомлением. Выход из сервера не может показать сообщение уже отключённому клиенту.
* Старые номера пяти режимов BB сохранены. «Поворот» добавлен шестым. Используется допустимый шаг объекта: 45° либо 90°. Фрагменты без собственной схемы ориентации не получают выдуманного поворота. Неподдерживаемое «особое действие» молчит; отдельные команды alt/base остаются.
* Исходные типы окна не удаляются из реестра: это сохраняет совместимость старых предметов и резервных карт. На рабочей карте заменяются только найденные 203 окна, без повторной конвертации города. Старые UUID 67 цельных окон переходят новым окнам. Стена отделяется, новая рама едина в обоих положениях ставней; небольшое расхождение высоты старых рам нормализовано по закрытому виду.
* Прозрачность исправляется локально для стеклянной вставки: копия исходной текстуры, alpha80 вместо255, две стороны. Внешние текстуры кладки не меняются. Сплошная стена за окном прорезана по контуру рамы. Новая текстура помещена в block/ для штатного атласа, дополнительные банки статической кладки снабжены загрузочными описаниями.
* Информационный габарит v12 теперь равен объединению физических коллизий, а не видимой геометрии. Отдельные коллайдеры игроков, механика и сохранённые данные не меняются; для рендера и пространственного поиска остаётся прежний полный габарит. Поэтому физически большой объект всё ещё может иметь большой корректный габарит.
* Фея и тьма не получают новых частиц или постоянных обработчиков кадров. Внутри используется штатное непрозрачное перекрытие экрана; форма для частиц удара безопасна, выделение и разрушение реального игрока остаются только в Creative.
* Проверки функциональные, выполняются последовательно с небольшими heap. Повторные замеры производительности и ранее принятые проверки v6 не требуются этим исправлениям. До итогового визуального принятия и аудита карты сборка не считается готовой.
