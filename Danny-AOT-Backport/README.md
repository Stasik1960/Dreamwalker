# Danny’s AoT — неофициальный порт для Fabric 1.20.1

Тестовый порт предоставленного `dannys-aot-2.4.3.jar` на Minecraft
1.20.1 / Java 17. В исходном JAR внутренняя версия указана как 2.4.1;
имя полученного файла — 2.4.3. Текущая версия порта — `2.4.3-backport.2`.

## Установка

Готовый файл: [dannys-aot-1.20.1-2.4.3-backport.2.jar](../releases/Danny-AOT/dannys-aot-1.20.1-2.4.3-backport.2.jar).
При обновлении удалить предыдущий `backport.1` из `mods` и поставить этот
файл вместо него; две версии порта одновременно оставлять нельзя.

Установить одинаковый файл на клиент и сервер с Minecraft 1.20.1,
Fabric Loader 0.16.10 или новее и Fabric API для 1.20.1
(сборка проверена компилятором с API 0.92.9+1.20.1).

Этот JAR заменяет три присланных файла для 1.21.1: Danny’s AoT, AAA Particles
и GeckoLib. Старые версии этих трёх файлов для 1.21.1 нужно убрать из `mods`.
Вручную библиотеки из общего JAR извлекать не нужно: Fabric загружает их сам.
Отдельная Player Animation Library также не требуется. Старую библиотеку
с mod ID `player_animation_library` нельзя оставлять рядом с этим портом.
Другие библиотеки анимации с иными mod ID этим указанием не затрагиваются.

Исходные файлы в вашей папке `.minecraft/mods` не изменялись.

## Что находится внутри

- Danny’s AoT: восстановленный из предоставленного JAR код, адаптированный к 1.20.1.
- Официальные GeckoLib 4.8.4 и AAA Particles 2.2.3 для 1.20.1.
- Player Animation Library 1.1.6-backport.1 — дополнительная библиотека,
  которую требует сам Danny’s AoT, отдельно перенесённая на 1.20.1.
- Вложенные зависимости этих библиотек: Architectury, Forge Config API Port,
  MCLib, MochaFloats и Javassist. Fabric API остаётся внешней зависимостью.

Перенесены сетевые пакеты, данные предметов (компоненты -> NBT), атрибуты
размера/движения титанов, игровые и клиентские mixin-вставки, рендеринг,
анимации, рецепты, достижения, измерения и структуры. Исправлена ошибка
декомпиляции в интерполяции анимации клинков по байткоду оригинала.
Сохранены ID контента, ограничения доступа оригинального мода и IntegrityGuard.

## Проверка и ограничения

`gradlew.bat build` и `verifyBackport` проходят. Выполнены 812 офлайн-проверок:
двусторонняя сериализация 133 типов пакетов, данные предметов и их сохранение,
стабильные UUID модификаторов, сохранение свойств брони.
Тестовый JVM использует отдельный агент доступа для mapped-классов Minecraft;
этот агент и тестовые предметы в поставляемый мод не входят.

В `backport.2` исправлен сбой запуска из пользовательского лога:
обработчик `GeassCameraLockMixin` теперь принимает дополнительный boolean
метода Minecraft 1.20.1. Исправлены также сигнатуры наклона моделей,
выбор перегрузки отрисовки рук, обработчик износа УПМ и точка вставки
анимации элитр во вложенной Player Animation Library.

В `check` включены две дополнительные проверки: `auditMixinHandlers`
сопоставляет аргументы обработчиков и целевых методов, а
`verifyMixinApplication` действительно применяет Sponge Mixin к байткоду
Minecraft 1.20.1, взяв классы и refmap из готового JAR и вложенной библиотеки.
Это офлайн-проверка: преобразованные классы не загружаются в JVM, игра
не запускается. Optional Xaero targets проверяются статическим аудитом.

Проверены также дескрипторы вызовов, поля и константы по байткоду 1.20.1.
Проверены 111 JSON, 29 NBT-структур и 3821 запись их палитр.
Аудит исходных переопределений Minecraft сравнил 1881 метод; изменения
сигнатур покрываются адаптерами 1.20.1. В общем JAR и вложенных библиотеках
нет основных классов новее Java 17; присутствуют mixin refmap и все вложенные JAR.

**Клиент и сервер Minecraft не запускались. Это тестовая сборка, а не
подтверждённый игровой релиз.** Совместное применение mixin с другими модами,
вход клиента, полёт на УПМ, превращения и анимации титанов, загрузку измерений,
размещение структур и совместимость с остальной сборкой ещё нужно проверить
в отдельном тестовом мире. Полная совместимость с неизвестным составом сборки
не подтверждена.

Некоторые строительные блоки 1.21 отсутствуют в 1.20.1: новые разновидности
туфа заменены близкими каменными/андезитовыми блоками, медный люк — железным,
а `short_grass` — `grass`. Форма и состояния палитр сохранены; воздухом
контент не заменялся. Новые ванильные звуки/частицы, используемые кодом,
перенесены в пространство имён мода.

В предоставленном оригинале отсутствуют пять заявленных звуков:
`raga.ogg`, `summon_raga.ogg`, `tame_summon.ogg`, `aura.ogg`, `danny.ogg`.
Их нельзя восстановить декомпиляцией — этих файлов в исходном архиве нет.
Ошибочные ссылки на ванильные звуки цепи и ambient исправлены.

Сводные результаты находятся в `reports/`. Контрольная сумма опубликованной
сборки — в `reports/bundle-verification.json`. Локальные журналы в Git не включены.

## Авторство и сборка из исходников

Автор оригинального Danny’s AoT — Danny; оригинальные модели — @kronart.
Оригинальная лицензия находится в `src/main/resources/LICENSE_dannys-aot`.
Лицензии библиотек сохранены внутри их JAR. Неофициальная локальная работа
по совместимости не меняет авторство и условия использования оригинала.
Ванильные ресурсы принадлежат Mojang; их происхождение записано в
`reports/vanilla-backport-assets.json`. Готовая сборка опубликована по запросу
пользователя в [Dreamwalker](https://github.com/Stasik1960/Dreamwalker/tree/main/releases/Danny-AOT);
Исходники неофициального порта находятся в этой папке репозитория.

Рабочие исходники и ресурсы находятся в `src/`, включая офлайн-проверки
в `src/verification/`. В `player-animation-backport/` включены исходники
перенесённой библиотеки анимаций, основанные на проекте ZigyTheBird
(ветка 1.21.1, commit `10e019f89fa25d0cd6f50fb8768586a969106911`, лицензия MIT).
Локальные JAR из `libs/` нужны для компиляции и упаковки; остальные зависимости
Gradle скачает при первой сборке. Исходные игровые JAR и промежуточная
декомпиляция для обычной сборки не нужны.

Сборка: Gradle wrapper 8.12.1, Loom 1.10.5, Yarn 1.20.1+build.10,
JDK **21** для инструментов, `--release 17` для выходных классов.
Установите `JAVA_HOME` на свой JDK 21. Из этой папки сначала соберите библиотеку,
затем основной мод:

```powershell
.\player-animation-backport\gradlew.bat -p player-animation-backport build
.\gradlew.bat build
```

Linux/macOS:

```sh
./player-animation-backport/gradlew -p player-animation-backport build
./gradlew build
```

Результат: `build/libs/dannys-aot-1.20.1-2.4.3-backport.2.jar`.
`build` включает `verifyBackport`, `auditMixinHandlers` и `verifyMixinApplication`.
Они работают без запуска Minecraft. Дополнительный исторический `auditOverrides`
требует отдельно подготовленных оригинальных JAR 1.21.1 в `work/` и `tools/`;
он не входит в обычный `build`. Проверка упаковки: `python tools/verify_bundle.py`.
