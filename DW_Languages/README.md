# DW Languages — Fabric 1.20.1

Система языков для Dreamwalker. Java 17. Мод работает на сервере; клиентам DW Languages не нужен. В одиночной игре установите его в свою папку `mods`.

## Установка

1. Установите Fabric Loader 0.16.10+ и Fabric API для 1.20.1.
2. Положите `dw-languages-0.1.0.jar` в серверную папку `mods`.
3. Обновите **RP Chat до 0.1.16**. Если используете рации, обновите **DW Magic Connect до 0.4.3** на сервере и клиентах. Старые JAR этих модов удалите. RP Chat UI менять не нужно.
4. Запустите сервер. Примеры `orc` и `elf` появятся в `config/dw_languages/languages/`. Fabric Permissions API уже включён в JAR.

## Игроку

| Команда | Действие |
| --- | --- |
| `/lang` | Справка и текущий язык |
| `/lang list` | Доступные языки |
| `/lang orc` | Переключиться на оркский |
| `+orc` отдельным сообщением | То же переключение |
| `/lang off` или `+off` | Вернуться на общий язык |

Пишите обычным способом. Знающие язык увидят оригинал, остальные — иностранную речь с пометкой языка. Выбор сохраняется после выхода и перезапуска. Шёпот, крик и радиусы RP Chat работают как раньше; рации учитывают знание каждого слушателя. OOC, GM-чат, личные сообщения, действия, повествование и броски не переводятся.

## ГМу / администратору

```text
/lang add Steve orc
/lang del Steve orc
/lang reload
```

`add` выдаёт знание, `del` забирает и сбрасывает выбранный язык на общий. Используйте настоящий ник Minecraft, не RP-псевдоним. Поддерживаются онлайн-игроки и профили, известные серверу.

ГМ и администратор RP Chat знают все языки и могут выдавать/забирать знания. Перезагрузка доступна администратору / OP 2+. Поддерживаются роли RP Chat и теги `profile_gm` / `profile_admin`.

При использовании LuckPerms можно выдавать `lang.know.orc`, `lang.know.elf`, `lang.manage` (выдача знаний), `lang.admin` (управление и перезагрузка). Решение команды `add`/`del` для конкретного игрока имеет приоритет над внешним правом; роли ГМ/администратора по-прежнему знают всё. Для возврата к внешним правам удалите соответствующую запись из `grants` при выключенном сервере.

## Добавить язык

1. Скопируйте `orc.json` под новым именем в `config/dw_languages/languages/`.
2. Задайте уникальный `locale` (например, `dwarf`), отображаемое `name` и свои категории, шаблоны, правила. Пример: [orc.json](src/main/resources/languages/orc.json).
3. Выполните `/lang reload`, затем `/lang add Steve dwarf`.

Для отключения установите `"enabled": false` или уберите файл и выполните `/lang reload`. При ошибке JSON команда укажет файл, а предыдущие настройки останутся действующими. Если выбранный язык отключили, игрок должен выбрать другой или `/lang off`.

Знания и выбор игроков: `<папка мира>/dw_languages/players.json`. Перед ручной правкой остановите сервер. При резервном копировании сохраняйте эту папку и `config/dw_languages/`.

## Сборка

Из корня репозитория, JDK 17 и Gradle 8.10.2:

```sh
gradle -p RP-Chat build
gradle -p DW_Languages build
gradle -p DW_Magic_Connect build
```

Готовые JAR — в `build/libs/` соответствующих папок (без суффикса `-sources`). Автоматическая сборка трёх модов: GitHub Actions → **DW Languages build** → артефакт `dw-languages-bundle`.
