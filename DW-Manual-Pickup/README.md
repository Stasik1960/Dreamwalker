# DreamWalker Manual Pickup 1.0.0

Мод для **Minecraft 1.20.1 / Fabric / Java 17**, отключающий автоматический
подбор выпавших предметов игроками. Требуются Fabric Loader 0.16.10+ и
Fabric API 0.92.12+1.20.1 (версия из текущей сборки DreamWalker).

## Установка и управление

Положите `dw-manual-pickup-fabric-1.20.1-1.0.0.jar` в `mods` **клиента и сервера**.
В одиночной игре достаточно установить на клиент: встроенный сервер входит в игру.
Это отдельный мод, заменять другие моды DreamWalker не нужно.

- Одно нажатие кнопки приседания (по умолчанию левый Shift) подбирает один
  ближайший доступный предмет / объединённый стак с пола.
- Удержание и системный автоповтор клавиши не дают дополнительных подборов.
  Для следующего стака отпустите кнопку и нажмите снова.
- Приседание работает одновременно с подбором. Обработчик не отменяет события
  клавиатуры, не регистрирует конкурирующую кнопку и не меняет настройки управления.
- Подбор следует за назначенной в Minecraft кнопкой приседания, включая назначение
  на мышь. В меню, чате и инвентаре Shift не запрашивает подбор с пола.
- Пустое нажатие не сохраняет запрос «на потом». Радиус не увеличивается:
  используется обычная область подбора Minecraft (с учётом езды на транспорте).
- Задержка подбора выброшенных вещей, владелец и вместимость инвентаря сохраняются.
  Если помещается часть стака, остаток остаётся на полу; второй стак не подбирается.
- Опыт, стрелы, подбор мобами и воронками не изменяются. Мод управляет именно
  `ItemEntity`, подбираемыми игроком. Он не отключает отдельные «магниты» других
  модов, которые переносят предметы в инвентарь своим кодом.

На сервере без этого мода клиент ничего не блокирует: авторитетная логика
подбора выполняется сервером. На сервере с модом игрокам также нужен этот JAR,
чтобы отправлять запросы подбора. Пакет не содержит выбранный предмет или радиус:
сервер выбирает ближайший допустимый стак сам. Лимит — 4 запроса от игрока
за серверный тик; удержание кнопки запросов не отправляет.

## Сборка и проверки

Нужны JDK 17 и Gradle **8.10.2**; Gradle Wrapper в этом модуле отсутствует.
Из корня репозитория DreamWalker в PowerShell:

```powershell
& 'C:\Users\vakir\.codex\dreamwalker\Assert-Workspace.ps1'
. 'C:\Users\vakir\.codex\dreamwalker\Initialize-Environment.ps1'
gradle -p DW-Manual-Pickup build sourceZip --max-workers=1
gradle -p DW-Manual-Pickup runGametest --max-workers=1
gradle -p DW-Manual-Pickup runClientqa --max-workers=1
```

Вне этого рабочего пространства после установки JDK/Gradle выполните из папки модуля
`gradle build sourceZip --max-workers=1`. JAR находится в `build/libs`, полный ZIP
проекта с тестами — в `build/distributions`.

`runGametest` запускает настоящий Fabric GameTest-сервер. `runClientqa` открывает
отдельный тестовый клиент, создаёт новый временный мир и проверяет реальные
keyboard callbacks, Fabric-пакеты, удержание, повторное нажатие, приседание,
Shift в инвентаре и переназначение кнопки. Его мир и настройки находятся только
в `build/clientqa`; тестовые драйверы не включены в устанавливаемый JAR.

Отчёты и точные границы выполненной проверки перечислены в
`../releases/DW-Manual-Pickup/VALIDATION.md`.
