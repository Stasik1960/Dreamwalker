# Danny’s AoT — неофициальный порт 2.4.3-backport.2

[Скачать JAR](dannys-aot-1.20.1-2.4.3-backport.2.jar) · [SHA-256](dannys-aot-1.20.1-2.4.3-backport.2.jar.sha256)

Тестовый перенос предоставленного `dannys-aot-2.4.3.jar` с Fabric 1.21.1 на
**Minecraft 1.20.1 / Fabric Loader 0.16.10+ / Java 17**. Внутренняя версия
оригинального файла — 2.4.1; имя предоставленного файла — 2.4.3.

## Установка

Установите этот JAR на клиент и сервер с Fabric API для 1.20.1. Замените
предыдущий `backport.1`; две версии одного мода оставлять нельзя.

Внутри уже находятся GeckoLib 4.8.4, AAA Particles 2.2.3, перенесённая Player
Animation Library 1.1.6-backport.1, Architectury, Forge Config API Port, MCLib,
MochaFloats и Javassist. Уберите прежние Danny’s AoT, GeckoLib и AAA Particles
для 1.21.1, а также отдельную Player Animation Library с тем же mod ID.
Извлекать вложенные JAR вручную не нужно. Fabric API остаётся внешним.

## Исправления и проверка

В backport.2 исправлены несовместимые mixin-обработчики камеры, наклона моделей,
отрисовки рук, износа УПМ и анимации элитр. Сохранены ID контента,
авторские ограничения доступа и IntegrityGuard.

- Gradle build/check: успешно, выходные классы совместимы с Java 17.
- 812 офлайн-проверок пакетов, NBT, атрибутов и брони: успешно.
- Аудит 169 обработчиков основного мода: без ошибок.
- Настоящий MixinTransformer применил 133 вставки AoT и библиотеки анимаций
  к 57 классам Minecraft 1.20.1 без ошибок, используя готовый JAR и его refmap.

Minecraft при проверке не запускался. Эти проверки не подтверждают игровой
запуск, работу всех способностей или совместимость с другими модами сборки.
Сначала используйте отдельный тестовый мир.

Некоторые строительные блоки 1.21 в структурах заменены близкими аналогами
1.20.1. Пять звуков (`raga`, `summon_raga`, `tame_summon`, `aura`, `danny`)
отсутствовали уже в предоставленном оригинале и не восстановлены.
