# Immersive Engineering через Kilt

Описание неофициального адаптера **IE Fabric Compatibility 0.2.0** для
Minecraft 1.20.1 / Java 17. [Каталог проектов](../README.md).

**В текущем `main` этой папки есть только README.** Упоминавшиеся ранее JAR,
установщик, исходники адаптера, `TEST_REPORT.md` и контрольные суммы здесь
не опубликованы. Этот раздел не является готовым комплектом для скачивания.

## Назначение

Адаптер предназначен для официального Forge-мода Immersive Engineering через
Kilt, а не для нативного переноса всего IE на Fabric API. В прежнем описании
зафиксировано исправление выпадения семян технической конопли через Fabric Loot API:
10% при разрушении обычной/высокой травы, без добавления семян при использовании ножниц.
