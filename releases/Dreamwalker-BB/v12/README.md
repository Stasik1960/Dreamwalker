# Dreamwalker BB Fabric V12

Новый инструмент BB использует сохранённую иконку и пять режимов: вверх, вниз,
особое действие, привязка команд, удаление связей и команд выбранного объекта.
ПКМ переключает режим, ЛКМ применяет его. Подробности — в TOOL-INSTRUCTIONS.txt.
Контур каждой авторской секции 90006 теперь один AABB; физическая коллизия угловой
лестницы остаётся пустой.

Minecraft 1.20.1, Java 17, Fabric Loader 0.16.10+, Fabric API 0.92.9+1.20.1,
GeckoLib 4.4.9. Установите JAR из этой папки на сервер и клиенты.
Распакуйте Dreamwalker-BB-v12-Gallery.zip в .minecraft/saves; level.dat должен
находиться непосредственно в saves/Dreamwalker-BB-v12-Gallery.

Свежая галерея содержит 121 экспонат: 103 предмета и 18 настоящих NPC. Все текущие
неразмещаемые предметы показаны в рамках, включая ровно один bb_tool. Платформы
соответствуют целочисленному следу коллизии игрока+2 блока с каждой стороны;
между соседними краями ровно 2 блока. При отсутствии коллизии использован визуальный
след, у рамки учтена поддержка. Creative и команды включены. Навигация:
/function dw_gallery:visit/<ID>; получить инструмент: /function dw_gallery:tool.
Полный индекс — GALLERY-INDEX.csv. Авторский QA мод сохранённому миру не нужен.

Сборка, серверные GameTests, сохранённые NBT всех 121 объектов, UUID/позиции/настройки,
размеры платформ, промежутки и production-only повторное открытие/сохранение прошли.
ZIP проверен по CRC и хешам файлов. Старые релизы сохранены.

Все 22 новых функциональных случая выполнены настоящими клиентами на этом JAR: режимы
инструмента, собаки, ALL-связки, пара фонарей, BASE/ALT и радиус, GUI команд,
личные/общие лимиты, удаление, контур90006 и сохранение/повторный вход.
Точные действия и пределы доказательств: [NATIVE-ACCEPTANCE.json](NATIVE-ACCEPTANCE.json).
Проверена целостность 51 нативных PNG; 20 выбранных кадров включены в
[QA-EVIDENCE.zip](QA-EVIDENCE.zip).
Ссылки evidence/ и native/ в итоговом отчёте разрешаются внутри этого архива;
хеши сохранённых состояний и закрытых запусков: [NATIVE-EVIDENCE.json](NATIVE-EVIDENCE.json).
Это функциональный проход; FPS/MSPT, AI/бой и непрерывная видеозапись
не заявляются. Исходный закрытый ZIP галереи
сохраняет предварительный встроенный статус; итоговая приёмка записана во внешних файлах.

Итоговая проверка комплекта: [FINAL-AUDIT.json](FINAL-AUDIT.json), 12/12 PASS.
