Dreamwalker BB V12.3 — обводка и 3D-иконки

Minecraft 1.20.1, Fabric Loader 0.16.10, Java 17.
Проверенные зависимости: Fabric API 0.92.9+1.20.1, GeckoLib 4.4.9.

Замените прежний combined JAR Dreamwalker BB новым JAR версии
0.1.0-v12.3-outline-icons в папке mods клиента и сервера.
Одновременно оставлять две версии Dreamwalker BB не следует.
Исходный ресурспак для работы мода не требуется.

У новых непроходимых объектов выделение теперь использует ту же форму,
что и физическая коллизия. У полностью проходимых объектов остаётся одна
простая прямоугольная область выделения: её можно выбрать, скопировать
и удалить, а игрок по-прежнему проходит сквозь объект.

Предметы установки RP-объектов из V12 показывают уменьшенные 3D-модели
самих объектов вместо иконки стойки для брони. Установленные RP-объекты,
их геометрия, текстуры, анимации и поведение сохранены.

Карта и прежняя галерея этой ревизией не изменены.
Тестовый QA-мод устанавливать пользователю не нужно: он не входит
в production JAR и использовался только для проверок в отдельном мире.

В full-source.zip находятся полные исходники, ресурсы, Gradle Wrapper
и воспроизводимые инструменты проверок. Для сборки предусмотрена задача
Gradle build; проверки: compileGameTests, runGameTests, transactionCheck.
verification.zip содержит отчёты, исходные журналы и игровые скриншоты.

Экспорт авторских коллизий не предоставлен и не применялся.
Контракт точного registry ID/состояния и действующие исключения сохранены.
