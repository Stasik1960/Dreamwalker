# Dreamwalker BB Fabric V11.3

V11.3 удаляет физическую коллизию **только у угловой лестницы90006** во всех
контекстах запроса по уточнению пользователя. Форма и контур обычной лестницы
сохранены. Сохраняются
очистка редактора/диагностики и исправление лишней анимации при загрузке уже открытого
RP объекта. Спорная задача ручного подъёма по угловой лестнице отменена.

Для установки нужны Minecraft **1.20.1**, Java **17**, Fabric Loader **0.16.10+**,
Fabric API **0.92.9+1.20.1**, GeckoLib **4.4.9**. Установите
[combined JAR](dreamwalker-bb-fabric-1.20.1-0.1.0-v11.3.jar) на сервер и клиенты.
Предыдущий Dreamwalker BB и отдельный bloodborne-rp одновременно с ним не оставляйте.
Перед обновлением существующего мира сохраните копию. Хеши находятся в соседних
`.sha256` файлах.

[Свежая галерея](Dreamwalker-BB-v11.3-Gallery.zip) создана из текущего каталога
V11.3: **120 экспонатов**, **102 предмета**, **18 настоящих NPC**.
Распакуйте ZIP в `.minecraft/saves`: файл
`saves/Dreamwalker-BB-v11.3-Gallery/level.dat` должен находиться непосредственно
в папке мира. Creative, команды включены; неразмещаемые предметы находятся в рамках.
NPC закреплены для показа. QA мод для сохранённой карты не требуется.

Платформы равны целочисленному следу коллизии игрока плюс2 блока с каждой стороны;
между соседними краями ровно2 блока. У экспонатов без коллизии использованы визуальные
границы; рамки учитывают поддержку. Переход к объекту:
`/function dw_gallery:visit/90020`. Точные имена, команды и координаты находятся
в [GALLERY-INDEX.csv](GALLERY-INDEX.csv), размеры и UUID — в
[gallery-manifest.json](gallery-manifest.json).

Сборка Java17,42/42 GameTests и21/21 проверка транзакций прошли. Сохранённые NBT,
платформы, промежутки и все120 объектов проверены до и после открытия и штатного
сохранения только с production JAR V11.3. ZIP проверен по CRC и побайтовым хешам.
Релизы V11.1 и V11.2 сохранены побайтово.

На V11.3 просмотрены четыре нативных ракурса собаки91007: задний и западный
подтверждают её присутствие; восточный и северный частично закрыты клеткой.
Завершена активная проверка двумя настоящими клиентами:240 нативных кадров камеры
A, обычные взаимодействия B и серверный профиль 659.50с /
13191 тиков / 20.00 TPS. Эта проверка использует отдельную сохранённую
сцену с119 основными экспонатами и дополнительными QA-секциями.

Компактные доказательства: [QA-EVIDENCE.zip](QA-EVIDENCE.zip),
статус и границы проверки: [QA.json](QA.json), [_ACCEPTANCE.md](_ACCEPTANCE.md).
Это проверка дискретных кадров, состояний и серверного TPS; FPS/MSPT, AI/бой и
полная приёмка всех игровых ситуаций не заявляются. Более ранние480 кадров V11.2
сохраняют привязку к его JAR. Внутри неизменного ZIP галереи остался исходный
статус подготовки; последующие проверки записаны в этих внешних файлах.
