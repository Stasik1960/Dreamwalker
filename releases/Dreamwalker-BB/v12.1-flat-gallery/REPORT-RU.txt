Dreamwalker BB V12.1 — новая плоская галерея

Готовый мир: Dreamwalker-BB-V12.1-Flat-Gallery.zip. Распаковать одну папку из архива в saves.
Minecraft 1.20.1, Java 17, Fabric Loader 0.16.10, Fabric API 0.92.9+1.20.1, GeckoLib 4.4.9.
Combined JAR приложен: тот же проверенный v12.1-resource-transfer; для галереи он не изменялся. Исходный ресурспак и QA-дополнение не требуются.

Полные исходники мода — архив full-source.zip; новые инструменты галереи и анализа — архив Flat-Gallery-generator-source.zip.

1942 отдельные платформы: 1885 настоящих объектов/предлагаемых вариантов и 57 подписанных диагностических платформ.
Голубые — исходная V12: 80. Зелёные — новые: 1682. Жёлтые — отсутствующие на карте: 120.
Красные — ошибки: 60 (3 реальных варианта с исходным отсутствующим particle-ресурсом и 57 диагностик).
Группы взаимоисключающие с приоритетом ошибка > отсутствие на карте > V12 > новые; происхождение сохранено в manifest.
Сетка 16 колонок, 123 ряда, область 318×1207 блоков. Между краями соседних платформ ровно два пустых блока.
У каждого настоящего объекта одна платформа; цельные составные модели сохранены вместе. BASE/закрытое состояние показано сначала.
Полные русские названия, ID, варианты, координаты и команды перехода — GALLERY-INDEX.csv. Таблички читаются с обеих сторон.
/function dw_gallery:help — помощь; dw_gallery:v12, dw_gallery:new, dw_gallery:absent, dw_gallery:error — переходы; dw_gallery:tool — BB-инструмент.
