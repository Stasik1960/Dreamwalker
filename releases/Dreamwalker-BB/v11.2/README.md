# Dreamwalker BB Fabric V11.2

Проверочная ревизия. Итоговая игровая приёмка ещё не завершена;
текущий статус записан в [_ACCEPTANCE.md](_ACCEPTANCE.md).

V11.2 сохраняет очисткуV11.1, исправляет лишний запуск анимации у уже открытого
RP объекта при его загрузке клиентом и уточняет коллизию свободной диагональной
лестницы90006. Ручная проверка подъёма при удержании клавиши ещё ожидает подтверждения.

Для установки нужны Minecraft **1.20.1**, Java **17**, Fabric Loader **0.16.10+**,
Fabric API **0.92.9+1.20.1** и GeckoLib **4.4.9**. mclib20 уже вложен в GeckoLib.
В `mods` установите [combined JAR V11.2](dreamwalker-bb-fabric-1.20.1-0.1.0-v11.2.jar)
на сервер и клиенты. Предыдущий Dreamwalker BB и отдельный `bloodborne-rp`
одновременно с ним не оставляйте. Перед обновлением существующего мира сохраните копию.
SHA256 JAR и карты находятся в соседних `.sha256` файлах.

[ZIP галереи](Dreamwalker-BB-v11-Gallery.zip) распакуйте в `.minecraft/saves`:
`saves/Dreamwalker-BB-v11-Gallery/level.dat` должен быть непосредственно внутри папки мира.
Это полная исходная опубликованная галереяV11.1, повторно открытая и сохранённая
с production JAR V11.2: **120 экспонатов**, **102 текущих предмета** и **18 настоящих NPC**.
Сохранены UUID, положения, настройки и содержимое объектов. ГалереяV11.1 не изменена.

Платформа охватывает целочисленный след коллизии игрока и ещё2 блока с каждой
стороны. Между соседними платформами ровно2 блока. Для экспонатов без физики
использованы визуальные границы, для рамок учтён поддерживающий блок.
NPC закреплены для показа. Неразмещаемые предметы показаны в закреплённых рамках.
Режим Creative, команды включены; галерея продолжается на восток.

Переход к объекту: `/function dw_gallery:visit/90020`. Для NPC и его яйца
используются разные имена, например `npc_910xx` и `item_910xx`.
Точные команды и координаты: [GALLERY-INDEX.csv](GALLERY-INDEX.csv).
Размеры, типы и UUID: [gallery-manifest.json](gallery-manifest.json).

Сборка Java17, **42/42 GameTests** и **21/21 проверка транзакций** прошли.
Сохранённые блоки, сущности, платформы и промежутки проверены до и после открытия
карты только с production JAR. ZIP проверен по CRC и побайтовым хешам файлов.
Редактор, автор галереи, тестовый мод и захват кадров для игры не требуются
и не входят в production JAR.

Результаты: [QA.json](QA.json), [GAME-TESTS.xml](GAME-TESTS.xml),
[TRANSACTION-CHECKS.txt](TRANSACTION-CHECKS.txt).
Просмотр **480 нативных кадров BASE/ALT** завершён в пределах статической проверки
видимых моделей, текстур и размещения. Ещё18 крупных планов уточнили отдельные объекты;
деталь собаки91007 за решёткой остаётся не подтверждена. Игровой цикл двери и повторный
вход проверены настоящими клиентами по кадрам и состояниям.
Метаданные, хеши кадров, отчёты и небольшие обзорные листы: [QA-EVIDENCE.zip](QA-EVIDENCE.zip).

Ручной подъём по90006 при удержании клавиши и длительная активная нагрузка ещё
ожидают проверки. ZIP карты сохранён побайтово: встроенные `GALLERY.txt` и manifest
содержат подготовительный статус до просмотра480 кадров. Актуальная запись приёмки
находится в [QA.json](QA.json) и [_ACCEPTANCE.md](_ACCEPTANCE.md).
