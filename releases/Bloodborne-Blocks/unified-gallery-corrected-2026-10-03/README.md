# Исправленный мод и город с галереей

Исторический выпуск: для сборки с WorldEdit используйте [оптимизированную версию `.3`](../unified-gallery-optimized-2026-10-04/README.md). В `.2` подтверждено исчерпание памяти при загрузке этой карты с WorldEdit.

Выпуск `2.1.0-unified-gallery.2`, Minecraft 1.20.1, Fabric, Java 17. Этот комплект заменяет ошибочный выпуск `.1`.

## Исправление объектов

Сухое дерево — `o_c001`, сухой куст — `o_dry_bush`. Это два самостоятельных блока-конструкции с разными числовыми ID. В каталоге доступен один образец дерева и один образец куста; направление установки определяется взглядом игрока. У куста нет свойства варианта. У дерева прежние формы сохранены только как внутренние состояния для совместимости с уже построенным городом; новая установка и выбор предмета используют каноническое дерево.

Дополнительно исправлено слияние цельных объектов: для общего ID должны совпадать форма, внешний вид, физика и положение относительно точки установки после поворота. Верхняя и нижняя плиты, верхний и нижний люк, а также одинаковая геометрия с различными текстурами остаются разными объектами. Истинные повороты одного объекта объединяются. Ручные решения из «Правки финал», функциональная стена и защищённые конструкции сохранены.

Аудит и исходники закреплены на коммите `b5acd39e494e4efa505b65d63631230993a897a9` ветки `codex/bloodborne-model-duplication-audit`. Реестр города сокращён с 3805 до 3554 ID; полный мод содержит 3605 ID: 3554 городских, 50 логических и служебный `architecture_part`. Формы старого города сохранены внутренними состояниями. Некоторые похожие фрагменты объединены по материалу, размеру и физике; восемь таких решений вынесены на сравнение в материалы просмотра.

## Город и редактирование галереи

В исправленном городе заменены все 27 393 913 записей устаревших блоков, подлежащих миграции. Взята исправленная карта до ошибочного выпуска `.1`, без старой галереи; повреждённая rc.4 не используется. Координаты, существующие наложения коллизий, чужие блоки и их данные сохранены. Все 416 блоков Yuushya остаются на своих местах. Разовое наложение выполнено при преобразовании сохранения; обычная установка в игре проверяет свободное место.

Над городом, начиная с Y=228, построены 3605 демонстрационных площадок: каждый зарегистрированный ID представлен ровно один раз. Между площадками — три воздушных блока. `editable-gallery-manifest.json` внутри мира содержит координаты, уникальные числовые ID длиной до пяти цифр, исходное содержимое и границы площадок. Для перехода используйте поле `tp`; `/bloodborne debug id 12345` показывает соответствующий registry ID.

1. Редактируйте образец над плитой своей площадки, внутри её границ X/Z и не выше Y=319.
2. Удалённый образец означает удаление ID. Один заменяющий блок означает замену. Постройка из нескольких блоков означает новую цельную конструкцию.
3. Плиты и таблички не входят в замену. Вспомогательные части не получают самостоятельного решения.
4. Служебная площадка `architecture_part` подписана отдельно; её изменение требует пересмотра зависимых конструкций.
5. Верните весь сохранённый мир вместе с исходным манифестом. Манифест вручную не редактируйте.

Устанавливайте мод и карту этого комплекта вместе, заменив прежний JAR. Сохраните остальные моды исходной сборки: в карте есть их блоки и сущности, в том числе Yuushya и Handcrafted. Для проверенного запуска использованы Fabric API, Yuushya и Architectury. Прежние миры требуют офлайн-конвертации. Архив карты не содержит персональных данных игроков.

## Материалы просмотра и проверки

`images/shortimageindex.json` описывает карточки, отрисованные из настоящих моделей программным рендером. Это сравнения геометрии и текстур. `screenshots/index.json` описывает настоящие снимки Minecraft, сделанные клавишей F2. Сравнительные образцы добавлены только в проверочную копию мира; карта для редактирования содержит один образец на площадке.

Машинные результаты проверки находятся в `*-proof.json`. Проверяются все 53 272 перенесённых состояния и 48 794 сочетания модели с поворотом, отсутствие удалённых ID во всём городе, сохранение чужих блоков и неизменность города ниже галереи. Проверки клиента и двух запусков dedicated-сервера выполняются на Windows; производственная конфигурация сервера не меняется. Клиент проверяется с Java-кучей 7 ГБ, сервер — 5 ГБ; малый лимит памяти не проверяется.

## Воспроизведение

Из каталога `Bloodborne-Blocks`, с Python, содержащим NumPy и Pillow:

```powershell
python tools/prepare_unified_inputs.py
python tools/build_unified_registry.py --apply
python tools/add_unified_tree_variants.py --asset-e --apply
python tools/build_creative_equivalence.py
python tools/verify_unified_registry.py
.\gradlew.bat check build
```

Для исторического куста нужен отслеживаемый `releases/Bloodborne-Blocks/bloodborne-blocks-2.0.1-mc1.20.1.jar`; сначала загрузите LFS-файлы (`git lfs pull`). Версии зависимостей сохранены. Генератор восстанавливает этот выпуск из закреплённых исходников: не запускайте его поверх пользовательских изменений моделей.

```powershell
python tools/convert_unified_city.py --help
python tools/build_editable_city_gallery.py --help
python tools/inspect_editable_city_gallery.py --world <edited-world> --manifest <original-manifest> --output <changes.json>
```

Манифест отделяет постоянные поля ресурса от игровых переключателей, поэтому обычное пересохранение мира не считается правкой образца.
