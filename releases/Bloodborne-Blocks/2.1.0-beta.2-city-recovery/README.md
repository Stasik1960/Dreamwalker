# Bloodborne City — восстановленная карта для beta.2

**Неизвестных блоков: 0 в обеих картах. Офлайн-проверки пройдены; проверка в игре остаётся за пользователем.**

Для первого запуска используйте [Bloodborne-City-Beta2-Conservative-Recovered.zip](Bloodborne-City-Beta2-Conservative-Recovered.zip).
Распакуйте папку мира рядом с прежним миром и выберите её при запуске сервера
(или поместите в `saves` для одиночной игры). Архивы — полные карты, не дополнения.

На сервере и клиентах нужен приложенный
[bloodborne-blocks-2.1.0-beta.2-mc1.20.1.jar](bloodborne-blocks-2.1.0-beta.2-mc1.20.1.jar) (Fabric 1.20.1 / Java 17).
JAR совпадает с предыдущей beta.2; если он уже установлен, менять его не нужно.
Исправления выполнены офлайн — команд обхода чанков вводить не требуется.

- **Conservative:** основная карта, без принудительных замен конфликтующих блоков.
- [Aggressive / ALT](Bloodborne-City-Beta2-Aggressive-Recovered.zip): отдельный ALT-вариант с прежними 737 принудительными решениями
  конвертера. Не смешивайте файлы регионов из двух вариантов.
- [Bloodborne-City-Recovery-Reports.zip](Bloodborne-City-Recovery-Reports.zip): полные журналы и проверки.
- [proof.json](proof.json): контрольные суммы входов, JAR, архивов и результаты.

Использован только актуальный MODDED-бэкап. По найденной старой MODDED-карте
восстановлены 30 служебных частей дверей и три пустые клетки, строго по
координатам и состояниям владельцев. Затем существующий конвертер обработал
их вместе с дверями. В Conservative сохранились 24 восстановленные части,
шесть устаревших частей убраны вместе со своими старыми владельцами; в ALT —
20 частей и десять убранных устаревших частей. Это восстановление подтверждённой
старой структуры, а не воссоздание потерянных составных моделей.

Проверены все 10 009 чанков, 1 003 216 896 клеток и сохранность 170 файлов
вне регионов блоков. Неизвестных ID и потерянных владельцев служебных частей нет.
Повторная конвертация не вносит изменений. Существующие отказы от опасных
преобразований сохранены: такие объекты остаются в совместимом старом виде.

Minecraft не запускался по просьбе пользователя. Игровая работа, внешний вид
и производительность требуют вашей проверки; эти результаты не подменяются
статическими тестами. Прежние архивы с `UNRESOLVED` заменены этим комплектом.
