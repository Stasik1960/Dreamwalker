# DreamWalker Manual Pickup 1.0.0

**Minecraft 1.20.1 · Fabric Loader 0.16.10+ · Fabric API 0.92.12+1.20.1 · Java 17**

Автоподбор выпавших вещей отключён. Одно нажатие приседания (левый Shift по
умолчанию) подбирает один ближайший доступный стак в обычной области подбора
Minecraft. Удержание не повторяет подбор. Приседание продолжает работать.

Установите один и тот же JAR в `mods` клиента и сервера. В одиночной игре —
только в `mods` клиента. Смена клавиши приседания меняет и кнопку подбора;
отдельной конфликтующей привязки нет.
