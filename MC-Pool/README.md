# Pool Billiards Fabric 1.20.1

Мод добавляет бильярдный стол для игры в пул-восьмёрку через общий UI стола.

## v0.1.13
- Кнопка «Шары: цветные / белые» доступна участникам до первого удара новой партии. В белом режиме все прицельные шары цвета слоновой кости, биток — золотистый. Номера и правила пула сохраняются.
- Выбор синхронизируется между игроками и сохраняется со столом. После первого удара сервер блокирует смену; новая партия снимает блокировку и сохраняет предпочтение. Для старых сохранённых партий сначала нажмите «Новая партия».
- Коллайдеры бортов и губ луз экспортируются из той же геометрии, что и модель; захват учитывает положение отверстия и радиус шара. По краям средних луз добавлены недостающие участки бортика и сукна.
- Разрушение любой части удаляет весь стол. В выживании выпадает один стол, в творческом режиме — без предмета; соседние столы не затрагиваются.
- Проверки: `gradle check` — физика, попадания во все шесть луз, сохранение/сеть и блокировка оформления, размеры UI, принадлежность частей во всех четырёх направлениях. Клиент и сервер Minecraft для проверки не запускались; поведение разрушения проверено по коду и геометрии, без игрового мира.
- Установите `build/libs/pool-billiards-0.1.13.jar` на сервер и клиент. Генератор `tools/generate_table_model.py` также обновляет `assets/poolbilliards/table_geometry.json`; этот файл нужно поставлять вместе с моделями.

## v0.1.12
- Адаптивная компоновка для крупного GUI: на небольшом экране игроки и управление находятся под столом, на широком — доступна боковая панель.
- Пропорции игрового поля сохраняются; борта, лузы, шары, номера и кий подстраиваются под доступное место.
- Длинные имена и статус обрезаются по ширине; кнопка новой партии и индикатор силы остаются в окне.
- Длина замаха зависит от ширины поля. Изменение размера окна отменяет незавершённый замах, чтобы избежать случайного удара.
- `gradle check` проверяет геометрию на 10 размерах GUI, включая 320×240, и выполняет проверки физики.
- Готовый мод: `build/libs/pool-billiards-0.1.12.jar`.

## v0.1.11
- Кий в игровом интерфейсе рисуется поверх боковой панели и остальных элементов.
- Все шесть луз расширены, их контуры закруглены; угловые входы открыты по диагонали. Геометрия остаётся статической, размер стола — 5×3 блока.
- Скорректированы передача импульса между шарами и отскок от резины: касательная скорость сохраняется лучше, слабые контакты быстрее затухают. Максимальная скорость удара сохранена.
- Добавлены пространственные звуки удара кием, столкновений, бортов и падения в лузу на основе ванильных звуков. Громкость зависит от силы; за тик звучит не больше одного события каждого типа.
- Высота декоративных киев в мире согласована с поднятым столом.
- Для среды разработки обновлён Fabric Loader до 0.16.10, совместимого с используемой Fabric API 0.92.8.
- Проверка физики: `gradle physicsCheck`; сценарии используют игровые классы без запуска клиента.
- Готовый мод: `build/libs/pool-billiards-0.1.11.jar`.

## v0.1.10
- Исправлена расстановка: в пирамиде снова ровно по одному шару с номерами 1–15, восьмёрка остаётся в центре. Старые сохранения с двумя девятками исправляются при загрузке.
- Стол стал выше и стройнее, с более заметными ножками, тёмным деревом и обрамлением боковых панелей.
- При удержании ЛКМ в игровом UI за битком появляется спрайт кия, который отводится назад при наборе силы удара.
- Готовый мод: `build/libs/pool-billiards-0.1.10.jar`.

## v0.1.9
- Клиент плавно сглаживает новые координаты шаров между сетевыми обновлениями — на столе и в игровом интерфейсе.
- Максимальная скорость удара снижена примерно на 10%; под конец качение затухает быстрее, чтобы не ждать следующего удара слишком долго.

- Игровой интерфейс оформлен тёмным деревом, сукном и латунными акцентами.
- Готовый мод: `build/libs/pool-billiards-0.1.9.jar`.

- Возвращено плавное затухание скорости после столкновений: шары внутри пирамиды больше не останавливаются почти сразу.

## v0.1.7
- Стол занимает 5×3 блока и собран из 15 статических частей. Перед заменой старой версии лучше убрать уже установленные столы и поставить их заново.
- Проект модели для Blockbench: `billiards-table.bbmodel`. Генератор `python tools/generate_table_model.py` создаёт его и 15 игровых моделей из геометрии в Python. Правки нужно вносить в генератор: он перезаписывает ручные изменения `.bbmodel`.
- Удары заметно быстрее и зависят от силы; физика использует больше шагов столкновений на высокой скорости.
- Сборка: `gradle build`; готовый мод находится в `build/libs/pool-billiards-0.1.7.jar`.
