# MC-Pool

Бильярдный стол для игры в пул-восьмёрку через общий интерфейс.
**Версия 0.1.14 · Minecraft 1.20.1 · Fabric · Java 17.**

[Скачать JAR](../releases/MC-Pool/pool-billiards-0.1.14.jar) · [История изменений](CHANGELOG.md) · [Все проекты](../README.md)

## Установка и игра

Установите одинаковый JAR на сервер и клиенты с Fabric Loader 0.16.10+ и Fabric API для 1.20.1.
Замените предыдущую версию, сохранив резервную копию мира.

- Стол занимает **5×3 блока**; оставьте свободное место для установки.
- Откройте интерфейс стола, начните партию и задавайте направление и силу удара мышью.
- До первого удара можно выбрать цветные или одноцветные шары. Это оформление: правила остаются правилами пула, не русской пирамиды.
- Состояние партии и выбранное оформление синхронизируются между игроками и сохраняются со столом.
- Разрушение любой части удаляет весь стол; в выживании выпадает один предмет стола.

Есть звуки ударов и луз, сглаживание движения шаров и адаптация интерфейса к размеру экрана.
В 0.1.14 уточнены отверстия луз, облицовка, геометрия столкновений, кий и линия прицеливания.

## Разработка

JDK 17 и Gradle 8.10.2; из корня репозитория:

```sh
gradle -p MC-Pool check build
```

Результат: `build/libs/pool-billiards-0.1.14.jar` внутри проекта.
`check` включает физику, структуру стола, оформление шаров и компоновку интерфейса.
Зафиксированные проверки 0.1.14 выполнены без запуска Minecraft; игровой FPS не измерялся.

Модель: [billiards-table.bbmodel](billiards-table.bbmodel).
Источник генерации — [tools/generate_table_model.py](tools/generate_table_model.py);
он обновляет модели и `table_geometry.json`, поэтому ручные изменения сгенерированных файлов будут перезаписаны.
[Общие инструкции](../CONTRIBUTING.md). Авторство и лицензия — в [метаданных](src/main/resources/fabric.mod.json).
