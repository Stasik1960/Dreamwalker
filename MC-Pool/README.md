# Pool Billiards Fabric 1.20.1

Мод добавляет бильярдный стол для игры в пул-восьмёрку через общий UI стола.

## v0.1.10
- Исправлена расстановка: в пирамиде снова ровно по одному шару с номерами 1–15, восьмёрка остаётся в центре. Старые сохранения с двумя девятками исправляются при загрузке.
- Стол стал выше и стройнее, с более заметными ножками, тёмным деревом и обрамлением боковых панелей.
- При удержании ЛКМ в игровом UI за битком появляется спрайт кия, который отводится назад при наборе силы удара.
- Готовый мод: `build/libs/pool-billiards-0.1.10.jar`.

## v0.1.9
- Клиент плавно сглаживает новые координаты шаров между сетевыми обновлениями — на столе и в игровом интерфейсе.
- Максимальная скорость удара снижена примерно на 10%; под конец качение затухает быстрее, чтобы не ждать следующего удара слишком долго.
- Убраны совпадающие поверхности модели, которые могли мерцать.
- Игровой интерфейс оформлен тёмным деревом, сукном и латунными акцентами.
- Готовый мод: `build/libs/pool-billiards-0.1.9.jar`.

## v0.1.8
- Добавлены деревянные губы и внешний обод вокруг всех шести луз.
- Возвращено плавное затухание скорости после столкновений: шары внутри пирамиды больше не останавливаются почти сразу.
- Максимальная сила удара умеренно снижена для более управляемого разбоя.
- Готовый мод: `build/libs/pool-billiards-0.1.8.jar`.

## v0.1.7
- Стол занимает 5×3 блока и собран из 15 статических частей. Перед заменой старой версии лучше убрать уже установленные столы и поставить их заново.
- Исходник новой модели для Blockbench: `billiards-table.bbmodel`. После изменения проекта экспортированные модели можно пересоздать командой `python tools/generate_table_model.py`.
- Удары заметно быстрее и зависят от силы; физика использует больше шагов столкновений на высокой скорости.
- Сборка: `gradle build`; готовый мод находится в `build/libs/pool-billiards-0.1.7.jar`.

## v7
- Исправлено отображение шаров на столах, повёрнутых EAST/WEST.
- Стол поднят обратно, но борта и лунки оставлены ниже и аккуратнее относительно сукна.
- Коллизия основного блока и технических частей поднята до новой высоты стола.
