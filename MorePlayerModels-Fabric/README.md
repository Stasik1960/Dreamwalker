# More Player Models для DreamWalker

Версия `1.0.6-dw.4` исправляет отключение от сервера Fabric 1.20.1 при синхронизации большого профиля. Смена режима в меню F12 отправляет `moreplayermodels:player_data_update`, а первый тик после входа отправляет тот же сохранённый профиль через `moreplayermodels:ping`. В dw.3 оба пакета содержали полный NBT. Сервер Minecraft отклоняет клиентский пакет больше 32 767 байт до вызова обработчика мода.

В dw.4 пакеты до 32 767 байт используют прежний протокол. Профили до 240 КиБ передаются частями при поддержке с обеих сторон. Сервер собирает их перед применением обычных проверок и сохранением. Если сервер не поддерживает части или профиль превышает лимит, клиент сохраняет профиль локально и выводит предупреждение.

Для передачи больших профилей установите [dw.4](../releases/MorePlayerModels/MorePlayerModels-Fabric-1.20.1-1.0.6-dw.4.jar) в папку `mods` на сервере и у игроков, заменив прежний JAR More Player Models. После перезапуска достаточно снова зайти в игру с сохранённым профилем.

В `src/` лежат восстановленные сетевые классы dw.3 с изменениями этого исправления. Скрипт сборки проверяет SHA-256 входного JAR, компилирует сетевой код и добавляет его в новую сборку. Оригинальные классы переключения MPM/CPM, ресурсы и лицензия входят в итоговый JAR из входной сборки. Подробности в [инструкции по сборке](BUILDING.md) и [инструкции по проверке](qa/README.md).

More Player Models создан Noppes. Работа atleast4IQ над [MorePlayerModels](https://github.com/atleast4IQ/MorePlayerModels) указана в исходной сборке. DreamWalker адаптировал мод для Fabric 1.20.1, а версия dw.4 меняет транспорт профилей. Условия [CC BY-NC 3.0](LICENSE.txt) сохранены.
