# RP Chat UI Fabric 1.20.1

Клиентский мод, который заменяет стандартный HUD чата на перемещаемое окно с вкладками.

## Что есть в v2

- Стандартное ванильное поле ввода чата отключено.
- Новое поле ввода находится внутри окна чата.
- `Enter` отправляет сообщение, `/команда` отправляется как команда.
- В обычной игре фон окна скрыт, виден только текст.
- Сообщения в режиме игры исчезают через 30 секунд после получения.
- При открытии чата все старые сообщения снова видны.
- При закрытии чата старые сообщения снова скрываются, если им больше 30 секунд.
- При открытом чате и наведении курсора на область чата окно проявляется.
- Окно можно двигать за верхнюю панель или кнопку `[↔]`.
- Размер окна можно менять, потянув за края.
- Положение, размер, вкладки и масштаб сохраняются после перезапуска клиента.
- Кнопки `+` / `−` справа меняют масштаб текста.
- Базовая вкладка `local` всегда есть и не закрывается.
- OOC, GM, ЛС и новые типы сообщений автоматически получают вкладки.
- Автосоздание вкладок можно выключить кнопкой `A+ / A−`.
- Кнопка `+` сверху создаёт кастомную вкладку.
- Кнопка `⚙` открывает настройки выбранной вкладки.
- Настройки вкладки теперь открываются как второе полупрозрачное окно рядом с чатом, а не как отдельный fullscreen-screen.
- Окно настроек вкладки можно двигать и менять по размеру.
- В настройках вкладки можно выбрать типы сообщений: Общий, OOC, GM, ЛС и новые типы, которые мод обнаружил в сообщениях.
- Вкладки можно закрывать и перетаскивать местами.
- Кнопка `⌕` открывает поиск по сообщениям.
- Поиск фильтрует текущую вкладку по ключевому слову или фразе.

## Типы сообщений

Мод сам определяет тип по тексту:

- `GM`: сообщения с `[GM]`
- `ЛС`: сообщения с `[ЛС ...]`, `[PM]` и похожими маркерами
- `OOC`: сообщения с `((...))`
- `Общий`: всё остальное
- Новые типы: сообщения с префиксом вида `[Название]`, например `[Radio]`, `[Trade]`

## Конфиг клиента

Файл создаётся автоматически:

```text
.minecraft/config/rpchatui-client.json
```

На Windows обычно:

```text
C:\Users\Admin\AppData\Roaming\.minecraft\config\rpchatui-client.json
```

Это именно клиентский UI-конфиг: положение окна, размер, вкладки, масштаб текста.  
Он не меняет серверные радиусы RP Chat.

## Сборка

```powershell
cd "C:\Minecraft projects\rp-chat-ui-fabric-1.20.1-v2\rp-chat-ui-fabric-1.20.1-v2"

& "C:\Gradle\gradle-8.10.2\bin\gradle.bat" clean build
```

Готовый jar:

```text
build\libs\rp-chat-ui-0.1.1.jar
```

- Окно чата теперь видно всегда, пока открыт чат.
- В режиме игры сообщения держатся 15 секунд и плавно исчезают за последние 1.5 секунды.

- В настройках можно менять оттенок, прозрачность и включить режим, где окно чата не скрывается после закрытия чата.

## v23

- Мод теперь работает не только на клиенте, но и на сервере.
- Добавлен серверный конфиг максимальной длины сообщений:
  - `.minecraft/config/rpchatui-server.json`
- Глобальный лимит может менять только админ:
  - `/rpchatui length global <число>`
- ГМ или админ может задать индивидуальный лимит игроку:
  - `/rpchatui length player <ник> <число>`
- ГМ или админ может сбросить индивидуальный лимит:
  - `/rpchatui length reset <ник>`
- Проверка текущего лимита:
  - `/rpchatui length get`
  - `/rpchatui length get <ник>`
- Лимит синхронизируется с клиентским UI: счётчик `0/512` меняется на актуальное значение с сервера.
- Сервер также блокирует слишком длинные обычные чат-сообщения и пишет игроку, насколько он превысил лимит.
- Роли совместимы с RP Chat / DnD Profiles:
  - `rpchat_gm`
  - `rpchat_admin`
  - `profile_gm`
  - `profile_admin`
