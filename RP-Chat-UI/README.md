# RP Chat UI

Перемещаемое окно чата с вкладками, поиском, избранным и настройкой внешнего вида.
**Версия 0.3.7 · Minecraft 1.20.1 · Fabric · Java 17.**

[Скачать JAR](../releases/RP-Chat-UI/rp-chat-ui-0.3.7.jar) · [История изменений](CHANGELOG.md) · [Все проекты](../README.md)

## Установка

Нужны Fabric Loader и Fabric API для 1.20.1. Метаданные допускают Loader 0.15.0+;
для общего набора Dreamwalker используется 0.16.10+.
Установите JAR на клиент для интерфейса. Серверная установка включает управление
лимитами сообщений и их синхронизацию. [RP Chat](../RP-Chat/README.md) отвечает за
ролевые режимы и радиусы отдельно; UI не заменяет его.

## Управление

- Откройте чат обычной клавишей; `Enter` отправляет сообщение, при пустом вводе закрывает чат.
- Перетаскивайте окно за верхнюю панель, меняйте размер за края; `+`/`−` регулируют текст.
- Вкладки отделяют общий чат, OOC, GM и личные сообщения; можно создавать свои и менять порядок.
- Поиск помогает переходить между совпадениями. Контекстное меню сообщения позволяет копировать его и добавлять в избранное.
- `↑`/`↓` перебирают историю ввода, `Tab` дополняет команды и имена, `Ctrl+A` выделяет текст.
- Настройки сохраняют расположение, размеры, вкладки и оформление. Компоновка подстраивается под масштаб GUI.

Ссылки остаются кликабельными. Автозагрузка и предпросмотр изображений удалены;
описания этих возможностей в старом changelog относятся к прежним версиям.

## Настройки сервера

Клиентский файл: `config/rpchatui-client.json`; серверный: `config/rpchatui-server.json`.
Пути отсчитываются от соответствующей игровой папки.

| Команда | Назначение |
| --- | --- |
| `/rpchatui length get` | Посмотреть свой лимит |
| `/rpchatui length get Steve` | Посмотреть лимит игрока |
| `/rpchatui length global 512` | Задать общий лимит, для администратора |
| `/rpchatui length player Steve 1024` | Индивидуальный лимит, для GM/Admin |
| `/rpchatui length reset Steve` | Сбросить индивидуальный лимит |

Роли совместимы с RP Chat и тегами `profile_gm` / `profile_admin`.

## Разработка

JDK 17 и Gradle 8.10.2; из корня репозитория:

```sh
gradle -p RP-Chat-UI check build
```

`check` включает `layoutCheck` и `contentCheck`. Результат: `build/libs/rp-chat-ui-0.3.7.jar` внутри проекта.
Эти проверки не заменяют визуальную проверку в Minecraft.
