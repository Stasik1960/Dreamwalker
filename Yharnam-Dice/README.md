# Кости Ярнама

[Скачать JAR 0.1.0](release/yharnam-dice-0.1.0.jar) · [SHA-256](release/yharnam-dice-0.1.0.jar.sha256)

Мод для Minecraft Java 1.20.1, Fabric Loader 0.16.10 или новее, Fabric API 0.92.9+1.20.1 и Java 17. В мультиплеере мод и Fabric API устанавливаются на сервер и на клиенты. Скопируйте скачанный JAR в папку `mods`. Сборка из исходников на Windows — `.\gradlew.bat build`.

## Быстрый старт

1. В творческом режиме откройте вкладку **Кости Ярнама**. Там лежат стол, мешочек, пустая дискета, три готовые дискеты и 18 дизайнов костей. Пять редких дизайнов выдаются из вкладки. Стол, мешочек, пустая дискета и остальные 13 костей имеют рецепты.
2. Поставьте стол. Он занимает два соседних блока. ПКМ по мешочку открывает инвентарь из 20 мест. Перетаскивайте кости или используйте Shift + ЛКМ для быстрого переноса. Каждая кость занимает один слот, одинаковые дизайны разрешены.
3. ПКМ по столу занимает ближайшую свободную сторону. В правом нижнем углу выберите мешочек из инвентаря и нажмите на нужные кости. Выбранные кости появятся у вашего края. В свободном режиме можно сразу бросать от 1 до 20 костей. В режиме с правилами хост запускает партию, когда у всех собрано нужное число.
4. Кнопка **Встать** или Esc освобождает место. Кости принадлежат мешочку всё время, поэтому при выходе, отключении или поломке стола их игровое представление убирается со стола без переноса предметов между инвентарями.

## Готовые игры

- **Покер костями · Ведьмак 2.** Игроки сначала бросают по пять костей, затем по очереди оставляют руку или перебрасывают выбранные кости один раз. Побеждает старшая комбинация. Равные по силе руки дают ничью.
- **Фаркл · Kingdom Come.** Бросьте шесть костей и отметьте комбинации, дающие очки. **Отложить** сохраняет отмеченные кости до конца хода. **В зачёт** добавляет очки хода к общему счёту. **Бросить** перебрасывает оставшиеся кости. Если сыграли все шесть, их можно бросить снова. Бросок без очков сжигает только незаписанные очки хода. Цель — 4000.
- **Двадцать одно.** Каждый бросок двух D6 прибавляет сумму к счёту. Можно бросить ещё или остановиться. Точный 21 завершает ход, перебор проигрывает. Побеждает ближайший к 21, при равных результатах ничья.

Во встроенных играх место хоста переходит к следующему участнику. Если игроков становится меньше минимума, текущая партия заканчивается без победителя.

## Свои правила

Откройте дискету ПКМ и вставьте один JSON-объект. Сервер проверит его при нажатии **Записать**. Пустой текст очищает дискету. С записанной дискетой нажмите ПКМ по незанятому столу. Чтобы извлечь её, нажмите Shift + ПКМ пустой рукой, когда все игроки встали. Стол хранит дискету при сохранении мира.

Пример для короткой партии в Фаркл:

```json
{
  "id": "short_farkle",
  "name": "Фаркл до 1500",
  "game": "FARKLE",
  "minPlayers": 2,
  "maxPlayers": 4,
  "dicePerPlayer": 6,
  "target": 1500,
  "hotDice": true,
  "allowDuplicateDice": true,
  "hostExit": "TRANSFER"
}
```

| Поле | Значение |
| --- | --- |
| `id`, `name`, `game` | Обязательны. ID содержит до 32 строчных латинских букв, цифр или подчёркиваний, название до 64 символов. Движки `FREE`, `DICE_POKER`, `FARKLE`, `TWENTY_ONE`. |
| `minPlayers`, `maxPlayers` | Числа от 1 до 4. Если опущены, минимум 1 и максимум 4. |
| `dicePerPlayer` | Свободный режим — лимит 1–20. Покер — 5. Фаркл — 6. «Двадцать одно» — 1–6 за бросок, по умолчанию 2. |
| `hostExit` | `TRANSFER` передаёт роль, `CANCEL` завершает партию, `BETWEEN_GAMES` блокирует обычный выход хоста во время партии. |
| `target` | Цель в Фаркле или «Двадцать одном». По умолчанию 4000 или 21 соответственно. |
| `maxRerolls` | Число перебросов в покере, по умолчанию 1. |
| `hotDice` | Разрешает бросить все шесть снова после того, как все дали очки в Фаркле. |
| `allowDuplicateDice` | Разрешает одинаковые дизайны в выбранном наборе. По умолчанию включено. |

JSON настраивает один из четырёх движков, включая свободный стол для ручных правил. Новый способ подсчёта или новая последовательность ходов потребуют дополнительного движка в моде. Готовые примеры лежат в `src/main/resources/default_rules`.
