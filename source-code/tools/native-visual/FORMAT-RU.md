# Раздельное хранение визуала и физики

Обычная декоративная ячейка хранит зарегистрированное состояние `bloodborne_dw:native_physics_<bank>[part=<0..127>]`. Оно определяет точную общую коллизию, выделение, отсечение, оптику, жидкость, подъём и функции. Визуал не участвует в физических запросах.

В корневом NBT чанка находится `DreamwalkerVisuals`:

```text
Schema: 1 (int)
Catalog: SHA256 исходного assets/bloodborne_dw/native_grid/catalog.json (string)
Sections: [
  {Y: координата секции (int), Entries: упакованные значения (int[])}
]
```

`entry = (visualIndex << 12) | localPos`, где `localPos = ((y & 15) << 8) | ((z & 15) << 4) | (x & 15)`. Индекс визуала остаётся исходным индексом каталога; схема допускает до 2^19 индексов. Пустые ячейки отсутствуют в Entries. На каждую обычную физическую ячейку требуется ровно одна запись соответствующего визуала. Несовпадение схемы, каталога, состояния или числа записей вызывает явную ошибку загрузки.

В памяти только занятые загруженные секции получают массив 4096 int (16 КиБ плюс заголовки). Таблица принадлежит чанку. Изменение создаёт копию затронутой секции; поток построения геометрии использует неизменяемый снимок таблицы вместе со снимком состояний.

Начальная таблица передаётся внутри существующего пакета чанка, дополнительным compound в heightmap NBT. Обычный декодер высот использует только известные типы heightmap. Таблица устанавливается до окончания публикации чанка. Адресные изменения передаются отдельным малым пакетом с dimension, BlockPos, visualIndex+1 и raw state ID; предварительные изменения составной транзакции не публикуются.

Предмет хранит `NativeVisualIndex` (int). Подбор и обычное разрушение сохраняют визуальный индекс; установка восстанавливает таблицу и физическое состояние. Старый обычный native_grid предмет переводится при чтении его NBT без изменения входного compound. Пустое новое физическое состояние, установленное внешним кодом без визуального предмета, использует детерминированный представитель своего физического типа.

Цельные конструкции остаются на прежних native_grid ID и part: сохранены их роли, единая установка и разрушение. Они не получают запись в DreamwalkerVisuals. Данные старых корней/helpers v12 и NativeGridBase не заменяются этой таблицей.

Готовая старая карта переводится `convert_ready_world.py` по копии с журналом регионов, затем `repack_ready_regions.py` убирает только неиспользуемые регионные сектора с побайтной сверкой сжатых чанков. Исходный каталог и meshes.bin не экспортируются повторно. Загружать старую непреобразованную ordinary native_grid палитру новым модом запрещено: специальная проверка выполняется до потери неизвестных состояний при декодировании.

Сборка: Java 17, Gradle wrapper, `gradlew.bat remapJar`. Готовые производные ресурсы находятся в src/nativevisual/resources; для воспроизведения компилятора используется compile_layout.py. Обычная сборка не требует запуска конвертера мира или Minecraft.
