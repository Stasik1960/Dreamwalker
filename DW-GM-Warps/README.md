# DreamWalker GM Warps

Серверный мод для Minecraft 1.20.1 с Fabric Loader 0.16.10 или новее, Fabric API и Java 17. Положите JAR в серверную папку `mods` после удаления FTB Essentials, чтобы команды принадлежали одному моду. Клиентская установка не требуется.

Все команды, включая `/back`, доступны операторам уровня 2 и выше. `/back` возвращает только самого отправителя.

| Команда | Действие |
| --- | --- |
| `/warp` | Показать все сохранённые варпы. |
| `/setwarp hub` | Сохранить или обновить `hub` в текущей позиции и измерении игрока. |
| `/delwarp hub` | Удалить варп. |
| `/warp hub` | Телепортировать себя в `hub`. |
| `/warp hub Alice Bob` | Телепортировать обоих игроков в `hub`. |
| `/warp -120.5,70,42 Alice Bob` | Телепортировать обоих по координатам в измерении отправителя. |
| `/back` | Один раз вернуться на свою позицию перед последним успешным `/warp`, включая исходное измерение. |

Имена варпов состоят из букв, цифр, дефиса и подчёркивания. Регистр не учитывается. Для координат используйте формат `X,Y,Z` без пробелов внутри и точку для дробной части. Ники онлайн-игроков разделяются пробелами. Из консоли при телепортации укажите хотя бы один ник. Координаты из консоли относятся к обычному миру. Для `/setwarp` и `/back` нужна позиция игрока.

Варпы и точки возврата сохраняются вместе с миром в `data/dw_gm_warps.dat`. Файл FTB Essentials автоматически не импортируется.

Сборка на Java 17 и Gradle 8.8 командой `gradle build`. JAR и архив исходников появятся в `build/libs`.
