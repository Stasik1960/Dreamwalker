# История изменений

Исторические записи; актуальная установка и сборка — в [README](README.md).
Старые имена JAR и описания промежуточных исправлений не являются текущими инструкциями.

## v9

- Добавлены цветные ники по умолчанию: игроки зелёные, GM/Admin красные.
- Добавлена команда `/rename nick newnick`.
- Поддержаны русские ники и Minecraft-коды форматирования через `&`.
- Ник применяется в RP-чате, GM-чате, личных сообщениях, над головой и в Tab.


## v10

- Исправлена сборка: удалён несуществующий `setPlayerListName`.
- Для Tab используется mixin на `ServerPlayerEntity#getPlayerListName` и пакет обновления display name.
- `/rename` должен менять имя в RP-чате, GM-чате, ЛС, над головой и в Tab.


## v11

- Исправлено применение цветов в никах.
- Парсер `&`-кодов теперь собирает имя из реально отформатированных компонентов, а не через пустой корневой `Text`.
- Поддерживаются и `&cНик`, и `§cНик`.
- Цветовой код теперь сбрасывает активные жирный/курсив/подчёркивание по ванильной логике Minecraft.


## v12

- Цветные ники теперь передаются в двух вариантах одновременно: через нормальный JSON-стиль Minecraft и через legacy-коды `§`. Это нужно для совместимости с клиентскими RP/UI чат-модами, которые читают сообщение как обычную строку и теряют стиль `Text`.
- `/rename` без аргументов сбрасывает собственный ник.
- `/rename nick` сбрасывает ник указанного игрока.
- `/rename nick clear` оставлен как дополнительный вариант сброса.


## v13

- Добавлен mixin для `PlayerEntity#getName`, чтобы кастомный ник отображался над головой игрока.
- Для неймтега над головой используется чистый `Text` со стилем, без legacy-символов `§`, чтобы над головой не появлялись служебные символы цвета.
- Чат и совместимые RP UI по-прежнему получают legacy-совместимый вариант ника.
