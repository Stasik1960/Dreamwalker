# RP Chat

Ролевой чат с расстояниями слышимости, действиями, бросками кубиков и ролями игроков.
**Версия 0.1.16 · Minecraft 1.20.1 · Fabric · Java 17.**

[Скачать JAR](../releases/RP-Chat/rp-chat-0.1.16.jar) · [История изменений](CHANGELOG.md) · [Все проекты](../README.md)

## Установка

Нужны Fabric Loader 0.16.10+ и Fabric API для 1.20.1. Установите мод на сервер;
для клиентских возможностей, включая отображение псевдонимов, — также на клиенты.
[RP Chat UI](../RP-Chat-UI/README.md) добавляется отдельно для нового интерфейса.
[DW Languages](../DW_Languages/README.md) и [DW Magic Connect](../DW_Magic_Connect/README.md) расширяют речь языками и рациями.

## Игроку

| Ввод | Действие |
| --- | --- |
| `/rpchat help` | Справка в игре |
| Обычный текст | Речь в стандартном радиусе |
| `=текст`, `==текст`, `===текст` | Тихая речь, шёпот, едва слышная речь |
| `!текст`, `!!текст`, `!!!текст` | Громкая речь, крик, усиленный крик |
| `_текст` | OOC-сообщение |
| `-текст` | Закрытый GM-чат |
| `*села на стул*` | Ролевое действие |
| `#В долину пришла зима` или `№В долину пришла зима` | Повествование |
| `d20`, `5d20+3`, `/roll d20` | Бросок кубиков |
| `/m Steve сообщение`, `/r сообщение` | Личное сообщение и ответ |

Отдельный префикс громкости переключает постоянный режим; повтор сбрасывает его.
Отдельные `_` и `-` включают/выключают соответствующий режим чата.

## Администратору

- `/rpchat role Steve gm|admin|user` — назначить роль (выберите одно значение).
- `/rename Steve &6Новое имя` — задать псевдоним; `/rename Steve clear` — сбросить.
- `/listen 100` — слушать чат в заданном радиусе; `/listen` включает общий listen либо выключает активный.
- `/rpchat reload` — перечитать серверный конфиг.

GM/Admin определяются через OP 2+, роли и теги `rpchat_gm`, `rpchat_admin`,
`profile_gm`, `profile_admin`. Псевдонимы поддерживают Minecraft-коды цвета через `&`.

## Настройки и данные

Сервер создаёт `config/rpchat.json`: радиусы, подписи громкости, псевдонимы и логирование.
В одиночной игре это `config/` выбранной игровой папки, а не фиксированный путь `.minecraft`.
Клиентский конфиг не изменяет серверные радиусы. Логи: `<мир>/rpchat/logs/YYYY-MM-DD.log`.

Стандартные радиусы: обычная речь — 18; тихая — 9; шёпот — 3; едва слышная — 1;
громкая — 30; крик — 50; усиленный крик — 80 блоков. Значения на сервере могут отличаться.

## Разработка

JDK 17 и Gradle 8.10.2; из корня репозитория:

```sh
gradle -p RP-Chat build
```

Результат: `build/libs/rp-chat-0.1.16.jar` внутри проекта.
Событие `RpChatEvents.LOCAL_IC_MESSAGE` предназначено для интеграций обычной IC-речи;
OOC, GM-чат, личные и системные сообщения через него не передаются.
