# RP Chat Fabric 1.20.1 (v0.1.16)

Серверно-клиентский мод для ролевого чата.

## Быстрая справка в игре

```text
/rpchat help
```

Команда показывает краткую справку по режимам чата прямо в чат. `/rpchat` без аргументов делает то же самое.

## Радиусы обычного чата

По умолчанию обычный чат слышен в радиусе из `defaultRadius` в серверном `config/rpchat.json`.

```text
=сообщение    -> quietRadius
==сообщение   -> whisperRadius
===сообщение  -> barelyAudibleRadius

!сообщение    -> loudRadius
!!сообщение   -> shoutRadius
!!!сообщение  -> screamRadius
```

Отдельное `=`, `==`, `===`, `!`, `!!`, `!!!` переключает постоянный радиус. Повтор того же режима сбрасывает радиус обратно на стандартный.

## Пометки громкости

```text
=     -> (тихо)
==    -> (шёпотом)
===   -> (едва слышно)

!     -> (громко)
!!    -> (кричит)
!!!   -> (орёт)
```

Слова и радиусы можно менять в серверном `config/rpchat.json`.

## OOC

```text
_Привет
```

Появится как:

```text
Player: ((Привет))
```

Отдельный `_` включает или выключает постоянный OOC-режим.

OOC комбинируется с радиусом:

```text
=_Сообщение
==_Сообщение
```

## GM чат

```text
-Сообщение
```

Видят только GM/Admin и сам отправитель.

Отдельный `-` включает или выключает постоянный GM-чат. Пока он включён, обычные сообщения игрока уходят в GM-чат.

## Listen

Доступно GM/Admin:

```text
/listen      -> если listen выключен, включает чтение всего чата; если включён любой listen, выключает его
/listen 500  -> включает чтение всего чата в радиусе 500 блоков
```

GM/Admin определяются через OP уровень 2+, теги `rpchat_gm`, `rpchat_admin`, а также совместимые теги `profile_gm`, `profile_admin`.

Выдать роль:

```text
/rpchat role username gm
/rpchat role username admin
/rpchat role username user
```

## Конфиг

Конфиг является серверным и читается логическим сервером. Игроки не могут изменить радиусы для себя своим клиентским конфигом.

Файл создаётся автоматически после первого запуска сервера:

```text
config/rpchat.json
```

На dedicated-сервере это:

```text
<папка сервера>\config\rpchat.json
```

В одиночной игре / LAN это будет конфиг встроенного сервера:

```text
C:\Users\Admin\AppData\Roaming\.minecraft\config\rpchat.json
```

После правки конфига можно применить изменения без пересборки мода:

```text
/rpchat reload
```

Пример конфига:

```json
{
  "defaultRadius": 18,
  "quietRadius": 9,
  "whisperRadius": 3,
  "barelyAudibleRadius": 1,
  "loudRadius": 30,
  "shoutRadius": 50,
  "screamRadius": 80,
  "quietLabel": "тихо",
  "whisperLabel": "шёпотом",
  "barelyAudibleLabel": "едва слышно",
  "loudLabel": "громко",
  "shoutLabel": "кричит",
  "screamLabel": "орёт",
  "enableChatLogging": true
}
```

## Ники, цвета и /rename

По умолчанию ники игроков зелёные, а ники GM/Admin красные. Это применяется в чате, над головой и в Tab.

GM/Admin могут менять ник онлайн-игроку:

```text
/rename стандартныйНик новыйНик
```

Пример с русским ником и цветом:

```text
/rename Ringoto &aКура
/rename Ringoto &cГМ-Кура
/rename Ringoto &6Золотая Кура
```

Цветовые коды поддерживают стандартный Minecraft-формат через `&`: `&a`, `&c`, `&6`, `&l`, `&o`, `&r` и так далее.

Сброс ника:

```text
/rename Ringoto clear
```

Изменения сохраняются в серверном `config/rpchat.json` в блоке `nicknames`.

## Сборка

Версия 0.1.13 публикует `RpChatEvents.LOCAL_IC_MESSAGE` для интеграции с DW Magic Connect. Событие вызывается после доставки обычного IC-сообщения и не вызывается для OOC, GM, личных сообщений, команд или системных сообщений.

```powershell
cd "C:\Minecraft projects\rp-chat-fabric-1.20.1-v12\rp-chat-fabric-1.20.1-v12"

& "C:\Gradle\gradle-8.10.2\bin\gradle.bat" clean build
```

Готовый jar:

```text
build\libs\rp-chat-0.1.12.jar
```

## v12

- Цветные ники теперь передаются в двух вариантах одновременно: через нормальный JSON-стиль Minecraft и через legacy-коды `§`. Это нужно для совместимости с клиентскими RP/UI чат-модами, которые читают сообщение как обычную строку и теряют стиль `Text`.
- `/rename` без аргументов сбрасывает собственный ник.
- `/rename nick` сбрасывает ник указанного игрока.
- `/rename nick clear` оставлен как дополнительный вариант сброса.
