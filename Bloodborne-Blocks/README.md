# Bloodborne Architecture — Fabric 1.20.1

## Выпуск 1.2.0: простые формы и игровые взаимодействия

Мод добавляет строительную палитру Bloodborne в `bloodborne_blocks`. Он **не генерирует город**, не заменяет ванильные блоки и не конвертирует карту автоматически. Сохранены все **503 старых ID**; после скрытия пустых заготовок, удалённого мусора и дубликатов в творческой вкладке остаются **476 предметов**.

- У кустов и мягких ветвей нет столкновений. Выделение каждого занятого блока — один прямоугольник. Бочки, мешки, лампы и другие объекты с историческими названиями кораллов сохраняют подходящую физику.
- Твёрдые предметы используют простые коробки; у ступеней, дверей и арок сохранены нужные проходы. Вместо 171 307 коробок столкновений теперь 22 562, вместо 181 863 коробок выделения — 20 287. Это счётчики данных, не замер FPS.
- Каменный мусор `spruce_button` скрыт и не имеет столкновений. Для полной очистки его занятых клеток на старой карте команда обновления удаляет корни и связанные части. Ванильные еловые кнопки не затрагиваются.
- 240 декоративных блоков получили горизонтальный поворот при установке по направлению взгляда. Для 16 доказанных дубликатов выбран общий предмет; старые ID читаются, сохранённые экземпляры можно заменить командой. Скопированный предмет не закрепляет старую ориентацию.
- Исправлены установка от основания, лишняя клетка под тонкими моделями и применение NBT после проверки свободного места. Содержимое предмета не изменяется при неудачной установке.
- Секционные лестницы (`waxed_exposed_cut_copper_stairs`, прямые варианты) позволяют подниматься и спускаться по всей высоте, включая связанные части.
- ПКМ по чугунной лавке (`nether_brick_stairs`, варианты лавки) усаживает игрока; Shift позволяет встать. Одно место на лавку, очистка при выходе/удалении, поиск свободного места рядом при вставании.
- Большие двери (`acacia_stairs`, `birch_stairs`, `dark_oak_stairs`) открываются по ПКМ. Крупные предметы занимают связанные клетки и удаляются целиком. Исправления размеров предметов в руках/инвентаре и текстур из предыдущих выпусков сохранены.

## Установка

Готовый файл: [bloodborne-blocks-1.2.0-mc1.20.1.jar](../releases/Bloodborne-Blocks/bloodborne-blocks-1.2.0-mc1.20.1.jar).

Minecraft **1.20.1**, Java **17**, Fabric Loader **0.16.10+**, Fabric API **0.92.9+1.20.1**. Мод устанавливается на сервер и все клиенты; прежний JAR этого мода нужно заменить. Для ранее использовавшейся связки Sodium 0.5.11 нужен Indium 1.0.34. Исходный Bloodborne resource pack и старый `bloodborne_transparency_fix` должны быть отключены.

## Уже построенная карта

Старые состояния сохраняют прежнюю точку размещения (`assembled=false`), новые предметы получают нормализованную (`assembled=true`). Замена JAR сама по себе не переставляет здания. Для коллизии выступающих частей старых объектов нужно создать связанные клетки.

На **резервной копии мира**, с правами оператора, в нужной загруженной области:

```mcfunction
/bloodborne update 32 preview
/bloodborne update 32 apply
```

`preview` ничего не записывает. `apply` удаляет мусор, заменяет подтверждённые дубликаты с сохранением видимых координат, восстанавливает связанные клетки и удаляет потерявшие владельца части. Радиус **1–32** задаёт куб вокруг исполнителя по трём осям. Чанки принудительно не загружаются; посторонние постройки не затираются; объект с конфликтом пропускается целиком. Для всей карты команду нужно выполнить в её загруженных областях. Мир пользователя в ходе разработки не открывался и не менялся.

Прежняя команда `/bloodborne repair 16 preview|apply` остаётся для восстановления частей без замены палитры. Таблица замен: [palette-aliases.json](docs/palette-aliases.json). Геометрия старых 18 968 состояний визуально остаётся на прежних местах; сравнение с опубликованной 1.1.0 проверяется `tools/check_migration.py`.

Есть два явных изменения старой палитры: 99 наборов случайных вариантов с разной физической геометрией закреплены за первым вариантом; случайное смещение растений отключено. Это нужно для совпадения серверной коллизии и клиентской модели. Список: [stabilized-variants.json](docs/stabilized-variants.json).

## Проверки и ограничения

[Отчёт 1.2.0](docs/OPTIMIZATION-1.2.0-RU.md), [таблица всех блоков](docs/block-audit.csv), [аудит форм](docs/collision-audit.json), [результат проверки ресурсов](docs/resource-checks.json).

Minecraft, клиент, сервер и мир **не запускались** по указанию пользователя. Выполнены автономные проверки ресурсов, форм и дверных проходов, офлайн-просмотр моделей и Gradle build. Они не заменяют игровую проверку FPS, сетевой синхронизации, сохранения мира и совместимости с другими модами. Исторический отчёт `docs/VALIDATION-RU.md` относится только к старому выпуску 1.0.1.

## Сборка

```sh
./gradlew build
```

Windows: `gradlew.bat build`. Закреплены Loom 1.6.12, Gradle 8.8, Yarn `1.20.1+build.10`, Java 17. JAR появляется в `build/libs`; задача `geometryCheck` входит в `check` и не запускает Minecraft.

Готовые ресурсы включены: генераторы для обычной сборки не нужны. Инструменты `tools/catalog_geometry.py`, `generate_collision.py`, `validate_architecture.py` используют Python, NumPy, Pillow и оригинальный Minecraft client JAR только как архив ресурсов. Путь можно задать через `BLOODBORNE_VANILLA_JAR`. `prepare_architecture.py` — одноразовая миграция исходной палитры, повторно применять её к 1.1.0 и новее нельзя.
