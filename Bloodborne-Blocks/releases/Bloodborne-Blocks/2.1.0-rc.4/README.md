# Bloodborne Architecture 2.1.0-rc.4

Сборка по просьбе пользователя без дальнейших локальных тестов/запуска игры.
Это кандидат, **не сертификация RELEASE_READY** и не обещание совместимости
с неизвестным серверным modpack. В main автоматически не объединяется.

## Файлы

- `bloodborne-blocks-2.1.0-rc.4.jar` — Fabric 1.20.1, Java 17; Fabric API 0.92.9+1.20.1.
- `Bloodborne-City-2.1.0-rc.4.zip` — полная исправленная копия rc.3, не QA-save.
- `Bloodborne-Artist-Kit-2.1.0-rc.4.zip` — JSON/PNG/Blockbench, BASE/ALT,
  соответствия ресурсов и импортёр. Открытие/импорт описаны в `BLOCKBENCH.md` внутри ZIP.
- `delivery.json` — SHA-256, исходный commit и реальные границы проверки.

## Установка и откат

Остановить сервер. Сохранить прежние JAR и весь каталог мира отдельно.
Заменить старый Bloodborne JAR (не оставлять две версии). Распаковать новый город
как отдельный мир и указать его в `level-name`; не накладывать region-файлы поверх
другого мира. Сторонние моды карты не удалять. Для отката остановить сервер и
вернуть **оба** прежних компонента: JAR и целую резервную копию мира.

## Изменения и компромиссы

Добавлены семь отдельных авторских вариантов травы: теперь 57 logical families.
На новой копии города применены 2 725 группы приблизительных замен, разрешённых
пользователем; изменены 27 339 клеток. Книги — цельные, без collision.
Четыре спорных размещения явно сдвинуты: см. журнал `APPROXIMATION.json` в документации.
У отдельных трав исходная композиция приподнята до пола; UV/форма сохранены.
Соседняя модульная геометрия в пределах исторического footprint могла измениться:
это **приблизительное**, не точное побайтовое восстановление artwork.

До отмены дальнейших проверок: независимый census 34 233/34 233; весь мир —
0 unknown/invalid Bloodborne states и 0 helper errors; сохранены 170 non-terrain
файлов, 9 492 нетронутых чанка. Повторный проход: 0 замен, побайтовое совпадение.
Это покрытие известного census, а не доказательство полноты всех возможных
исторических декоративных объектов. Финальные client/dedicated/full-modpack
проверки не выполнены. Общий локальный check был остановлен по просьбе пользователя.
