# Bloodborne REPAIR TEST 3

Minecraft 1.20.1, Fabric, Java 17, существующий Fabric API. Замените прежний
Bloodborne JAR тестовым JAR в отдельной копии сборки. Распакуйте
`Bloodborne-REPAIR-TEST-3-world.zip` в `saves`. Полный город и main не изменены.

Окно занимает root и один helper сверху: collision и наведение 1×2×1.
Подоконник совпадает с верхом полного опорного блока. Artwork и раскрытие
ставней 22.5° сохранены; декоративное пересечение с задником допустимо.
Задник остаётся обычными независимыми блоками.

Две вкладки: основная — 50 строительных IDs / 139 художественных записей;
историческая и техническая — 3777 IDs / 46530 записей. Все 3827 BlockItem
доступны. Эти числа не означают 3827 полноценных строительных типов.

Начало оконного стенда: `/tp @s 86 65 17`. Столбцы x=86/98/110/122,
ряды z=22/32/42/52 — BASE closed/open, ALT closed/open; z=62 — стены без
окон, z=72 — окна без задника. Полный список пяти прежних образцов и действий:
[MANUAL-CHECKS-RU.md](MANUAL-CHECKS-RU.md).

`check build logicalGameTest` PASS: 228 Python tests,
56/56 server GameTests. Grid: 1788 logical + 52212 city states,
0 ошибок, 0 дополнительных изменений; недоказанные маски оставлены как были.
Маленький мир: 5 транзакций, 47 helper-связей, 0 orphan/unknown IDs,
повторный проход побайтно неизменен. Подробности — [verification.json](verification.json).

GUI, графический клиент и полный перезапуск приложения не проверялись.
Старые whole-world ошибки не пересчитывались. После пользовательской приёмки
следует один новый полный проход существующего конвертера на копии MODDED-бэкапа.
