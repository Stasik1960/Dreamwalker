# Проверки выпуска 1.0.1

Готовый JAR `bloodborne-blocks-1.0.1-mc1.20.1.jar` проверен в рамках завершённой миграции правильного мира Ether. При переносе в GitHub используются эти результаты; повторная конвертация и новые игровые запуски не выполняются.

SHA-256: `8f06380f9dbf460b11983f09671b16e142e68be8cb34e1dc6601cb18f0a1bf44`.

| Проверка | Результат |
| --- | --- |
| Модели и текстуры | 503 блока, 13 936 состояний, 948 520 проверенных граней; отсутствующих моделей и спрайтов мода не найдено |
| Исправленные варианты | 1 874 состояния, 39 354 сравнения с моделями, реально загруженными Minecraft из исходного пака; совпали геометрия, UV и пути текстур |
| Происхождение PNG | Все 307 файлов побайтно совпали с зафиксированными исходниками |
| Коллизии | 2 009 форм, 1 825 сравнений с нативным объединением, 48 216 контрольных точек |
| Визуал | Просмотрены пять пар кадров правильного исходного города и результата; шейдеры выключены, очереди Sodium завершены перед каждым кадром |
| Сохранение | После игрового сохранения сверены 27 119 848 архитектурных размещений и все 7 478 медных блоков/руд; изменений ID или свойств нет |
| Повторное открытие | 315 размещённых типов блоков и 102 полных состояния меди сохранены; новый чанк вне города полностью пустой |

Игровая конфигурация: Minecraft 1.20.1, Java 17, Fabric Loader 0.16.10, Fabric API 0.92.9+1.20.1, Sodium 0.5.11, Indium 1.0.34, Iris 1.7.5 с выключенными шейдерами, Continuity 3.0.0-beta.5 и совместимые моды присланной сборки.

Игровые проверки выполнялись на копиях мира. После них в выдаваемом мире восстановлено единственное служебное поле `Data.DragonFight` из исходного Ether; остальные поля NBT и файлы мастера проверены на неизменность. Это изменение метаданных не относится к JAR.

Визуальная проверка пяти ракурсов не является полным обходом каждого интерьера. Известные восстановления отсутствующих авторских текстур и ограничения коллизий сохранены. Отдельные ошибки ресурсов сторонних модов, включая Yuushya `knife_rest`, не исправляются этим модом. Выделенный сервер и производительность на пользовательском оборудовании отдельно не проверялись.
