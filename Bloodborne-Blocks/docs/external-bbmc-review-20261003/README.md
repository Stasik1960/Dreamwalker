Полноценный локальный запуск чужого мода не подтверждён: dedicated Forge 1.18.2 с GeckoLib падает на клиентском PoseStack, без GeckoLib — на отсутствующей зависимости. Графический клиент не запускался. Контрольные копии v14 и VladraCastle прошли load/save/restart на своих версиях Minecraft.

Архитектурный baseline — v14; поздний декор — v16; новые ресурспаки полезны для расширения палитры. v1 pack побайтно совпадает с нашим исходником. В v16 262 Bloodborne entities и две custom-block клетки. Число предметов исправлено: 103 обычных + 18 spawn eggs = 121.

Публикуются собственные отчёты, вычисленные inventories, результаты и код проверок. ZIP/JAR карт и модов, авторские текстуры/модели/звуки/изображения и декомпилированный чужой код не входят в этот пакет: комплект содержит ограничения на распространение. Декомпиляция и оригиналы сохранены локально для изучения.

Ветка `bloodborne` создана от `00948c356` — текущего tracked checkpoint проекта. Незавершённые изменения основной рабочей папки в эту публикацию не включены. Указанные в анализе текущие показатели city audit взяты из локального продолжения работы и не означают, что FAIL города исправлен этой веткой. Gradle/build/game code в этой задаче не изменялись.

Схемы высот — аналитические проекции NBT, не кадры Minecraft и не проверка проходимости. JSON миров исключает Player/UUID/inventory payload; их фактические данные не публикуются. Абсолютные локальные пути удалены из публичного пакета.
