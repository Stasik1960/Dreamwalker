# Bloodborne 2.1.0-unified-gallery.3

Исправляет зависание города при запуске с WorldEdit 7.2.15 и очищает неиспользуемые внутренние вариации. Предыдущая `.2` создавала 185 602 состояния и около 44,86 млн переходов WorldEdit; журнал пользователя и дамп JVM подтверждают исчерпание Java heap при построении этих таблиц. У пользователя это происходило даже с `-Xmx10G`.

Для широких блоков Bloodborne Minecraft и WorldEdit теперь находят готовое состояние в общей таблице блока. Они больше не создают отдельную плотную таблицу переходов для каждого состояния. Поведение `with`, `withIfExists`, `cycle`, проверки значений и исключения сохранены. Интеграция WorldEdit включается только при наличии этого мода; другие пространства имён не затронуты. Проверена совместимость с Lithium 0.11.2 из предоставленной сборки.

Удалены 3 612 неиспользуемых частных вариаций в 588 конструкциях: 14 448 состояний. Осталось 171 154 состояния и одно состояние служебного блока. Две дополнительные формы сохранены для исторических решений конструкций. Сохранены все 3 605 зарегистрированных ID, цифровые debug ID, отдельные дерево и куст, ручные правила «Правки финал», четыре горизонтальных поворота и все используемые формы города. Сходство расположения частей само по себе не считается доказательством одинаковой модели: сравниваются полный mesh, текстуры, геометрия и повороты. Дополнительных точных дублей среди оставшихся вариантов не найдено.

Очистка опирается на полный разбор упакованных индексов блоков и всех NBT карты и локального сохранения: контейнеров, вложенных предметов, сущностей, игроков, структур, схем и строк команд. Проверены 125 файлов. Значения оставшихся вариантов не перенумерованы. Все входные файлы и изменяемые ресурсы проверяются по SHA-256 до подготовки и применения результата. Пустые POI разрешены только по точным путям из исходного архива с зафиксированным SHA-256.

Город и демонстрационные площадки сохранены. Все 49 исходных файлов мира, включая его регионы, сущности, Yuushya и манифест редактирования галереи, входят в новый архив побайтно прежними. Добавлен только `optimized-mod-version.json`. Заменять реально используемые блоки при этой очистке не потребовалось; повторное перемещение конструкций и наложение коллизий также не требуется. В галерее остаётся по площадке на каждый ID, зазоры — три блока. Правила будущего удаления и замены экспонатов действуют как прежде.

Проверки: `gradlew.bat --offline --no-daemon --console=plain -I tools/verification-direct-resources.init.gradle -PbloodbornePython=<python> -Dorg.gradle.java.installations.paths=<JDK17> check build`; отдельная проверка упакованных mixin; запуск всей предоставленной сборки на dedicated server с 5 ГБ и клиенте с 8 ГБ, вход в галерею, проверка всех 171 155 состояний, граничных переходов свойств и 1 050 операций Minecraft, штатное сохранение и закрытие. Скриншот клиентской проверки приложен. Клиент проверялся без шейдеров, с дальностью прорисовки и симуляции три чанка; это проверка исправления загрузки, а не замер производительности при максимальной графике.

Установка: удалить старый Bloodborne JAR и положить `.3` из комплекта. Полный локальный `Mods-Fixed-2026-10-04.zip` содержит ту же сборку: заменён только Bloodborne, остальные моды побайтно прежние. Новый архив города содержит совместимую карту-галерею. Уже отредактированное пользователем сохранение автоматически не заменяется.

Состав комплекта и хеши — в `package-manifest.json` и `SHA256.txt`. Исходники и собственные материалы опубликованы в ветке `codex/bloodborne-unified-models-gallery`; полный архив сторонних модов предоставлен локально.
