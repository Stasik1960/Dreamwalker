# Установка и откат rc.3 checkpoint

Перед обновлением обязателен полный backup старого мира, JAR и конфигурации
сборки. Сначала используйте отдельную тестовую установку Minecraft 1.20.1,
Java 17, Fabric Loader 0.16.10 и Fabric API 0.92.9+1.20.1.

1. Остановите именно свою тестовую игру/сервер штатным способом.
2. Сохраните все исходные моды: данные игроков и остальных модов входят в
   поставляемую карту. Проверка с одним Bloodborne/Fabric API не заменяет
   полную сборку и может пропустить чужие entities на своей QA-копии.
3. Установите игровой `bloodborne-blocks-2.1.0-rc.3.jar` одинаково на сервер
   и клиент. Sources JAR предназначен разработчикам, его не кладут в `mods`.
4. Распакуйте `Bloodborne-City-2.1.0-rc.3-checkpoint.zip` под новым именем.
   `level.dat` должен находиться непосредственно в папке выбранного мира.
   Для dedicated укажите эту новую папку в `level-name`.
5. Отключите старые исходные Bloodborne resource pack и transparency fix:
   актуальные ресурсы уже включены в JAR. Сверьте SHA-256 из комплекта.
6. Проверьте реальные точки из `REPORT.md`: книги, grass_0, окно, ограды,
   двери, лестницы, сиденья и attachments. Графическая приёмка ещё требуется.

Простая замена JAR не выполняет миграцию вашей произвольно изменённой карты.
Офлайн-режим `--complete-accepted-objects --repeat-check` принимает
закреплённый rc.2 и пишет только в новую папку. Несовпадающие исходные клетки
не разрешают локальную очистку или поклеточный fallback.

23 неизвестных composite ID были намеренно удалены в прежней новой карте;
перед обновлением обязателен backup старого мира. Возможные визуальные
пустоты — следствие этого принятого retirement, а не «восстановление».
rc.3 не повторяет очистку прежних 33 координат: часть уже занята известными
объектами. Подлинно неизвестных Bloodborne palette IDs в поставляемом
checkpoint не найдено; новых неизвестных ID не удалялось.

Для отката штатно остановите тестовую установку, верните сохранённую пару
JAR+мир и конфигурацию модов. Не открывайте исправленный мир более старым
JAR ради отката и не перезаписывайте исходные rc.2/MODDED ZIP. Невыполненные
release gates и известные остатки приведены в `../RELEASE-STATUS.md`.
