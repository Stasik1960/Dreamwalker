# Редактируемые custom meshes

Статус: редакторский комплект для rc.4. Полная игровая приёмка не заявляется.
В едином ZIP модели расположены в `blockbench/models/`, текстуры —
в `blockbench/textures/`; обратный импортёр включён в `tools/`.

Экспорт: `python tools/export_blockbench_mesh_bundle.py build/whole-models/blockbench-meshes.zip`.
Единый комплект с существующими JSON/reference/ALT-архивами:
`python tools/export_current_art_bundle.py build/whole-models/artist-kit.zip --with-blockbench`.
Распакуйте архив целиком. Открывайте `models/<layer>/<mesh>.bbmodel` в Blockbench.
PNG находятся в общей папке `textures`; сохраняйте относительное расположение.
`mesh-manifest.json` связывает семейства и состояния (включая visual=base/alt)
с mesh, runtime-файлом, JSON visual model и контрольными суммами. Один mesh может
использоваться несколькими состояниями: изменение общего mesh влияет на всех
его потребителей. Физика/ownership этим инструментом не редактируются.

Файл `.bridge.json` рядом с моделью обязателен: Blockbench удаляет незарегистрированные
служебные поля при сохранении. Он также сохраняет исходную точность координат:
округление редактора до пяти десятичных знаков компенсируется в пределах
0.0000051 единицы редактора (один блок = 16 единиц). Более крупные изменения
координат сохраняются как правки. UV имеют шкалу 0..16, независимо от разрешения PNG.

После правки вершин/UV сохраните `.bbmodel`, затем:

```sh
python tools/blockbench_mesh_bridge.py models/logical/MESH.bbmodel edited-mesh.json
```

Команда создаёт новый JSON `{mesh_id: {polygons: ...}}`. Существующий выход не
перезаписывается. Импорт отвергает группы, анимации, кубы, небезопасные числа и
неприменённые origin/rotation: сначала сведите трансформации в координаты вершин.
JSON имеет формат runtime meshes, но сам по себе не обновляет JAR. Интегратор должен
заменить соответствующую запись mesh в указанном manifest runtime JSON/GZIP,
проверить всех его потребителей и запустить сборку/игровую проверку. Менять collision,
footprint, состояние или привязку owners вместе с визуальной правкой запрещено.

Для logical BASE/ALT можно сразу получить ресурсную JSON-модель:

```sh
python tools/blockbench_mesh_bridge.py models/logical/MESH.bbmodel edited-visual.json --visual-template PATH_TO_ORIGINAL_VISUAL_MODEL.json
```

Шаблон берётся по `visual_model` из manifest. Команда сохраняет его display-настройки,
заменяет геометрию на поддерживаемое runtime поле `bloodborne_polygons`, записывает
texture slots. Поместите результат в соответствующий model path ресурс-пака на
QA-копии, включите его выше ресурсов мода, выполните F3+T. Изменение ALT-слота
должно оставлять BASE неизменным. Импортёр не переключает visual state сам.
