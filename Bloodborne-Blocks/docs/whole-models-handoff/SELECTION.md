## Почему rc.3

Это единственная известная свежая пара, одновременно содержащая полный город,
текущий runtime и целые атомарные восстановления. rc.2 полезен как более раннее
доказательство server lifecycle, но переносить его поверх rc.3 без точной
проверки нельзя: rc.3 уже включает принятые решения и добавляет ручные целые
группы. Галереи и TEST3 не заменяют город.
