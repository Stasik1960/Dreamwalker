# Решения по цельным моделям

## Книги — принято B

Пользователь выбрал: «B: цельная композиция без коллизии (рекомендую)».
Основание: `books-current-vs-logical.png`, одинаковый масштаб, перспектива и вид
сбоку; синий обозначает selection, оранжевый collision. Исходные state/mesh/shape
сохранены в `books-current-vs-logical.json`; визуализация офлайн из настоящих assets.
Исходники runtime: rc.3 / `c568add9293ba8aae4f72ef48e9356496730bb7d`.
Пример текущего города: overworld `(-556, 50, -199)`.

Принятое поведение: целая авторская композиция `o_books`, без collision, с прежними
BASE/ALT и ориентациями. Соседний независимый декор и owners сохраняются. Решение
разрешает такую замену только при доказательстве полного текущего состава объекта;
оно не разрешает удалять произвольные соседние клетки. Одна исходная vanilla-клетка
не доказывает, что её нынешнее раздробленное представление занимает одну клетку.

Статус применения: ожидается проверка полного состава текущих фрагментов.
