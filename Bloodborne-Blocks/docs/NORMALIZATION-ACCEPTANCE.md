# Приёмка структурной нормализации

Продолжение предыдущей реализации. **Не готовая версия.** Наличие ресурса,
миграционного правила или успешного bootstrap-теста не означает приёмку объекта.
Результаты прошлой alpha в `LOGICAL-OBJECTS-STATUS.md` — исходная точка, не
результаты этого прохода.

Для каждой строки обязательны: правильный item, одно placement, единое selection
и breaking, orientation, collision, соседние соединения, open/closed (где нужно),
отсутствие заменённых частей в creative и миграция объекта реальной карты.

## Ограничение визуальной проверки

Клиент Minecraft 1.20.1 действительно запускался, но захват окна средствами
desktop-автоматизации завершился `SetIsBorderRequired / 0x80004002`.
Скриншоты игрового мира не получены, игровые действия не засчитаны.
Offline contact sheets используются только для сопоставления исходного artwork.

## Проверенный промежуточный срез — 21 сентября 2026

Это не завершение задачи и не новый опубликованный выпуск.

- Из прежних 2732 creative-items скрыты **1429**; остаются 1303 старых items.
  Среди оставшихся классификатор отмечает 562 составных фрагмента, 415 служебных
  вариантов, 192 без полной связи с источником, 111 самостоятельных и 23 варианта.
  Их нельзя бездоказательно скрыть, пока замена не покрывает все применения.
- Доступны 256 логических семейств. Серверный тест успешно проверил для каждого
  одно placement, создание helpers, правильный pick-item и единое breaking с одним
  drop. Это не проверка внешнего вида, всех ориентаций или всех объектов карты.
- Headless Minecraft GameTest: **7/7 прошли**. Дополнительно проверены четыре
  ориентации и open/closed дверей, ворот и ставней; соседские связи бордюра и
  высокой балюстрады; attachment статуи через master/helper; расход, возврат и
  единственный drop фонаря; creative без дублирования; заполненный survival
  inventory; отказ при препятствии и rollback прямой смены blockstate без потери
  чужой кладки. Для трёх лестниц в четырёх ориентациях проверен реальный
  `PlayerEntity.isClimbing()` на геометрии root/helpers и отсутствие climbing вдали.
  Это проверка поведения сервера, **не визуальная приёмка**. XML:
  `build/test-results/gametest/TEST-logical-gametest.xml`.
- Точный исходный фильтр исправлен для gothic_sash_window и iron_gate: их старые
  блоки не имеют свойства `assembled`. Генератор теперь прерывается, если хотя бы
  одно curated-семейство не получило ни одного правила миграции.
- На копии текущего `Ether-Bloodborne-2.0.2-positions.zip` преобразовано **59811**
  объектов. Независимо проверены 10009 чанков, 1003216896 позиций и сохранность
  170 файлов вне регионов. Повторная конвертация: 0 замен; все 186 файлов мира
  побайтово идентичны. Результат: `build/logical-world/Ether-Bloodborne-normalized-v5`.
- Отдельная, альтернативная копия раннего `Bloodborne-City-Ether-1.20.1.zip`:
  **86435** объектов, 117 семейств, независимая проверка 4489 чанков и 116 внешних
  файлов. Результат: `build/logical-world/Bloodborne-City-Ether-logical-v5`.
  Это не автоматическая замена актуальной карты: поздние изменения построек
  в раннем архиве могут отсутствовать. Миры не смешивались.

Перенос текущей карты всё ещё неполон: точные v2-комбинации окон/книг нередко
утрачены из-за старого объединения/отсечения перекрывающихся модулей. В ранней
копии удалось преобразовать 118 sash-окон, 14 tall-arched окон и 6 куч книг,
но framed-окна по-прежнему конфликтуют с окружающими блоками. Старые неполные
группы не заменяются по сходству имени или одному найденному фрагменту.

Вторая системная граница — пересечение авторского artwork со стенами и декором.
Текущий helper хранит одного владельца; отключение проверки чужих клеток
уничтожило бы кладку. Проверенные `ownership_bounds` допустимы для декоративных
свесов, но не для произвольного урезания физики. Shared ownership с вложенными
блоками требует отдельной схемы сохранения, выбора по лучу, удаления одного
владельца и сохранения поведения вложенных блоков. Root-only fallback не считается
выполнением требования полной selection/collision. Поэтому конфликты сохранены,
а все 23 строки пока остаются без полной визуальной приёмки.

```powershell

python tools/check_packaged_resources.py build/libs/bloodborne-blocks-2.1.0-alpha.1.jar
```

`.\gradlew.bat logicalGameTest check build`.

## Доказательства и ограничения миграции

- Исходные миры не редактируются; новые результаты и приватные ledgers — только `build/`.
- Проверка `check_logical_preservation.py` сравнивает существовавшие до этого
  прохода объекты, состояния, геометрию и правила с git-archive базовой версии.
- Старые registry IDs сохраняются. Для скрытия creative-модуля необходима
  доказанная замена всех его достижимых применений, не только совпадение имени.
- Оконные source-пары `deepslate_tile_stairs` и `smooth_red_sandstone_stairs`
  подтверждены в исходной карте: соответственно 322 и 1145 пар bottom/top с +2.
  `warped_stairs`: 45 таких пар; единственный +3 не подменяется правилом +2.
- Старые записи, называвшие deepslate/smooth-red stair модели балюстрадой,
  ошибочны. Визуальный аудит исходных моделей показал оконную геометрию.
- Шпиль подтверждён 459 точными тройками coal/raw_iron/raw_copper с +3/+6;
  необязательные основания ancient_debris не поглощаются.
- Крепление статуи подтверждено 50 парами одинаковой ориентации с +2.
  Единственная пара разных ориентаций автоматически не объединяется.
