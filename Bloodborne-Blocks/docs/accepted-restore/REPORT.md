# Объединённые принятые исправления — 2.1.0-rc.2

Комплект для проверки на отдельной копии: один JAR и полный город. Графический
клиент не проверен; это не окончательное восстановление всех исторических
объектов и не production RELEASE_READY.

Принятые TEST3 и реальное локальное продолжение сохранены вместе. Источник
runtime — checkpoint `41c20ee8b730c2d1567b2ab5a3d579d51bdbea1a`, родитель TEST3
`3d07b4890b7612b390fc0d975990bfadd7402cfb`. Точный интеграционный source commit,
JAR и world SHA указаны в [delivery.json](delivery.json).

База карты — опубликованный rc.1 SHA
`749853aeb19ba8ea823bf1f683476985b74e2fce2746143eeacc3225eb0ed0a9`.
Неизменный MODDED SHA
`c517dfeb52c4d13bdbe90e02a93ac00416354eb89313a9d1377f24823af6d0e9`
служит только доказательством исходных сборок. Новых пользовательских
сохранений не предоставлено. Исходные архивы не менялись.

26 804 подтверждённые транзакции continuation и 211 известных RC1 owner
объединены в 26 981 атомарную группу. 6 507 восстановлены, 20 474 уже корректны.
Независимо проверены 50 589 целевых root и 101 722 клетки. Фактически изменены
71 343 blockstate в 769 чанках; 9 240 чанков не изменены. Все 170 файлов вне
terrain, включая player data и данные других модов, побайтно идентичны.
Вне доказанных транзакций значимые terrain/NBT данные неизменны.

Полный мир: 10 009 чанков, 0 unknown ID, invalid states и ошибок ownership;
53 677 helpers проверены в обоих направлениях. Второй запуск: 0 записей,
0 изменённых чанков; все 186 файлов идентичны. Доказательства:
[первый проход](independent.json), [второй](second-independent.json),
[байтовое сравнение](second-byte-comparison.json).

## Точки проверки в полном городе

- Дерево: `(-284,42,-71)`; альтернативный подтверждённый пример `(-468,65,-305)`.
- Книги: `(-645,83,-8)` (`books_0`) и `(-639,83,6)` (`books_1`).
- Окно TEST3: `(-428,100,32)`, ориентация east; root + верхний helper.
- Шпиль C474: `(-566,85,-165)`.

Историческая точка реквизита `(-332,77,-137)` оставлена без изменения:
принадлежность целой стопке не доказана готовым accepted rule. Она не включена
в 34 восстановленные стопки. Нет склейки старой сцены C003: книги, мешок, бочка
и ящики остаются разными предметами. Исторические 933/112 случаи не объявлены
решёнными и не использованы как разрешение на запись.

Все 33 позиции прежнего retirement сохранены как в rc.1, включая NBT. 20 из
них уже были повторно заняты прежней конвертацией. Неизвестные 23 composite ID
не восстанавливались из MODDED.

Сохранены физика/placement всех 2 914 общих RC1 compatibility-блоков;
добавлены 868 принятых owner/строительных определений. JAR проверяется по
принятым исходникам и logical/owner-контрактам; release-check также повторяет
независимую проверку именно поставляемого архива города.
