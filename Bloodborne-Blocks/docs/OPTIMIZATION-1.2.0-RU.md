# Проверки Bloodborne Architecture 1.2.0

Стек не менялся: Minecraft 1.20.1, Fabric Loader 0.16.10+, Fabric API 0.92.9,
Yarn build.10, Java 17, Gradle 8.8, Loom 1.6.12.

## Формы и производительность

Проверены все 503 ID и 42 269 состояний. Формы вычисляются генератором заранее,
переиспользуются между состояниями; поиск профиля при столкновении использует
готовую таблицу BlockState вместо сборки и сортировки строки свойств.

| Данные общих профилей | 1.1.0 | 1.2.0 |
| --- | ---: | ---: |
| Профили | 2 778 | 2 644 |
| Занятые клетки | 18 710 | 20 287 |
| Коробки столкновений | 171 307 | 22 562 |
| Коробки выделения | 181 863 | 20 287 |
| Максимум физических коробок на клетку | 110 | 12 |

Выделение всегда состоит из одной коробки на клетку. Кусты/мягкие ветви пропускают
игрока; обычные твёрдые предметы имеют простую форму. Двери, арки и ступени
используют ограниченную сетку 1/4 блока, сохраняя необходимые отверстия.
Коробки тонких новых моделей не создают клетки ниже основания.
Это проверка объёма данных и алгоритмов, **не измерение FPS**.

## Сохранения и взаимодействия

- `tools/check_migration.py` сравнил 18 968 старых визуальных состояний с
  опубликованным коммитом `ad80f423dca92937726af3bdcb2b7731aa0edb6d`.
  Старые модели, ориентации и смещения сохранены. Удаление каменного мусора
  `spruce_button` — отдельное намеренное изменение отображения и взаимодействия.
- Проверены 16 таблиц дубликатов (112 состояний): после смены ID и смещения корня
  текстурированные грани совпадают. Старые ID остаются зарегистрированными.
- `/bloodborne update <1–32> preview|apply` строит план для загруженной области,
  пропускает конфликты с чужими блоками/сущностями и незагруженными клетками.
  Сама карта пользователя не открывалась и не изменялась.
- Подъём подключён только к игрокам и моделям лестниц, включая связанные части.
  Дополнительный поиск ограничен клетками рядом с ногами и проверяет близость
  к плоскости лестницы; глобального обхода мира или тика каждого блока нет.
- Сиденье создаётся сервером только по использованию лавки, не сохраняется,
  удаляется при вставании/выходе/удалении лавки. На одну лавку — одно место.
  Рендерер сиденья зарегистрирован только на клиенте.
- Нет новых сетевых пакетов, библиотек, генерации города или фоновой миграции.

## Выполненная проверка

- `geometryCheck`: все 42 269 состояния, пустая коллизия растительности,
  лимиты сложности, непрерывные клетки лестниц, проход 0.6 × 1.8 через открытые
  двери в четырёх направлениях.
- `validate_architecture.py`: 4 254 JSON, 497 предметных моделей в пределах
  заданного размера, полнота состояний и разрешение текстур.
- `check_migration.py`: старые визуальные состояния и таблицы замен.
- Gradle `build`: компиляция, проверки, remap клиентских/общих классов и JAR.
- Проверка ZIP, версии, ресурсов и refmap миксина в итоговом JAR.

По просьбе пользователя Minecraft, игровой сервер и мир не запускались.
Нужна игровая проверка размещения в конкретной карте, посадки/вставания,
подъёма, синхронизации и фактического FPS с используемым набором модов.
