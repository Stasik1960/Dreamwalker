КАРЕТА НОЧНОГО ДОЗОРА 0.1.3

Minecraft Java Edition 1.20.1 · Fabric Loader 0.16.10+ · Fabric API · Java 17

Установка
Готовая сборка находится в ../releases/Night-Watch-Carriage/.
Поместите JAR в папку mods на клиенте и на сервере.
В одиночной игре достаточно клиентской установки. LambDynamicLights
необязателен: он добавляет освещение окружения от включённых фонарей.

Как пользоваться
1. Возьмите карету во вкладке «Инструменты» творческого режима или через
   /give @s nightwatchcarriage:carriage. В выживании есть рецепт на верстаке:

     чёрная шерсть    фонарь    чёрная шерсть
     тёмный дуб       кожа      тёмный дуб
     железный слиток  —         железный слиток

   «Тёмный дуб» в рецепте означает доски тёмного дуба.
2. Поставьте карету на площадку. Наведитесь на нужное кресло или упряжь
   и нажмите ПКМ, чтобы занять именно это место, если оно свободно.
3. Пока игрок в упряжи, каретой управляет левый пассажир. Если его нет,
   рулит игрок в упряжи. Левый пассажир может передавать управление
   кнопкой «Руль» на панели. Работают назначенные в игре клавиши
   движения, по умолчанию WASD.
4. Приборная панель отображается внизу только у тех, кто занял место
   в этой карете. Сервер принимает её команды только от них.
   G включает курсор, а повторное нажатие G или Esc возвращает управление
   камерой. Курсором можно выбрать свободное место и нажать кнопки
   крыши или фонарей. Клавиша «Курсор на приборной панели» переназначается
   в настройках управления Minecraft.
5. Shift — выйти. Удар по пустой карете в приседе позволяет забрать её.

Сборка и проверка
gradlew.bat build           — собрать JAR.
gradlew.bat runGametest     — серверные сценарии с тремя игроками.
gradlew.bat runClientSmoke  — изолированный клиентский сценарий и снимки
                              в build/client-smoke/screenshots.
Для Unix вместо gradlew.bat используется ./gradlew.
Исходная модель: artwork/night-watch-carriage.blend.
Изображение модели: artwork/night-watch-preview.png.
Экспорт из папки проекта:
uv run --no-project --python 3.13 --with bpy==5.1.2 --with Pillow python scripts/export_carriage.py artwork/night-watch-carriage.blend
Экспорт уже включён в ресурсы, для сборки мода Blender не требуется.
