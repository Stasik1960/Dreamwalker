# Материалы завершённой статической миграции

`author/` и `geometry-export/` — раздельные дополнительные sourceSets; `portable-static.init.gradle` использует относительные пути. Author resources включают binding к игровому JAR и консервативную политику функциональных input families. По умолчанию game build не запускает эти инструменты.

`materials/` — точные контроллеры и генераторы фактически завершённой локальной операции. Их layout привязан к восстановленному handoff; не запускайте их как новый installer или повторную конвертацию. Нет задачи повторно проверить старые OOM, переупаковать прежний комплект или возобновить старые наблюдатели.
