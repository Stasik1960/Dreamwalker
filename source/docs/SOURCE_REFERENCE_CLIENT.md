# Эталонная физика оригинальной карты

Текущий эталон — `reports/SOURCE_REFERENCE_CLIENT_SWEPT.json` и сырые измерения `reports/SOURCE_PHYSICS_CLIENT_SWEPT_ACTUAL.json`. Настоящий Minecraft 1.18.2 / Forge 40.2.0 открыл отдельную копию исходного мира через штатный `Minecraft.loadLevel`. QA-мод измерил реальные collision/outline shapes и вызвал обычный `Entity.move` у Forge FakePlayer. Использованы неизменённые Bloodborne X Minecraft 6.0 и GeckoLib 3.0.57. В продукт Fabric этот QA-мод не входит.

Перед запуском все 114 файлов копии карты совпадали с ZIP-данными побайтно. Исходные архивы, моды и ресурс-пак сохранили SHA256. Пак заявляет pack_format 9; отдельный профиль 1.18.2 явно разрешает его через incompatibleResourcePacks. ResourceManager подтвердил загрузку оригинального пака. Новый запуск завершился штатным `Minecraft.stop`, кодом 0, за 56.875 с. Ошибки оригинальных мода/пака остаются в собственном логе; запуск доказывает измерения, без заявления полной совместимости сборки.

Измерены 165 исходных клеток и семь движений. Координаты старта и векторы сохранены; перед каждым движением загружены все чанки пересекаемой траектории с дополнительным краем в один блок.

| Проверка | Запрошенное Z, м | Реальное Z, м | Свободный проход |
|---|---:|---:|---|
| Западный просвет листвы | 3 | 3 | Да |
| Центральная исходная шерсть | 3 | 1.199999988 | Нет |
| Ствол из melon | 3 | 1.199999988 | Нет |
| Центр исходной двери | 4 | 1.199999988 | Нет |
| Бок исходной двери | 4 | 4 | Да |
| Центр исходного деревянного окна | 3 | 0.199999988 | Нет |
| Вход к исходной лестнице | -2 | -1.012499988 | Нет |

Перед окном находится исходный полный блок BRICKS в `[-32,37,-1121]`. Старый эталон `SOURCE_REFERENCE_CLIENT.json` / `SOURCE_PHYSICS_CLIENT_ACTUAL.json` сохранён как частичная история: его соседний чанк не был загружен, поэтому старое перемещение окна 1.2 м непригодно для сравнения. Исправленный результат 0.2 м совпадает с контрольным измерением исходных блоков в Fabric. Остальные шесть результатов сохранились.

Оба исходных `bloodborne:hunter_lamp_light_source` в `[228,69,-932]` и `[229,69,-931]` реально являются `AirBlock`: свет 9, isAir=false, replaceable=true, пустые collision и outline. Это подтверждает ограниченное сопоставление с `bloodborne_dw:source_hunter_lamp_light`; обычный AIR и свет 15 не эквивалентны источнику.

Collision/outline исходных окон соответствуют ванильным carrier-ступенькам. Эталон не доказывает авторское открывание деревянного окна. Движение новых створок и узкий ствол дерева остаются предложениями для первого review gate.

Ручное управление, визуальное сравнение и пользовательская приёмка отмечаются отдельно. Первоначальный неудачный dedicated server (`SOURCE_REFERENCE.json`), первая диагностическая попытка клиента (`SOURCE_REFERENCE_CLIENT_V1_FAILED.json`) и частичный второй клиентский эталон сохранены. Новая попытка находится в `build/source-reference-client-original-physics-v3-swept`; после измерений её собственный процесс PID94424 завершился штатно.

`INPUTS.json` отдельно хранит шесть additional_reference_inputs с хешами исходных Forge-модов, официальных Minecraft client/metadata/mappings и установленного Forge client profile. Восемь первоначальных пользовательских входов сохранены. `tools/record_inputs.py` перепроверяет эти файлы без чтения аккаунтов или launcher credentials.
