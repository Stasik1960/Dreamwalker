# Review V9 / 0.1.0-prototype.4

Небольшая повторная проверка замечаний после V8. Текущий production JAR: `dreamwalker-bb-fabric-1.20.1-0.1.0-prototype.4.jar`, SHA256 `a84d202c4f404ba48b6219e864f915f9160b0e0153b1b5a708d731f9ffd6d1a0`. Native Attempt10: 104/104, проверки ядра: 20/20. Все шесть обычных серверных фаз release5 прошли: создание сцены, игровое повторное открытие и повторное открытие только с production JAR — в минимальной и полной сборке. Исходная миграционная площадка release7 тоже прошла создание, production-only повторное открытие и повторное применение без изменений; четыре независимые проверки сохранений и архив прошли. Минимальный клиент release7 и сохранённый повторный вход release8 прошли нормальную загрузку, сохранение и выход; независимая диагностика release7 прошла. Полная клиентская сборка109 модов с Kappa5.2: release7 при heap4 ГБ не завершился нормально после99% heap и длительных GC; свежий release8 при heap6 ГБ пока проверяется. Успешный повтор не отменит ограничения исходного4 ГБ прогона. Ручная визуальная/игровая приёмка — `PENDING_USER_REVIEW`; полный каталог, весь город, галерея и финальные номера — `NOT_READY`.

Используется Minecraft 1.20.1, Fabric и Java17; нужны Fabric API и GeckoLib4. Этот JAR содержит RP-порт. При установке замените прежний Dreamwalker JAR и отдельный старый Bloodborne-RP JAR; одновременно две версии RP не устанавливаются. QA companion нужен только изолированным автоматическим проверкам и не является игровой зависимостью. Используйте отдельную копию обзорной карты из комплекта; исходный город не заменяется этой площадкой.

В Creative самостоятельный рисунок выбирается отдельным предметом с TEMP в имени и tooltip. Middle pick сохраняет художественный тип и BASE/ALT. В обычной новой установке положительное пересечение настоящих твёрдых collision-объёмов запрещено; касание и декоративное наложение разрешены. Для редактирования держите строительный инструмент: ПКМ в воздух перебирает действия, ПКМ по объекту применяет выбранное. Shift+ПКМ в воздух отменяет незавершённый выбор рычага. Режим «поворот» меняет остекление на90°, остальные поддерживаемые объекты на45°; у ограды он фиксирует текущую форму в MANUAL. Shift+поворот переключает BASE/ALT. «Режим остекления» переключает вертикаль/пол/потолок. «Положение панелей» открывает предусмотренные панели. Самостоятельное исполнение выбирается новым предметом, а не вариантом одного номера. Редактирование требует Creative/OP2 и права менять место; обычное игровое открытие дверей/сундука, действие рычага и фонаря доступны Survival.

В режиме «связать рычаг → объект» выберите конкретный рычаг91072/91073, затем конкретную активируемую цель. Подтверждение содержит TEMP и UUID двух экземпляров. «Показать связи» и «разорвать связь» работают с этим экземпляром. Несколько целей одного рычага и одна общая цель двух рычагов поддерживаются; исходная задержка —70тиков. Статичный люк91088 не получает выдуманной анимации. Видимость собак меняется режимом инструмента на конкретной клетке. Подробнее: [инструмент, связи и фонари](MECHANISMS_V9_REVIEW.md).
