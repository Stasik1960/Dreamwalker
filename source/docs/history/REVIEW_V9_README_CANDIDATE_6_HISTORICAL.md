# Review V9 / 0.1.0-prototype.4

Небольшая повторная проверка замечаний после V8. Текущий production JAR: `dreamwalker-bb-fabric-1.20.1-0.1.0-prototype.4.jar`, SHA256 `3f4461775234a5f86db657cd0c5322ea97b91347dcabf195556e48b496494d63`. Native Attempt6: 100/100, проверки ядра: 20/20. Повторные обычные серверные и клиентные запуски этого SHA ещё выполняются. Ручная визуальная/игровая приёмка — `PENDING_USER_REVIEW`; полный каталог, весь город, галерея и финальные номера — `NOT_READY`.

Используется Minecraft 1.20.1, Fabric и Java17; нужны Fabric API и GeckoLib4. Этот JAR содержит RP-порт. При установке замените прежний Dreamwalker JAR и отдельный старый Bloodborne-RP JAR; одновременно две версии RP не устанавливаются. QA companion нужен только изолированным автоматическим проверкам и не является игровой зависимостью. Используйте отдельную копию обзорной карты из комплекта; исходный город не заменяется этой площадкой.

В Creative самостоятельный рисунок выбирается отдельным предметом с TEMP в имени и tooltip. Middle pick сохраняет художественный тип и BASE/ALT. В обычной новой установке положительное пересечение настоящих твёрдых collision-объёмов запрещено; касание и декоративное наложение разрешены. Разрешение исходной конвертации относится только к первоначальному экземпляру и не переносится в новый предмет. `/bb debug` показывает настоящий тип, TEMP, владельца и отдельные счётчики collision/selection/helpers.

[Полная таблица прежний ID+вариант → новый тип](../reports/V9_TYPE_ID_MAPPING.json) сохраняет все использованные номера. Семь прежних мебельных TEMP зарезервированы как aliases; новые предметы/pick используют канонические номера. window03 с исходным −45° остаётся только у установленных исходных/старых экземпляров; обычного предмета для него нет, pick возвращает кардинальный window02. Финальные registry вида `bloodborne_dw:12345` ещё не назначены.

Для редактирования держите строительный инструмент: ПКМ в воздух перебирает действия, ПКМ по объекту применяет выбранное. Shift+ПКМ в воздух отменяет незавершённый выбор рычага. Режим «поворот» меняет остекление на90°, остальные поддерживаемые объекты на45°; у ограды он фиксирует текущую форму в MANUAL. Shift+поворот переключает BASE/ALT. «Режим остекления» переключает вертикаль/пол/потолок. «Положение панелей» открывает предусмотренные панели. Самостоятельное исполнение выбирается новым предметом, а не вариантом одного номера. Редактирование требует Creative/OP2 и права менять место; обычное игровое открытие дверей/сундука, действие рычага и фонаря доступны Survival.

В режиме «связать рычаг → объект» выберите конкретный рычаг91072/91073, затем конкретную активируемую цель. Подтверждение содержит TEMP и UUID двух экземпляров. «Показать связи» и «разорвать связь» работают с этим экземпляром. Несколько целей одного рычага и одна общая цель двух рычагов поддерживаются; исходная задержка —70тиков. Статичный люк91088 не получает выдуманной анимации. Видимость собак меняется режимом инструмента на конкретной клетке. Подробнее: [инструмент, связи и фонари](MECHANISMS_V9_REVIEW.md).
