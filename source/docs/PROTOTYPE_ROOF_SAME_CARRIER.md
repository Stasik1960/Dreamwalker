# Кровельный модуль: исходник, посадка и повторная проверка

Кровля TEMP **90003** и деревянное окно TEMP **90007** имеют разные registry IDs и предметы. Оригинальный ресурсный пакет назначает их одному vanilla carrier: `jungle_stairs[half=bottom,shape=straight]` выбирает `minecraft:block/wood_window`, а `half=top,shape=straight` — `minecraft:block/stairs/jungle_stairs_roof`. Исходное направление для обоих: south0°, west90°, north180°, east270°. Для рассмотренных селекторов назначена одна модель, без случайных альтернатив. Изменение соседних jungle stairs не превращает один новый тип в другой.

В оригинальной карте обнаружены 213 оконных и 601 кровельная ячейка. Это числа ячеек, а не логических объектов. Исходные примеры: окно `-32 37 -1120`, кровля `-173 59 -239`. Частоты, состояния и модельные хеши записаны в `reports/ROOF_PROTOTYPE_ASSETS.json`. Авторское имя модели и эти места применения не доказывают назначение каждого roof carrier в городе; прочие формы/углы исходной кровли этим прототипом не охвачены. Полный город не переносился.

Модель кровли использует исходную `block/addon/spirelamp_0026.png`, две наклонные объёмные части с intrinsic X45°/rescale=true и две декоративные двусторонние плоскости. Геометрия, UV, исходные повороты, display и PNG сохранены; импорт меняет ссылки ресурсов и particle alias. ALT по умолчанию наследует импортированную модель. Source yaw и global yaw применяются один раз после исходного element baking; наклон не дорисован и не удвоен. Исходные полные границы в модельных единицах `[-1,-3,-12.1525432638]..[17,28.1525432638,19]`, объёмных частей `[-1,-3,-6]..[17,22,19]`.

Для нового размещения применяется source NORTH yaw180 и part offset `[0,3,-5]`. Нижнее ребро объёмной части оказывается `[3,0,8]..[13,0,8]`, поэтому нужна реальная опора под центральным основанием. ПКМ предметом по верхней поверхности размещает весь модуль; полная опора и верхняя плита дают MountY0, нижняя плита MountY−0.5. Чужая опора сохраняет собственную физику. Инструмент/команда поворачивает тот же объект шагом45°; pick/drop возвращает один предмет с variant/profile. На новом месте посадка пересчитывается, исходный SourceShift в предмет не копируется.

Текущая физика V8 — **8 крупных ступенчатых объёмов** (по четыре для каждой объёмной наклонной части), вместо 82 мелких полос V7. Selection — **1 область выбора всего модуля**, вместо 143 мелких частей; она задаёт выбор и не является сплошной физической коробкой. Декоративные плоскости не получают твёрдую физику. Root essential mask содержит одну ячейку; пересечение визуального свеса с чужим блоком само по себе не очищает/резервирует его. Нативный выбранный контур следует `getOutlineShape`, а столкновения — `getCollisionShape`; раздельное добавление реализовано в `CompositeShapeMixin`. Цвет/число линий отдельного screenshot не служит замером физики. Авторские cuboids, нативные разложения и фактические helper/overlay cells учитываются раздельно.

Выравнивание ограниченного исходного примера использует SourceShift `[0,-3/16,+5/16]` блока для северного направления с последующим global yaw. Это компенсирует новую посадку и сохраняет исходные мировые координаты модели. V7 проверка ограниченного source save — историческое доказательство прежнего JAR. Для V8 подготовлен отдельный `build/source-review-prepared-v8-final2/world` с текущим descriptor SHA и guard перед QA-транзакцией; его runtime/save/reopen подтверждается отдельными текущими отчётами. Оригинальная карта/архив не меняются, весь набор из 601 carrier не объявляется перенесённым.

Новая сцена показывает два встречных ряда: `x=-16…-12`, `y=66`, `z=30/33`, yaw0/4, на обычных каменных опорах. Это наглядный строительный пример для осмотра посадки, поворота и стыка; герметичность полного ската, назначение всей городской кровли и пользовательская приёмка остаются открытыми. Выдать предмет можно через `give @s bloodborne_dw:prototype_roof`; TEMP90003 — временный номер типа, не registry/NBT/UUID. Сравнение с исходником выполняется в отдельном сохранённом source-фрагменте, где присутствуют исходные местные обстоятельства установки.
