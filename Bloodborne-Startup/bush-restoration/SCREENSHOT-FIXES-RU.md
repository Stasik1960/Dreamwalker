# Проверка исправлений со скриншотов

Проверка читает опубликованный Bush Restoration и собранный Distinct Forms. Она проверяет содержимое JAR и сохранение индексов городских фрагментов.

```powershell
python tests/check_screenshot_assets.py <Bush-Restoration.jar> <новый-Distinct-Forms.jar>
```

- У стекла 90643 и его фиксированных форм высота физики и обводки равна одному блоку.
- У стойки 93114 есть физическая преграда на высоте балясин и верхней балки. Для конструкции 34 из 93234 восстановлена коллизия стены.
- Пилястра 90478 ставится одним предметом целиком. Основание остаётся на уровне опоры, верхняя часть опущена на четверть блока. На сохранённой карте показанные части пилястры хранятся в ячейках запечённой геометрии. Нижняя ячейка содержит также грани соседней ограды. Original Pick выдаёт одну и ту же цельную пилястру по обеим её частям и сохраняет выбор ограды по попаданию в её грани.
- Стекло двери 93152 обрезано по двум проёмам с обеих сторон в закрытом и открытом состоянии. Это верхняя остеклённая конструкция над дверью в точке `171 90 -765` на карте Bush Restoration.

При загрузке чанков физика уже установленных составных блоков пересчитывается штатной миграцией по фактическому ID блока, включая отдельные формы. Файлы сохранения можно использовать без предварительной обработки. Существующие запечённые фрагменты пилястры остаются отдельными ячейками.
