# Авторские коллизии после V12.5

Исходный `docs/COLLISION_IMPORT_HANDOFF.md` сохранён без изменений. Экспорт
`dreamwalker-collisions.json` не предоставлен: **NOT_SUPPLIED_NOT_APPLIED**.
Новые таблицы V12.5 — наши упрощённые физические значения по умолчанию;
они не являются реконструкцией или применением коллизий автора.

`ImportedCollisionV125` читает встроенный
`bloodborne_dw/imported-collision-v125.json` один раз. Точный список допуска
содержит 1045 зарегистрированных объектов после оригинальной V12, включая
скрытые переходники сохранений. В рабочем каталоге V12.5 остаётся 551 новый
тип. Оригинальные V12 и технический `source_ladder_backing` вне этого списка.
Таблицы раздельно выбирают полный вариант, BASE/ALT, закрытое/открытое
положение и каждый из восьми поворотов. Пятьзначные ID, 1281 существующее
соответствие старых состояний и legacy-art таблица лестниц не изменены.
Добавленные городские состояния являются дополнительными вариантами;
для banked типов полный вариант равен `art_bank * 16 + variant`.

Будущий импорт должен разрешать точный актуальный ID и selector через
существующие `CollisionPack` / `CollisionReplacements`, а затем реально
потреблять авторскую замену **перед** этим default-путём в форме движения
игрока. Редактирование только `collision` в descriptor не применит замену:
новый default guard имеет приоритет. Пространственный поиск и движение
должны учитывать замену, фактический SourceShift, VerticalOffset, MountY
и ориентацию экземпляра. Кэш и диапазон поиска обновляются по этим данным.

`players_only` не означает замену общего occupied-footprint или физики
размещения блоков, NPC, опоры и сохранённых владельцев. Эти системы сейчас
используют наши default-таблицы. Авторская player-only замена требует
отдельного проверенного consumer; наличия parser/provider недостаточно.
Явно пустая reviewed-замена и отсутствующий selector остаются разными случаями.
Актуальные исключения оригинальной V12, удалённые номера и физика лестниц
сохраняются согласно исходному контракту и последующим указаниям владельца.
