# Упрощённая физика новых объектов V12.5

Основа: `653ae307ba4c44392ee08969f3890321e95659bb`. Оригинальная V12,
модели, текстуры, UV, legacy-art лестниц, номера и таблица соответствий
состояний не изменены этим этапом.

Новый default-ресурс имеет SHA-256
`d326175ab836e4555f04475c348afdbb065d8b8a87c8dc3185adb2d2ee8d7cf9`.
Он охватывает точно 1045 зарегистрированных новых объектов, 2534 полных
варианта и 81 088 комбинаций closed/open, BASE/ALT и восьми поворотов.
Рабочих новых типов после стилевого объединения — 551; скрытые переходники
сохранений остаются зарегистрированными.

Обычный объект получает одну обычную коробку. Наклонные крупные платформы
и сложные тела используют несколько крупных внутренних прямоугольников;
арки — необходимые опорные сегменты, максимум 12. Пустой проём и углы
охватывающего AABB не заполняются. Мелкие швы и детали не получают отдельной
физики. Частичное проникновение в модель допускается. Функциональные
кардинальные лестницы, подъём и физические исключения прежних арок сохранены.
Проходимые варианты остаются проходимыми и имеют одну простую форму наведения.
Для остальных объектов выделение совпадает с действующей физикой.

Формы заранее вычислены, JSON читается один раз; игрового растра нет.
Размер ресурса 2 741 312 bytes, 900 повторно используемых таблиц.
Кэш ограничен 4096 ключами, 65 536 ячейками и 262 144 ссылками на коробки,
не содержит ссылок на мир. Сдвиги и повороты не расширяют его без ограничения.
После instance-сдвига применяется прежнее обрезание небольшого выступа:
отдельно по каждой из шести сторон, строго меньше 0,5 блока.

Три точных NEW guards связывают ресурс с реальными physical/selection
footprints и занятой геометрией. Остальной код двух общих классов после
удаления этих трёх строк равен исходному. Существующий
`ImportedCollisionMigration` сравнивает сохранённую геометрию BEFORE с текущей,
атомарно удаляет старые вклады и сохраняет UUID, состояние и payload.
Корневая ячейка владельца остаётся занятой. Обычная повторная установка
по-прежнему проходит штатную проверку; постоянного обхода коллизий нет.

Для `source_allium` точная native-геометрия учитывает `rescale:true` при
нулевом угле: Minecraft использует коэффициент 45°. Старый collider этого
объекта не охватывал реальные высокие панели. Теперь используются до трёх
опор внутри видимых панелей, вместо сохранения невидимой старой коробки.
Визуальные ресурсы не исправлялись. Для прежних намеренных функциональных
исключений старые активные orientation domains сохраняют приоритет.

`offline-proof.json`: **PASS** по всем 81 088 комбинациям. Не осталось
пустых ранее непроходимых комбинаций или проверенных cuboid samples вне
исходной геометрии; 3424 функциональных кардинальных комбинации сохранены
точно, 6304 проходимых комбинации остались пустыми. Дополнительно проверены
125 точек каждой уникальной fitted-коробки; исходный offline fit проверяет
углы и центр своих аналитических ячеек. Это проверка геометрии, не игровой PASS.

Игровые проверки: **NOT_RUN в момент передачи исходников на сборку**.
Новый `ImportedCollisionV125GameTests` проверяет сохранённую полуаркy после
rebake, освобождение старых helper-ячеек, сохранение чужого stone/UUID/NBT,
реальное движение игрока и обычную установку ванильного блока; второй тест
проверяет свободные внешние углы крупной наклонной модели и оставшуюся опору.
Результаты конечной сборки и игровых прогонов добавляются отдельными отчётами.
Четыре SVG-схемы и `priority-cases.json` — offline координаты для native QA,
они не заменяют игровые скриншоты.

Авторский экспорт: **NOT_SUPPLIED_NOT_APPLIED**. Будущая интеграция описана в
`AUTHOR_COLLISION_INTEGRATION.md`; исходный handoff-контракт не изменён.
