RP placer icons, revision V12.3

Scope: 69 canonical offered RP object placer items from V12 and 7 retained
compatibility aliases. Exact resource list and model/texture hashes are in
RP-ICON-MANIFEST.json. No registry, catalogue, entity, placement, interaction,
animation, collision, saved-state, model geometry or texture changes.

The item model now selects Minecraft's builtin/entity model. Fabric's existing
BuiltinItemRendererRegistry invokes a client-only renderer of the original
GeckoLib cubes, UV and textures. The renderer copies the original bone snapshots;
it never spawns/ticks an entity or mutates the bones used by installed objects.
The static model is shown from an oblique angle. The authored wood_gate resting
sample uses the same existing AuthoredObjectMotion sampling as its world model.

All transformed vertices, including nested bone and cube rotations, are measured
in the icon orientation. A uniform scale puts the whole model inside a centred
cube of side 0.82, independent of large dimensions or off-centre model origins.
Small and large objects retain their proportions. Item GUI, held, dropped and
item-frame contexts use the same miniature with context-specific display scale.
The item renderer caches the copied bones and fit until GeckoLib replaces the
baked model on resource reload. The item does not run animation controllers.
