# Dreamwalker Bloodborne — меню V10 / 0.1.0-prototype.5

Статус этой рабочей инструкции: игровая проверка новой ревизии ещё выполняется. Окончательный SHA256, результаты и путь площадки будут записаны в отдельном отчёте V10. Прежняя V9 сохранена.

## Термины

Блок — архитектурный блок Minecraft. RP-объект (энтити-блок) — размещаемая декоративная сущность RP, например фонарь, мебель или лестница; это не название игрока или живого моба. Тип имеет пятизначный рабочий ID, экземпляр — собственный UUID, измерение и положение. Настройки и связи принадлежат экземпляру. Registry ID, рабочий номер и UUID показываются отдельно. Прежняя задача финальных числовых registry ID и частотной нумерации остаётся впереди.

Коллизия движения, область выбора и проверка размещения независимы. RP не препятствует размещению блоков и других RP, но сохраняет движение/опору по своей физике. Одну занятую ячейку BlockState это не разрешает перезаписывать. Монтажное смещение — перенос всего экземпляра по мировой Y, без изменения размера/анимации. Архитектурный корень и UUID сохраняются; RP переносится на разницу смещения, поэтому его фактическое положение используется фонарями и взаимодействиями.

Оформление (BASE/ALT, декоративная поза, содержимое) отличается от функционального открытия. Открываемый объект имеет устойчивые открытое/закрытое состояния. Импульсный объект запускает один клип; для 91094 не создаётся состояние открытия. Статичный 91088 не получает выдуманного действия. 90006 и родственные исполнения — деревянные архитектурные лестницы; 91069 — RP-лестница для взбирания с верхней платформой; 91086 — RP-ступени для ходьбы.

## Инструмент

Оба сохранённых типа, 90008 и 90009, работают одинаково и имеют разные вручную составленные пиксельные значки. Их различие сохраняет совместимость прежних предметов.

- `/give @s bloodborne_dw:builder_tool` — 90008.
- `/give @s bloodborne_dw:composite_builder` — 90009.
- Оба доступны в общей вкладке **Bloodborne · строительство и предметы**.

ПКМ инструментом в основной руке открывает меню в воздухе, по блоку и по RP. Дверь/рычаг/фонарь при этом не срабатывает. ЛКМ применяет выбранное действие один раз; удержание не повторяет монтаж. Инструмент в любой руке отменяет обычное разрушение и удары. Для редактирования перенесите его в основную руку. Уберите оба инструмента, чтобы обычным Creative ЛКМ снова удалять RP.

Меню не приостанавливает мир. Esc закрывает без применения незавершённых форм. Кнопка режима выбирает действие для следующего ЛКМ; формы применяются отдельной кнопкой. Вкладки и просмотр сами по себе не меняют объект. Полный UUID/registry находятся в «Подробностях». Перекрывающиеся объекты выбираются из списка с ID/положением; закреплённый выбор обозначен и временно выделяется. Колесо мыши прокручивает страницы.

На вкладке «Объект» доступны поворот с допустимым шагом, подъём/опускание с шагами 1/16, 1/8, 1/4, 1 (исходно 1/8), точное смещение и сброс только высоты. BASE/ALT, положения панелей, монтаж стекла и содержимое показываются по возможностям выбранного типа. Стекло поворачивается только на 90°; «Вертикально / Пол / Потолок» задаются отдельно. Изменить художественный тип через старый «вариант N» нельзя — у самостоятельного исполнения свой предмет.

Для функционального объекта задаётся «Рукой и рычагами» либо «Только рычагами». Второй режим личным сообщением «не поддаётся» отказывает ручному клику и сохраняет работу рычагов. Это отдельная настройка, она не является общей RP-блокировкой Locked.

## Простой рычаг

1. На вкладке «Рычаги» введите имя и создайте правило: исходно «Любой, открывать/закрывать».
2. Выберите режим «выбрать источники», закройте меню и ЛКМ выберите рычаг.
3. В меню выберите «добавить цели», затем ЛКМ выберите дверь/сундук/ворота. Один источник остаётся выбранным для нескольких целей.
4. Просмотрите состав и завершите выбор. Уберите инструмент; обычным ПКМ активируйте рычаг. Сохраняется принятая задержка 70 тиков.

«Любой» действует на отдельное успешное срабатывание. «Только открывать» не закрывает уже открытую цель; «Только закрывать» не открывает закрытую. Импульсная цель запускает одиночную анимацию. Входящие/исходящие правила видны с выбранного экземпляра.

## Группа «Все»

Создайте правило, добавьте несколько источников и целей, в форме выберите «Все» и примените. Новое правило само не запускает механизм. Меню показывает, например, «Активированы 2 из 3». Логический признак источника сохраняется отдельно от его короткой анимации и общий для всех его правил.

При «Открывать и закрывать» достижение всех активных открывает цели, нарушение условия закрывает. «Только открывать/закрывать» действует при достижении всех активных, а при нарушении оставляет состояние. Импульсная цель срабатывает только при достижении условия. Сброс предварительно показывает затронутые группы; он пересчитывает «Все» и не создаёт срабатывание «Любой».

Порядок создания правил сохраняется и показан номером. При нескольких правилах одной цели это отмечается; последнее применённое действие определяет результат. Защищённое закрытие при живом игроке в проходе остаётся в очереди до фактического успеха. Выгрузка чанка не равна удалению. Удаление обязательного участника «Все» делает правило неполным; состав восстанавливает оператор, оно не превращается автоматически в выполненное.

## Телепортная линия

Настройка сети требует оператора уровня 2. На вкладке «Фонари» выберите режим исходного фонаря и ЛКМ укажите A. Он регистрируется автоматически; имя можно изменить формой. Создайте/выберите линию, например «Центральный Ярнам». Выберите «В обе стороны» (по умолчанию) или одно направление, примените параметры назначения и выберите режим добавления назначений. ЛКМ укажите B, затем C.

Линия содержит явные связи A↔B и A↔C; это не создаёт B↔C. В списке видны настоящие направления. Направление/разрыв меняют указанную связь выбранной линии. Обратный маршрут другой линии сохраняется и отмечается. Старые направленные связи V9 импортируются направленными. Удаление всей линии подтверждается в меню с указанием её имени.

Уберите инструмент, ПКМ по точному фонарю откройте обычное меню и выберите имя назначения. Оно не приостанавливает мир, поддерживает прокрутку и Esc. Пауза между переходами показана остатком времени. Для выгруженного назначения временно запрашиваются только нужные чанки с ограничением ожидания; заявки освобождаются при успехе, отказе, отмене, выходе и остановке сервера. Удалённый или небезопасный узел не становится разрешённым переходом. Респавн и исходный технический свет в этой ревизии не перерабатываются.

## Команды и диагностика

«События» доступны администратору уровня 4. Для действительно открываемого экземпляра есть раздельные списки «После открытия» и «После закрытия», редактирование/перестановка/удаление и явное сохранение. Они выполняются сервером по порядку после фактического успешного изменения, без повторов от тиков, загрузки и одинакового состояния. Неудача команды журналируется и не откатывает объект. Вложенный переход из команды не запускает бесконечную цепочку.

Подстановки: `{id}`, `{uuid}`, `{x}`, `{y}`, `{z}`, `{dimension}`, `{player}`. Контекст — измерение и фактическая монтажная точка цели. `{player}` — инициатор; без доступного инициатора такая команда пропускается. UUID RP можно использовать с @e, UUID архитектурного владельца не является UUID сущности — используйте координаты/измерение.

Безвредный пример: `execute positioned {x} {y} {z} run playsound minecraft:block.note_block.bell master @a[distance=..16]`. Списки команд не назначаются обычным строителем только на основании Creative.

«Диагностика» сохраняет снимок выбранного объекта с пометкой, запускает запись 60 секунд для всех/выбранного экземпляра, останавливает её, показывает статус и экспортирует ZIP существующей системы. Управление требует оператора уровня 2. Запись по умолчанию выключена; снимок не меняет объект. Команды `/bb diagnostics start 60`, `stop`, `status`, `mark <пометка>`, `export` и `/bb debug <пометка>` сохраняются.

Общий FPS не означает процент нагрузки конкретного типа. CPU-подготовка рендера не является временем GPU. Отчёты различают клиент/сервер/общий Java-процесс, ограниченные выборки и не измеренные данные.

## Граница этой ревизии

90020 — восстановленный самостоятельный window03 с нормализованным внутренним углом и собственными pick/drop. Обе стороны 90010/90020 используют лицевую область исходного атласа; отдельный придуманный рисунок не добавлен. Старые формы обрабатываются совместимо без массового сдвига карты. Каталог, окончательная нумерация и полная конвертация города остаются отдельными незавершёнными этапами исходного задания.
