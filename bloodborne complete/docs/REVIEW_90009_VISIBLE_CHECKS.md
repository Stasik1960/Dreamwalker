# Оставшиеся видимые проверки 90009

Это план, а не отчёт PASS. 10 октября пользователь завершил проверки на сегодня и поручил передачу на GitHub для другого компьютера. Minecraft сохранён и закрыт, Computer Use сброшен. Итог наблюдений и очередность продолжения — HANDOFF.md и reports/REVIEW_90009_NATIVE_VISIBLE_20261010.json. Использовать отдельную копию выдаваемого ZIP, обычный JAR из той же папки и минимальный профиль без QA. Не открывать пользовательские миры.

## Первый проход

Войти в распакованную галерею: Creative, читы, 90009, точка `[0.5,64,-5.5]`. Проверить краткий ПКМ и первый ЛКМ, который только закрепляет экземпляр. В форме выбрать поворот; следующий ЛКМ при взгляде на землю должен изменить закреплённый UUID. Shift+ЛКМ возвращает направление. Ctrl+колесо меняет режим, Alt+колесо — шаг высоты `1/16,1/8,1/4,1`, без смены слота; обычное колесо снова меняет слот. Ctrl+Z отменяет только последнее успешное действие; X завершает выбор, не стирает сохранённые связи.

Во вкладке «Управление» назначить действие на E: при инструменте E редактирует, без инструмента открывает обычный инвентарь. Проверить чат и поле ввода, затем сбросить назначения. Создать два перекрывающихся экземпляра на свободном месте: средняя кнопка перебирает кандидатов, ЛКМ не выбирает автоматически соседний UUID. Инструмент в другой руке защищает от обычного удара, но редактирование требует основной руки.

Меню: 1280×720 с обычным Auto и увеличенной доступной шкалой, 1920×1080 со scale3 и scale4. Проверить все шесть вкладок, колесо/страницы, длинный UUID/список, нижнюю строку действий. Изменить черновик → Esc → Остаться → сменить вкладку/размер → Сохранить с ACK. Отдельно «Не сохранять». Не считать просто открывшееся меню полным прохождением T21.

Каждую собаку скрыть, вернуть и проверить картинку без инструмента в руке: исчезает собака, не клетка. Второй экземпляр того же типа не должен измениться. Сохранить/выйти/войти и повторить наблюдение. Снять F2 до/после с одинаковой камерой.

Рычаги: обычным ПКМ без инструмента, дождаться 70 тиков и окончания собственного клипа; все три настоящие цели должны сработать. Затем пройти создание новой простой связи без меню, ANY/ALL, удаление конкретной связи, неполную группу и «Только рычагами». При закрытии с игроком в проходе проверить один безопасный pending CLOSE.

Фонари: настоящие A→B→A и A→C→A из обычного меню, не `/tp`. Переименовать имя узла и линии через форму; следующий LINK использует новую линию. Проверить отмену, cooldown и недоступное/небезопасное назначение. Сохранить и повторить круг после входа.

Объекты: обойти обе стороны остеклений, повернуть только на90° и проверить все плоскости без ресурс-пака/шейдера. У оград проверить разрешённые углы, сохранение без нижнего блока и отсутствие взаимных соединений диагонального столба с vanilla wall/fence/pane. У лестниц проверить реальное движение игрока, удаление одной из двух опор, высоту/поворот и повторный вход. В выступающую часть90003 поставить обычный блок: корень и движение не повреждены.

Ordinary взаимодействие проверять без инструмента: настоящие части и промежутки между ними, каменное препятствие, Creative и Survival штатная дальность. Спам двух рук/рычагов не прерывает клип и не копит новые OPEN/TOGGLE/PULSE; 91094 остаётся одиночным импульсом, 91088 статичен. Для 91030/91013 новое размещение, высота/сброс, восемь углов и сохранение не меняют исходную базу. RP nameplate отсутствует, CustomName/HUD и имена NPC сохранены.

## Отдельный сервер и завершение

На изолированном localhost-сервере с обычным JAR выдать только тестовому игроку OP4. Через форму назначить две безвредные команды после открытия/закрытия: сообщения с разными пометками. Проверить порядок, сохранение, отсутствие выполнения при повторе/занятости; без OP4 редактирование недоступно. Два действительных клиента: отдельные выборы, конфликт версии общего UUID и безопасная отмена. Серверные mock-player проверки не заменяют этот пункт.

Диагностика: через GUI снимок/60с/автостоп/mark/stop/export, настоящие отдельные server/client отчёты и ZIP. Сравнить одну и ту же сцену без подсветки/с подсветкой/с записью; не объявлять FPS процентом нагрузки типа или CPU временем GPU. Фоновый console-прогон проверяет только серверную часть, не клиентскую кнопку.

Все результаты записывать в матрицу T01–T32 разрешёнными статусами. После проверки сохранить и штатно выйти из Minecraft, сбросить сеанс Computer Use и сразу сообщить о возврате управления. При последующем исправлении пересобрать JAR и повторить только затронутые проверки; неизменившийся полный набор не запускать по кругу.
