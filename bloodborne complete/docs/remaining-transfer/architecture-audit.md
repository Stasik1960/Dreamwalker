# Архитектура V12 перед дополнительным переносом

База: `8b770a03de21554a21c91700a1c1c6fe86c894c4`. Окружение LocalC проверено;
перенос E: остаётся на паузе. Карта и галерея в этом этапе не изменяются.

Вход мода `DreamwalkerBb` сохраняет независимые архитектурные и RP source trees.
Combined JAR собирает `src/architecture/java`, `src/rp/java` и ресурсы обоих
пространств. Пространство `minecraft` содержит только атлас и теги, а не замену
исходных ванильных blockstate/model/texture. Исходный ресурспак не требуется.

## Минимальный путь расширения

`CompositeSpec` загружает descriptors `bloodborne_dw/composite/<path>.json`.
Для нового законченного объекта задаются исходные визуальные parts, отдельные
selection/collision, essentialMask и support. `CompositeRootBlock` и `CompositeItem`
уже обеспечивают одно предметное размещение, owner UUID, копирование состояний,
45° yaw, удаление всей сборки и сохранение ledger/NBT. Неподвижные новые объекты
не наследуют vanilla stair/button/trapdoor/plant carrier behavior.

Все существующие объекты используют rotation 0–7, variant 0–15, open и profile:
512 BlockState на новый registry type. Уменьшение диапазона требует изменения
действующих общих контрактов и для этого этапа не нужно. Самостоятельные artworks
имеют самостоятельные TEMP типы; только поворот/поза/BASE–ALT одного объекта являются
состояниями. Все законченные состояния должны быть предложены предметами.

`import_remaining_assets.py` дописывает только новые `source_*` объекты и отдельное
дерево `bloodborne_dw:remaining/source/`. Модели и texture dependencies разрешаются
по v15 с fallback на vanilla 1.20.1. Parent/texture references получают собственное
пространство имён; геометрия элементов, UV, display и PNG bytes сохраняются.
Элементы с собственной вращательной геометрией получают SAT voxel raster для новой
физики по умолчанию, а не заполненный большой AABB. Это не авторские коллизии Studio.
Нулевые визуальные плоскости имеют selection, но не физическую коллизию. Полупрозрачная
alpha используется для translucent layer; остальные новые объекты используют cutout.

Новые PNG находятся в `textures/block/remaining/source/`, поэтому стандартный
источник `block` ванильного атласа включает их без изменения прежнего атласа V12.
`_e` маски двух реально используемых текстур сохраняются отдельными точными
overlay-моделями; новый `source_` renderer использует fullbright только для этих
частей. Это свечение исходной текстуры, а не выдуманный источник мирового света.

После подтверждённого OOM при сохранении тестового мира новые SAT defaults
объединены в точные прямоугольные объединения. Для слияния обязаны совпадать
четыре координаты поперечного сечения; объединяются только смежные/перекрывающиеся
интервалы третьей оси. Отверстия не заполняются, большой enclosing AABB не
подставляется. Архив `box-coalescing-before-after.jsonl.gz` сохраняет исходные и
итоговые массивы по registry ID, variant, pose и collision/selection; независимая
проверка сравнивает точное покрытие координатными слоями.

Прежние runtime, serializer и лимит пакета 1 MiB не изменены. Статический аудит
`packet-budget.json` повторяет native clipping для всех восьми поворотов и
подсчитывает настоящий размер NBT: каждый cuboid занимает 53 байта в списке,
collision и selection передаются отдельно. Аудит обычного предметного размещения
использует пустой строительный payload и одного owner в ячейке; размер произвольной
поздней пользовательской NBT и нескольких владельцев этим расчётом не ограничивается.

JSON с синтаксическим дефектом, отсутствующий parent/texture, циклические aliases и
неподдерживаемое исходное содержание отмечаются конкретным дефектом. Они не угадываются.
Source dependency copy и сборка не являются native визуальной/игровой приёмкой.
