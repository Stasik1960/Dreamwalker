# Ручное редактирование галереи

Файл галереи содержит 580 семейств блоков. Пол платформ находится на Y=336, ROOT — на Y=337. Размер платформы 7×7, шаг 9, зазор 2 пустых блока. Якорь галереи: X=-80, Z=-1104; spawn — (-77,338,-1101). Последняя допустимая высота — Y=511. Город ниже галереи сохранён. Распакуйте `Bloodborne-DW-v16-gallery.zip` как отдельный мир и откройте его с complete и зависимостями. При необходимости `/tp @s -77 338 -1101`.

Manifest неизменяем: редактирование выполняется только поверх полного world-файла и manifest. Construction capture bounds берутся из manifest. Не меняйте ID вручную и сохраняйте текстовые исправления по ID вместе с этими двумя файлами.

На табличке каждой платформы указан её постоянный ID. Расположение рассчитано по соседству блоков в городе: близость платформ не означает близость ID. Дверь, кровать или двухчастное растение представлены одним логическим семейством, хотя физически занимают две ячейки; обе отмечены в `logical_block_cells`.

Рабочий объём `construction_bounds` — центральные 5×5 блоков над платформой, высотой 15 блоков. Не заходите конструкцией на соседнюю платформу. Пол, табличка и неизменённые опоры нужны для работы галереи и не входят в будущую модель. Для сравнения опор используется исходная галерея с тем же manifest; изменённую опору нельзя автоматически исключать как служебную.

- Удалите исходный образец, включая вторую половину при её наличии. Если рабочий объём после исключения служебных опор пуст, ID подлежит удалению. Он сохраняется в истории и не выдаётся заново.
- Установите один новый блок вместо образца: при будущей обработке его внешний вид и свойства заменят старые, а ID платформы останется прежним.
- Соберите несколько блоков в рабочем объёме: это заявка на единый логический блок с тем же ID. ROOT может быть пуст, если осталась новая конструкция; это не считается удалением. В будущем будут отдельно проверены перенос моделей, состояний и физики всей конструкции.
- Не меняйте таблички, границы или `gallery-manifest.json` и не переставляйте платформы. Смена ID самим игроком не требуется.

После будущей обработки все экземпляры ID в городе получат новую реализацию; удалённые ID будут заменены воздухом. Этот этап сейчас не выполнен: изготовлена исходная галерея и протокол её обработки. Для конструкций больше одной ячейки может понадобиться внутренняя структура опорных коллизий; сохранение одного пользовательского ID не означает заранее готовый универсальный механизм больших коллизий.

Текстовые правки оформляйте отдельным UTF-8 документом, например:

```text
ID: 00025
Действие: заменить / удалить / конструкция / только текстовая правка
Название: ...
Вид BASE: ...
Вид ALT: ...
Коллизия и взаимодействия: ...
Особые замечания: ...
```

Верните полный ZIP отредактированного сохранения, неизменённый manifest и документ правок. Перед упаковкой выйдите из мира, чтобы все чанки сохранились. Сохраните исходную галерею: она нужна для отличия пользовательских изменений от служебных ячеек. Работа с самой галереей не требует менять исходный город; конвертер BBMC сейчас не является импортером ручных правок.
