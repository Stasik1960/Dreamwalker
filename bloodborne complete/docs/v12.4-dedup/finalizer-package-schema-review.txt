Finalizer/package schema review — 2026-10-12
==========================================
This is a tools review, not final artifact acceptance. No Java, Gradle, release
finalizer or packaging process was executed for this review.

Completed integration corrections
---------------------------------
The dedicated native save checker now emits productionJarSha256 as well as
afterProductionJarSha256, both derived from the actual candidate JAR bytes.
Both native outputs, both server profiles, their actual runtime output/logs,
the saved fixtures and the manifest must match that candidate.

The finalizer preserves the concrete native partial-chunk result through
nativePendingChunkOrdering, then nativePendingChunkProbeSelection, then the
bound dedicated proof's naturalPartialChunkProbe. It no longer replaces the
specific unobserved-cohort reason with a generic NOT_RUN.

Packaging now revalidates every acceptance evidence path/byte SHA before any
release directory is created. Project inputs and parent paths reject reparse
points. Docs/world enumeration rejects reparse directories before descending;
archive members are checked again, and ZIP contents are compared to source SHA.
Existing release directories still cannot be overwritten.

Criteria checked for consistency
--------------------------------
The finalizer requires successful combined build and GameTest XML, bound native
migration/reopen with exact mapping count, complete ordinary item interaction
coverage and ledger checks, the independent native save proof, complete client
image review, ordinary-server gallery reopen without QA addon, client gallery
open/save plus saved-state/disk geometry checks, resource dependencies, original
V12 catalogue and ID reservation preservation, and unchanged source references.
The report records physical input/FPS/account-auth checks as NOT_RUN and author
collision data as NOT_SUPPLIED_NOT_APPLIED. Native partial loading is its own
explicit status; server item PASS does not imply pixel acceptance.

Read-only AST parsing succeeded for finalize_v124_report.py,
package_v124_release.py and check_v124_native_save_evidence.py. Final acceptance
and archive generation remain the root agent's later artifact-bound stages.
