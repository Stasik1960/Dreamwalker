# Исправление новых форм ступеней после независимого review

В build2 обнаружен дефект производных форм. Генератор использовал объединение
физических коробок `exact_coalesce` для элементов видимой модели. У внутреннего
угла оно могло слить нижнюю проступь и верхнюю часть через Y=8. Затем на весь
такой элемент переносились faces и UV верхней части: нижняя половина получала
другой atlas patch, а отсутствовавшая внутренняя грань после переворота могла
оказаться отсутствующей внешней плоскостью.

Исправлена только генерация новых моделей. Видимые компоненты сохраняют
авторское разделение: широкая нижняя проступь, верхняя половина и необходимая
угловая четверть. Физические коробки продолжают объединяться отдельно и
сохраняют прежние два/три прямоугольника. Оригинальные модели и PNG не меняются.

При обрезке UV учитываются направление проекции каждой грани и авторский
поворот UV 0/90/180/270°. Добавленная четверть переносит уже существующий
авторский участок; обрезка вне исходного участка запрещена проверкой.
Когда новый верхний вариант требует плоскость, отсутствовавшую у исходного
напольного объекта, производная модель использует текстуру и UV его
авторской противоположной грани. Новые текстуры не рисуются.

Особенно существенно для 93004: в источнике закончен только нижний внутренний
угол. Его нижние угловые состояния продолжают использовать исходную модель.
Производные прямые, внешние и верхние состояния теперь имеют отдельные
проступи с теми же исходными материалами, без подмены нижнего слоя atlas-участком
верхнего. Верхние внутренние углы имеют полную внешнюю верхнюю плоскость.
У 93028 учитывается авторский поворот UV 270°; его десять состояний с накладками
сохраняют отдельную оригинальную геометрию декора и прежнюю простую физику.

Для окончательного клиента приоритетны верхние внутренние углы всех восьми
материалов, все новые формы 93004 и обычные/угловые/верхние накладки 93028.
Форма frozen BEFORE и новой AFTER может намеренно отличаться: это сравнение
с ближайшим авторским материалом, а не требование одинакового силуэта у
новой прямой формы и единственного исходного внутреннего угла.
Итоговый PASS давать после чтения BakedModel, просмотра необработанных native
PNG и отдельных проверок размещения/соседей/сохранения.
