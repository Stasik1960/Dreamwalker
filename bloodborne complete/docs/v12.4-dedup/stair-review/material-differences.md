# Функциональные лестницы и заметные различия материалов

48 прежних типов обычных ступеней сведены к 19 типам по внешнему виду. Два
вертикальных рунговых объекта 90586/90587 сведены к одному типу 90586 с высотой
одна/две клетки. Итого в этой части: 50 рабочих типов → 20, 30 номеров оставлены
только для совместимости. Полное соответствие 315 прежних состояний находится
в `functional-type-fragment.json`; общий объединённый план включает эту таблицу.

Внешние поверхности проверялись по разрешённым элементам моделей, UV и
фактическим пикселям текстур после одинакового положения. Сравнение охватывает
`actual-stair-models-*.png`, а независимый межматериальный поиск дополнительно
проверен по `global-material-review-00.png`/`-01.png`. Проверка конечного вида
нативным клиентом — отдельный этап; программный просмотр её не заменяет.

Небольшие накладки старого 90980 не являются отдельным типом: они сохранены
как состояние `trim=true` основного 93028. Составные площадки 90585 и 90603 не
являются рунговой приставной лестницей: у них есть длинный наклонный марш,
ступени и площадка, тогда как 90586 — вертикальная узкая рама для подъёма.
Декор с техническим именем `stairs`, но без настоящих проступей, проверяется
в общем плане декоративных объектов, а не превращается в обычные ступени.

Для новых обычных ступеней `rotation` задаёт направление, а существующий
`variant` кодирует половину и форму без избыточного произведения свойств:

| variant | Половина | Форма |
|---|---|---|
| 0 | нижняя | прямая |
| 1 | нижняя | внутренний левый угол |
| 2 | нижняя | внутренний правый угол |
| 3 | нижняя | внешний левый угол |
| 4 | нижняя | внешний правый угол |
| 5 | верхняя | прямая |
| 6 | верхняя | внутренний левый угол |
| 7 | верхняя | внутренний правый угол |
| 8 | верхняя | внешний левый угол |
| 9 | верхняя | внешний правый угол |

Старый диапазон регистрации `variant=0..15` сохранён для чтения прежних
палитр. Новые установки используют десять функциональных состояний. Углы
режима `connections=auto` обновляются по соседям. Прежняя статическая форма
сохранений получает `connections=manual`, чтобы изолированный старый угол не
превратился при загрузке в прямую ступень. Shift+ПКМ пустой рукой включает
для такого экземпляра автоматическое соединение. Основной предмет обычной
установки использует автоматическое соединение сразу.

У основного 93028 в режиме AUTO Shift+ПКМ пустой рукой переключает накладки
`trim=false/true`. Поэтому оба сохранённых вида доступны после установки
единственным обычным предметом. У прежнего MANUAL-экземпляра первое действие
включает AUTO, следующие переключают накладки. Настройки экземпляра, UUID,
полезная физика и форма соединения сохраняются.

Полезная физика каждого состояния состоит из двух/трёх прямоугольных коробок
для проступей и опоры. Видимая обводка совпадает с этой физикой. Небольшие
выступы после поворота обрезаются штатным правилом менее 0,5 блока отдельно
по каждой стороне. Авторские коллизии без предоставленного экспорта не
объявляются применёнными. Исходные объекты V12 не изменяются.
