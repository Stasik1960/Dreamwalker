# Галерея и будущие ручные правки

Галерея всего каталога сейчас **NOT_GENERATED**: самостоятельные объекты и реальные частоты ещё не закреплены; полный первый набор не принят. Платформы с выдуманными пятизначными ID не создаются. `GALLERY_MANIFEST.schema.json` фиксирует формат будущего результата.

Одна платформа соответствует одному пользовательскому ID, технические части отдельно не показываются. Площадь платформы и область правки вычисляются по объединённым bounds всех допустимых ориентаций, функциональных состояний и опор; между границами платформ оставляются два пустых блока. Метки ID находятся вне области образца и сохраняются после его удаления. Пол, таблички и опоры отмечаются как технические данные, а не новая геометрия объекта.

Определение соседства: два подтверждённых логических экземпляра одного dimension имеют граничащие по одной из шести граней исходные клетки. Каждая пара экземпляров даёт один голос паре типов; повторы через дополнительные helper-клетки не увеличивают вес. Совпадающая клетка двух независимых объектов учитывается отдельной метрикой пересечения, не превращает их в один тип. До распознавания принадлежности статистику carrier-клеток нельзя выдавать за соседство объектов.

Предлагаемый воспроизводимый алгоритм: сначала выбирается тип с максимальной суммой весов соседства; равенство решается stable_key. Следующий тип выбирается по максимальному весу связей с уже размещёнными. Его прямоугольник ставится в свободную точку ортогонального фронтира, минимизирующую сумму вес × расстояние центров до уже размещённых платформ, затем площадь общей оболочки, затем z/x. Прямоугольники расширяются на двухблочный зазор для проверки пересечений. Это практическая группировка; не гарантируется соседство всех сильных пар.

Полный скан всех **35 890** terrain chunks подтвердил занятые клетки Y **-64..319**. Исходная авторская геометрия в точке `[140,319,-510]` достигает Y **321** (`reports/HEIGHT_AUDIT.json`). В начальном скане высота 317 относилась только к явно перечисленным carrier-блокам. Стандартная верхняя допустимая клетка Overworld — 319: места над городом нет. При окончательной раскладке высота **только галерейной копии** будет рассчитана по полной верхней границе города, RP-объектам, максимальной высоте образцов и зоне правки, с округлением height до кратного 16. Основной мир не перемещается и не обрезается. В manifest сохраняются прежние и новые dimension_type/height, datapack SHA и причина отличий. Конкретный datapack не создаётся до закрепления каталога и проверки первого набора.

Базовая галерея сохраняется неизменённой в отдельном архиве. Для каждой платформы manifest хранит ID, имя, точный исходный образец/state/RNG, основной блок и владельцев частей, bounds области правки, технические клетки, опоры и SHA каталога/JAR/исходного мира. Дополнительные проверки ориентаций и BASE/ALT размещаются вне основных областей.

Правила будущего импорта, отдельного этапа после возврата карты:

- Удалённый образец означает удаление этого ID из мода и его экземпляров из карты; номер остаётся занятой исторической записью.
- Замена образца другим блоком создаёт новый объект с прежним ID.
- Конструкция из нескольких блоков внутри области платформы становится одним объектом с прежним ID, с визуалом и коллизиями всей конструкции.
- Текстовые изменения привязываются к ID; другие объекты не перенумеровываются.

Сейчас импорт правок и удаление объектов не запускаются. Неподдерживаемые блоки/NBT внутри будущей конструкции должны быть вынесены в адресный конфликт, а не превращены в воздух.
