# Хранение владельцев полной конвертации

Режим включается явно `CompositeLedger.enableSharding(world)` **до** установки первого модового владельца в новой копии исходного мира. Он сохраняется в метаданных мира. Уже существующие глобальные сохранения V12/V12.6, UUID, формат их `cells` и сетевой путь остаются прежними. Существующий непустой глобальный журнал намеренно нельзя переключить этим методом: автоматической миграции старых сохранений здесь нет.

В полном городе нельзя держать общий Java-словарь всех занятых ячеек и всех экземпляров во всех когда-либо посещённых чанках. Новая реализация хранит отдельные compressed NBT `data/bloodborne_dw_owner_shards/owners-X.Z.nbt`. В общей метадате остаются только ключи чанков. `PersistentStateManager` не получает отдельный PersistentState на каждый чанк и поэтому не удерживает посещённые чанки навсегда.

В памяти находятся журналы фактически загруженных чанков. На выгрузке и конце тика удаляются журнал, публикация геометрии и временные индексы миграции. Чтение выгруженного чанка для проверки — кратковременное чтение одного файла без публикации геометрии или помещения в кэш. Предохранитель допускает максимум 1024 одновременно удерживаемых журнала; это верхний предел, а не число постоянно выделенных записей. Геометрия на потоках освещения читается только из неизменяемого `CompositeShapeSnapshots`, без дискового IO.

Каждый файл использует словари владельцев, форм и типизированных данных корня. Ячейки ссылаются на словарь, а полное NBT экземпляра не повторяется для каждой занятой ячейки. При чтении ссылки разделяют один объект `Owner`, `BlockData` и `Footprint`. В корневом чанке отдельно хранится полная принадлежность всех ячеек объекта, в том числе из других чанков. Это позволяет будущей замене авторских коллизий знать точное сохранённое состояние BEFORE, даже если первым загрузился чанк вспомогательной части.

Сохранение сначала пишет compressed NBT во временный `.pending`, затем заменяет файл атомарно, где файловая система это допускает. Сброс вызывается перед обычным сохранением ServerWorld и при выгрузке чанка. Ошибки IO, отсутствующий индексированный файл, повторные координаты и повреждённая схема диагностируются и не трактуются как пустой мир. Это обычная модель сохранения Minecraft; отдельной транзакции, атомарной сразу для всех файлов и vanilla region, не заявляется.

Клиент получает только владельцев отслеживаемых им чанков: начальная синхронизация выполняется после настоящего vanilla `sendChunkDataPackets`, изменения посылаются через `PlayerLookup.tracking` каждого затронутого чанка. Глобальная рассылка при JOIN/смене мира для нового режима отключена. На клиентской выгрузке чанка освобождаются его ячейки и геометрия. Дополнительного растущего словаря «кто когда видел какой чанк» нет.

`shardMetrics()` сообщает фактическое число известных и удерживаемых журналов, ячеек, ссылок принадлежности, чтений/записей и разделённых объектов. Поля `typedPayloadBytesWithoutSharing` / `typedPayloadBytesWithSharing` измеряют точный размер массивов типизированного NBT, **не** полный Java heap или RSS игры. Цифры общего RAM города должны браться из отдельного измерения процесса, а не выводиться из этой метрики.

Нативные проверки в `ShardedLedgerV127GameTests`: запись/выгрузка/чтение через Minecraft NbtIo; helper-first чтение полной принадлежности; последовательность изменения/отката с сохранением чужого UUID; неизменяемая геометрия с рабочего потока без IO; 1000 реальных файлов выгруженных чанков без роста резидентных записей; 64 повторные типизированные нагрузки после словарного чтения с 64→1 разделяемым массивом; отдельная выборка владельцев каждого чанка; сохранность старого глобального формата. Статус запуска этих тестов фиксируется в итоговом отчёте родительского задания — этот документ не объявляет PASS без результата сервера.

В настоящем запуске **tests7 без WorldEdit** все четыре описанных нативных теста получили **PASS**: legacy-format/ошибочный индекс, словарное разделение payload,1000 transient disk-reads и flush/unload/helper-first/reload/откат. Имена, время и SHA256 XML сохранены в `storage-native-validation.json`. Проверка роста кэша измерила0 максимальных резидентных shard/cell при1000 прочитанных выгруженных чанках; проверка словаря подтвердила64→1 разделяемый массив типизированных данных. Общий запуск tests7 имел11 других ошибок, поэтому PASS этих случаев не подменяет итоговую проверку всех функций и отдельного WorldEdit.
