Dreamwalker BB V12.7 / Minecraft 1.20.1 / Fabric / Java 17

Итоговая проверенная версия определяется acceptance.json и SHA256SUMS.txt.
Файлы промежуточной сборки не являются готовым релизом без принятой проверки.

1. Используйте Minecraft 1.20.1, Java 17, Fabric Loader 0.16.10,
   Fabric API 0.92.9+1.20.1 и GeckoLib 4.4.9.
2. Замените прежний Dreamwalker/Bloodborne combined JAR новым
   dreamwalker-bb-fabric-1.20.1-0.1.0-v12.7-final.jar в mods.
   Не оставляйте одновременно старую и новую версии BB.
3. Исходный ресурспак и временные модули проверки/конвертации не требуются
   обычному клиенту или серверу. WorldEdit 7.2.15 — отдельная необязательная
   зависимость только для работы его командами с модовыми объектами.
4. Галерея в этом этапе не создавалась. Исходная полная карта не конвертирована.
   Готовый план и исходники позволяют выполнить это позже по отдельной команде
   владельца. Инструкция: HANDOFF-RU.md.

DW-барьер: ID 93230; DW-свет: ID 93231.
/bb alt all и /bb base all меняют вид объектов нашего мода по сохранённой карте.
/bb status показывает ход; /bb cancel завершает текущую работу.
/bb no-collide разрешает следующее размещение из предмета в основной руке
игнорируя чужую физику установки. Это разовый эффект экземпляра предмета;
перекладывание/выбрасывание/смена слота сбрасывает его. В физике игрока и
при последующих обычных установках разрешения на наслаивание нет.

Авторские коллизии Collision Studio не передавались и не применялись.
Для их последующего импорта нужен dreamwalker-collisions.json и точное
сопоставление registry ID/состояний по сохранённому контракту.

Для будущей полной конвертации автономный сервер подготавливается командой:
python tools/prepare_v127_server_bootstrap.py --output build/v127-server-bootstrap
Она скачивает только проверяемые официальные файлы Minecraft 1.20.1,
Fabric Loader 0.16.10 и server capsule 1.0.1; Java и мир не запускаются.
JAVA_HOME17 должен указывать на Java 17; JAVA_HOME используется как резерв.
Полная команда запуска находится в HANDOFF-RU.md и использует параметры
--server-bootstrap build/v127-server-bootstrap
--server-launcher build/v127-server-bootstrap/fabric-server-launch.jar
Сам полный импорт остаётся выключен до отдельной явной команды владельца.

Снятые из каталога авторские поверхности исходной карты сохраняются скрытой
совместимостью. Подходящая ваниль используется только для доказанно закрытых
непрозрачных кубов внутри строений; после разборки соседей она станет видимой.
Такие ванильные наполнители не управляются инструментом BB и его редактором.
ID 93232/93233 и скрытые зависимости включаются в новый Blockbench ZIP;
открытие через GUI Blockbench считается NOT_RUN без отдельной реальной проверки.
