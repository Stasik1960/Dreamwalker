# Кэши инструмента и ALT

Инструмент не обходит мир каждый тик в обычной игре. Радиусный выбор действует
только при явном действии; работа `all` запускается явно и обрабатывает один
существующий чанк и до16 целей за тик. Список чанков читается из заголовков файлов,
без большого массива всех ячеек карты. Память активной работы ограничена этим
списком, посещёнными UUID/ключами и текущими целями/временными билетами. После
завершения/отмены/остановки сервера работа и билеты удаляются.

Загруженные RP-объекты индексируются по UUID и чанку через ENTITY_LOAD/UNLOAD
и непосредственное изменение позиции. При просмотре следующего чанка не
производится повторный обход всех сущностей мира. Индекс содержит только
загруженные объекты, освобождает пустые чанки и не хранит сами Entity/World в
значениях. Нормальный цикл игры не имеет периодического полного сканирования.

Оболочки ALT моделей создаются по идентичности неизменяемых baked-моделей в рамках
одной перезагрузки ресурсов. Цветные vanilla quads теперь разделяются общей
IdentityMap внутри той же перезагрузки: один исходный неизменяемый BakedQuad
получает одну цветную копию для всех стен и их соединений. Ранее созданный новый
вариант оболочки мог повторять одинаковую цветную копию в каждом соединении.
Это подтверждённое дублирование устранено без изменения вершин, UV, спрайтов,
нормалей и исходных BASE quads. Кэш ограничен baked-данными загруженных моделей,
а не количеством установленных объектов или координат мира. При перезагрузке
ресурсов прежний набор заменяется.

RP-оттенок — один tracked boolean и один цвет, без новых текстур/мешей на
экземпляр. Новые составные объекты используют прежний renderer и исходные
базовые модели; ALT добавляет лишь множитель RGB, не копирует их геометрию
на каждую позицию.

Native QA записывает реальный `Runtime.totalMemory/freeMemory/maxMemory`, числа
оболочек/разделяемых цветных quads и клиентских снимков owner-геометрии после
запуска, до `all` и после завершения `all`. Это наблюдаемые значения JVM;
непринудительный GC и кэши Minecraft влияют на них. GameTest не объявляется
доказательством расхода клиентской памяти. Показатели повторного открытия
фиксируются отдельно при реальном запуске сохранённого тестового мира.
