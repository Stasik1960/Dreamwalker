# Инструмент и альтернативный вид — V12.7

Весь рабочий строительный каталог поддерживает основной и альтернативный вид:
исходная архитектура V12, новые составные блоки, размещаемые RP-объекты,
DW-барьер и DW-свет. Оружие, обычные предметы и существа не являются строительными
блоками и не получают бессмысленное состояние внешнего вида.

Пять режимов инструмента, перемещения, связи, команды и лимиты V12 сохраняются.
Инструмент выбирает только `bloodborne_dw` и `bloodborne_rp`. Ванильные блоки,
сущности и объекты других модов не являются допустимыми целями даже при передаче
поддельного объекта выбора на сервер.

| Команда | Действие |
| --- | --- |
| `/bb none` | Особое действие применяется к одному объекту; сбрасывает незавершённый выбор связки. |
| `/bb select 8` | Сохраняет прежнее поведение V12: ЛКМ в особом режиме переключает загруженные экземпляры того же ID в сфере радиуса 8 от игрока. |
| `/bb select all` | Следующий ЛКМ в особом режиме задаёт всем поддерживаемым объектам карты вид, противоположный виду выбранного объекта. Этот режим приоритетнее настройки ручного открывания и связок; `/bb none` возвращает обычные особые действия. |
| `/bb alt 8` | Задаёт ALT всем поддерживаемым типам в сфере радиуса 8; сохранённые незагруженные чанки области тоже обрабатываются. |
| `/bb base 8` | Возвращает BASE всем поддерживаемым типам в той же области. |
| `/bb alt all` | Задаёт ALT всем поддерживаемым объектам сохранённой карты во всех измерениях. |
| `/bb base all` | Возвращает BASE по всей сохранённой карте. |
| `/bb status` | Показывает ход работы, число изменённых объектов, отклонений и обработанных чанков. |
| `/bb cancel` | Прекращает текущую работу; уже выполненные изменения сохраняются. |

Для команд нужны прежние права строительства: Creative либо OP2, возможность
изменять мир и разрешение редактировать соответствующее место. Работа идёт
последовательно, без постоянного `/forceload`: сначала читаются заголовки
сохранённых регионов, затем по одному загружаются существующие чанки. За один тик
меняется не более 16 целей. Для составного объекта также загружается его занимаемая
геометрия. Временные билеты загрузки снимаются после обработки. Одновременно
выполняется одна общая работа; отмена или потеря прав прекращает её.

UUID, позиции, повороты, монтаж, настройки, связи, события и счётчики не
заменяются. Состояние меняется штатной транзакцией объекта. Защищённое место или
отклонённая транзакция учитывается в сообщении и журнале; такой объект не объявляется
изменённым. ALT не отменяет правила коллизий и не выдаёт разрешение на наложение.

Для авторских альтернатив используются имеющиеся модели в точности. Для новых
поз, у которых источник содержит только основной вид, добавлен явно созданный
исполнителем тёмный холодный оттенок: множители RGB `0.60 / 0.67 / 0.72`.
Прозрачность, исходные текстуры, UV, геометрия и физика сохраняются. Если хотя бы
одна часть позы имеет самостоятельную авторскую ALT-модель, вся авторская поза
остаётся без дополнительного оттенка, включая её неизменяемые части.

У исходных нативных оград и приставных лестниц V12 состояние ALT существовало,
но все его JSON были простыми родителями BASE без изменений. Теперь только
ALT получает такой же оттенок в клиентской оболочке модели; BASE и замороженные
файлы моделей/текстур остаются прежними. Это расширение альтернативного вида,
явно затребованное в финальном задании, а не исправление прежней физики V12.

Размещаемые RP-объекты используют дополнительный отслеживаемый boolean
`BbAltVisual`, сохраняемый как NBT BYTE лишь при ALT. В BASE новая запись
отсутствует. Старые типизированные selector редактора коллизий остаются прежними:
новый оттенок не меняет физику, анимации, клетки с собаками, рычаги или телепорты.
Копирование сохраняет выбранный внешний вид без новых физических привилегий.

Полная таблица поз: [ALT-COVERAGE.tsv](ALT-COVERAGE.tsv). Статический аудит:
[alternate-audit.json](alternate-audit.json). Наличие состояния в таблице
проверяется отдельно от игровых тестов и просмотра настоящих клиентских кадров;
статический PASS не заменяет проверку запуска, установки и синхронизации.
