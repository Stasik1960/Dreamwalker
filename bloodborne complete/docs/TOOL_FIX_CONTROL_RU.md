# Инструмент 90009: короткая памятка

Возьмите **90009 (`bloodborne_dw:composite_builder`) в основную руку**. Для изменения мира нужен Creative или разрешение оператора. Предмет в любой руке защищает от обычной поломки/удара. Для обычного использования двери или рычага и удаления объекта уберите инструмент из обеих рук.

| Управление по умолчанию | Результат |
|---|---|
| ЛКМ в «Выборе» | Закрепить конкретный экземпляр; его ID и операция показаны над хотбаром |
| Ctrl + колесо | Следующая/предыдущая доступная операция; слот хотбара не меняется |
| ЛКМ в операции | Один шаг для закреплённого объекта; повторно целиться в него не требуется |
| Shift + ЛКМ | Обратный поворот, спуск или предыдущая допустимая плоскость |
| Alt + колесо | Шаг высоты: 1/16, 1/8, 1/4, 1 блока |
| ПКМ | Настройки текущего UUID; открытие окна само по себе объект не меняет |
| Ctrl + Z | Отменить последнее поддерживаемое изменение; история ограничена 20 записями |
| X | Снять текущий выбор/источник; сохранённые связи остаются |
| Средняя кнопка мыши | Выбрать другой объект под прицелом; перекрывающиеся кандидаты перебираются по очереди |
| Esc в окне | Закрыть окно; при изменённом черновике сначала выбрать, что с ним делать |

Модификаторы, отмена и снятие выбора переназначаются в настройках управления Minecraft. ЛКМ, ПКМ и средняя кнопка следуют назначенным действиям Minecraft. Обычная прокрутка меняет слот; в открытом окне колесо прокручивает список. Чат и текстовые поля не выполняют операции мира. Подсказки показывают действующие назначения.

Первый клик без закреплённого объекта только выбирает его. Следующий выполняет действие. Смена поворота/высоты и открытие окна сохраняют выбор. При недоступном объекте инструмент сообщает отказ; выбрать другой можно средней кнопкой или после X.

Для простой связи выберите «Связать», нажмите рычаг и затем каждую из нужных дверей. Источник остаётся закреплённым; предварительная цель находится под прицелом. После настройки уберите инструмент и нажмите обычный ПКМ по рычагу: его авторская анимация передаёт импульс с задержкой **70 серверных тиков**. «Разорвать» удаляет выбранную связь. В окне «Связи» доступны составные правила, условия «Любой»/«Все» и действия; новый состав остаётся черновиком до «Сохранить».

Фонари связываются как источники и назначения; в «Телепортах» видны направления и линии. Для простого обратимого маршрута соедините исходный фонарь с каждым назначением. Пользуйтесь телепортом обычным взаимодействием без инструмента. Список маршрутов относится к выбранному фонарю; односторонние маршруты и другая обратная линия настраиваются отдельно.

В «Объекте» доступны только настоящие возможности типа: точная высота, три монтажные плоскости стекла, собака в клетке и положение открываемых архитектурных панелей. RP-двери/лестница/сундук меняют открытое состояние обычным взаимодействием без инструмента или рычагом. Скрытие собаки меняет один экземпляр клетки. Самостоятельные художественные исполнения выбираются своими предметами; сохранённый BASE/ALT без отличающейся графики не является видимой сменой оформления. Полный список — `TOOL_FIX_CAPABILITIES.md`.

«Только рычагами» запрещает ручное открытие конкретного экземпляра. События открытия/закрытия задаются в «Событиях», сохраняются обеими списками и требуют оператора уровня 4. Команды запускаются после успешного перехода один раз по порядку. Отмена инструмента не отменяет исполненные команды, игровые открытия, телепортацию или другие побочные действия; чужие изменения не откатываются.

В «Диагностике» (оператор уровня 2) запись выключена до явного запуска. Снимок/пометка подтверждаются сообщением; запись останавливается автоматически через 60 секунд или вручную. После экспорта чат показывает имя и путь отчёта. При игре на отдельном сервере серверный путь относится к серверу; локальный клиентский файл показывается отдельно. `/bb debug` осматривает фактический выбранный объект, `/bb diagnostics` сохраняется.

90008 выведен из предложения. Старый предмет в сохранённом инвентаре, сундуке или на земле читается как 90009 с совместимыми настройками; номер 90008 не присваивается другому типу.

Фактическая проверка управления и ограничений для выдаваемого JAR отмечена в `TOOL_FIX_TESTS.md` и отчёте проверки. Эта памятка не заменяет игровые доказательства.
