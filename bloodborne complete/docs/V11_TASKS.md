# Актуальные задачи V11.3

Первоначальные пользовательские правки сохранялись в V11: удалён редактор и
устранён дополнительный дефект изоляции 90012. Пользователь ответил на три запроса
проверки сообщениями о невозможности двигаться и застревании; последняя ручная
проверка V11.2 C285 не принята. Пользователь заменил требование 90006: убрать коллизию
только углового варианта, прямой вариант оставить. Подъём угловой лестницы больше
не требуется. V11.3 собрана: 42 GameTest и 21 core test прошли на SHA `6a45ab4f…`.
Проверки относятся к конкретному JAR, файлы выпуска V11.2 сохраняются отдельно.

Начальная синхронизация OPEN была подтверждённым дефектом V11.1. V11.2 задаёт
исходный OPEN через существующий native spawn packet и запускает переход только
после смены OPEN в целиком применённом metadata batch. Схема tracked data и NBT
не расширена. Повторный вход с сохранённой открытой дверью проверен настоящим
клиентом на финальном SHA. Повторный вход с исходно закрытой дверью и её первое
настоящее открытие через примерно 28 секунд также проверены. Действие в первые
две секунды эта серия не проверяла; дополнительный ранний сценарий не является
новым требованием пользовательской приёмки.

Все прежние задачи GUI90009, его клавиш, undo и записи диагностики закрыты удалением
соответствующего функционала; их проверки не переносить в новую приёмку.
