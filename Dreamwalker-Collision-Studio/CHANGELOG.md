# Обновление v3 / Model Packs 0.2.0

- Одни авторские OBB используются для движения игроков и запрета пересечения при установке блоков.
- Проверяются обе ячейки двери, кровати и высокого растения. Отказ не расходует предмет.
- Новые модели/сборки нельзя ставить поверх существующих блоков или других моделей с общими коллизиями.
- Смена варианта отклоняется при пересечении новых объёмов с блоками; существующие блоки не удаляются.
- Сидения остаются маркерами, а не дополнительными коллизиями. Физика мобов и предметов не меняется.
- Проект schemaVersion=2, policy.scope=players_and_blocks; игровой набор version=2, collisionScope=players_and_blocks.
- JSON v1 можно открыть и экспортировать заново. Игровые ZIP v1 читаются с прежним player-only поведением.
- Обновлены инструкция Codex, схема, руководства, архивы, исходники и проверки.

Пройдены: 187 основных браузерных проверок, импорт/экспорт, сборки, математические OBB-проверки и 3 GameTest сервера Minecraft. Сервер проверяет реальную установку BlockItem внутри/вне объёма, расход предметов, двойные блоки, обратное размещение моделей, свободный угол повёрнутого OBB, движение PlayerEntity и посадку.

Ограничения: /setblock, генерация мира, поршни и моды, обходящие BlockItem, требуют отдельных хуков. Уже размещённые блоки при обновлении не удаляются. Проверка обычной установки не равнозначна твёрдым world-block placeholders, механике редстоуна или опорам.
