DREAMWALKER MODEL PACKS 0.1.0 — FABRIC 1.20.1, JAVA 17

Этот отдельный мод добавляет размещаемые энтити-декорации из ZIP.
Работает рядом с Dreamwalker BB V10, не заменяет его встроенные блоки.
Исходный V10 для новых объектов не обязателен: текстуры уже внутри ZIP.

УСТАНОВКА
1. Сделайте резервную копию мира. Начните с отдельного тестового мира.
2. Установите Fabric Loader для Minecraft 1.20.1 и Fabric API 1.20.1.
3. Положите dreamwalker-modelpacks-0.1.0.jar в mods/ клиента и сервера.
4. В редакторе создайте коллизии/сидения или отметьте вариант завершённым.
   Для соединения моделей используйте «＋ Сборка», сохраните одним объектом.
5. Нажмите «Архив для игры», задайте постоянный ID набора латиницей.
6. Положите полученный ZIP целиком в config/dreamwalker_modelpacks/packs/.
   Папку можно создать вручную, либо она создастся при запуске мода.
   На сервере и ВСЕХ клиентах должны быть одинаковые наборы ZIP.
7. Перезапустите игру и сервер. Новые модели появятся в творческой
   вкладке «Dreamwalker · импортированные модели».

Предметы имеют общий значок булыжника и собственные названия.
ПКМ по поверхности ставит объект целиком в точке клика.
Поворот вокруг Y при размещении округляется до 45 градусов.
ПКМ по поверхности жёлтого маркера садит игрока на свободное место.
Несколько маркеров = несколько независимых мест для разных игроков.
Shift — встать; Shift+ПКМ по объекту — переключить вариант.
Смена варианта освобождает места. Удар игрока удаляет объект;
в выживании выпадает его предмет, в творческом режиме — нет.
Команды для оператора:
  /dwmodels list
  /dwmodels give <игрок> "<ID из list>"

ОБНОВЛЕНИЕ НАБОРОВ
Сохраняйте ID набора и ID объектов. Замените прежний ZIP новым,
а не кладите обе версии одновременно: повторяющиеся ID запрещены.
Перезапустите сервер и клиенты. Изменения загрузятся также у уже
поставленных объектов. Не удаляйте наборы, используемые в мире.
При отсутствии определения объект не отрисовывается, но его ID
сохраняется в NBT. Возврат того же набора восстановит определение.
Несовпадение наборов блокирует вход на сервер, а не синхронизирует ZIP.
Ошибочный набор останавливает загрузку: смотрите latest.log.

ФОРМАТ ZIP
pack.json: schema=dreamwalker.model-pack, version=1, id, name, objects.
objects: id, name, states. states: key, name, quads, bounds, colliders, seats.
quads: texture (путь PNG), vertices (4 XYZ), uv (4 UV), normal (XYZ).
bounds: minXYZ,maxXYZ; colliders: center,size,rotation; seats: id,center,rotation.
Координаты уже в блоках Minecraft (редактор делит на 16 и один раз
применяет scale оригинала). rotation — градусы Euler ZYX.
center сидения — центр ВЕРХНЕЙ поверхности маркера; не центр его объёма.
studio.json — резервная копия проекта для импорта в редактор.
Несколько частей сборки запекаются в один набор граней одного объекта.

ГРАНИЦЫ РЕАЛИЗАЦИИ
Это энтити-объекты, не блоки сетки. Обычные блоки можно устанавливать
внутри авторских коллизий; коллизии ограничивают только PlayerEntity,
а не мобов, выпавшие предметы или размещение блоков. OBB сохраняют
произвольный поворот; осевой bbox используется только для поиска.
Автоматическое перешагивание не реализовано — используйте прыжок.
Позы статичные, смена вариантов мгновенная: этот загрузчик не
воспроизводит исходные GeckoLib-анимации, Molang и звуки. Для них
потребуется отдельное развитие загрузчика; исходники моделей сохранены
в ранее выданном Blockbench-архиве. Никакой механики редстоуна/воды
или ванильных блоковых опор здесь нет.

ПРОВЕРКИ
Сборка JAR и 5 математических проверок OBB; браузерные тесты редактора,
импорта/экспорта, сборок; GameTest в настоящем сервере Minecraft.
Отчёт сервера приложен. Это не замена визуальному тесту в вашей сборке:
проверьте отображение, высоту посадки и нескольких реальных клиентов.
DEMO-test_pack.zip — технический стул с грубой кубической коллизией,
не готовая авторская разметка мебели. Устанавливать демо необязательно.

ИСХОДНИКИ
source.zip: Gradle-проект, исходники и тесты. Для сборки нужны Java 17
и интернет. Распакуйте, запустите gradlew.bat build. runGametest требует
положить DEMO-test_pack.zip в build/gametest/config/dreamwalker_modelpacks/packs/.
