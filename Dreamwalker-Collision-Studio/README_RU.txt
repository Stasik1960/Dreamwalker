DREAMWALKER BB FABRIC V10 — МОДЕЛИ И РЕДАКТОР КОЛЛИЗИЙ

Редактор: распакуйте весь архив в одну папку и запустите START.bat
или откройте index.html в Chrome / Edge / Firefox на ПК.
Установка Node, Python, Java и доступ в интернет не требуются.
Все библиотеки и встроенные модели поставляются локально.

Выберите модель слева и её вариант сверху. Открытое/закрытое,
BASE/ALT, материалы и соединения оград имеют отдельную разметку.
Ограды: цифры в варианте = север/восток/юг/запад;
0 — отсутствует, 1 — низкая, 2 — высокая сторона.
Обычные мировые повороты экземпляра применит код мода.

Зелёный прямоугольник — коллизия только для движения игроков.
Добавьте его, измените положение, размер и поворот по 3 осям.
Жёлтый прямоугольник — место посадки одного игрока на ПКМ.
Его размер фиксирован, перемещение и поворот доступны.
Верхняя поверхность жёлтого маркера обозначает поверхность сидения.
В сцене и полях: 16 единиц = 1 блок. Модели RP показаны до их
runtime scale; код применит scale экземпляра один раз.

W — перемещение, E — поворот, R — размер, F — вписать сцену.
ЛКМ — выбрать маркер; перетаскивайте оси/плоскости манипулятора.
Зажать ЛКМ на свободном месте — вращать камеру.
Зажать ПКМ — панорама. Колесо — масштаб камеры.
Ctrl+Z / Ctrl+Y — отмена и повтор в текущем состоянии.
Delete — удалить маркер. Координаты можно вводить справа.
У сидений локальная стрелка -Z обозначает направление взгляда.

Проверьте анимацию ползунком. Для дополнительной авторской позы
используйте «Сохранить позу как вариант». Такая новая поза требует
сопоставления с игровым состоянием; редактор не создаёт механику.
Исходные анимации сохранены полностью. Встроенный preview поддерживает
числовые линейные ключи и простые выражения Molang; сложные контроллеры
и эффекты GeckoLib не исполняются. Сохранённые original JSON являются
авторитетным источником анимации, bbmodel — удобной рабочей копией.

«Сохранить JSON» — переносимый проект, включая загруженные модели.
«Готово · пакет для Codex» — ZIP с JSON, схемой и подробным заданием
для внедрения авторских коллизий в мод. Загрузите этот ZIP в Codex.
Незатронутые состояния не меняются. Завершённое пустое состояние
явно требует убрать его коллизии/сидения для игроков.
Автосохранение зависит от браузера/пути файла. Держите резервный JSON.

Импорт: .bbmodel с кубами и embedded PNG; Bedrock/GeckoLib .geo.json
с PNG и .animation.json; Minecraft Java JSON с родителями и PNG.
Выберите связанные файлы вместе или ZIP. Полигональные mesh-элементы
в .bbmodel не поддерживаются: используйте кубические модели.
Идентификатор импортированной модели нужно сопоставить с registry ID
мода при внедрении. Выбор PNG для Bedrock: одноимённая текстура либо
первая PNG в комплекте; для многотекстурного набора лучше .bbmodel.

BLOCKBENCH:
В архиве моделей откройте models/*.bbmodel. Текстуры встроены.
RP модели содержат именованные группы и копии анимаций. Для точной
работы GeckoLib установите GeckoLib Animation Utils в Blockbench,
откройте original/assets/bloodborne_rp/geo/*.geo.json, добавьте
соответствующую PNG и импортируйте animation.json из catalog.json.
Оригиналы не изменены. bbmodel имеют формат Free Model, чтобы хранить
все повороты/составные модели без лимитов Java block model.
Архитектура: составные объекты выгружены в собранном виде для BASE/ALT
и разных поз. Ограды представлены всеми авторскими примитивами;
в редакторе эти примитивы собираются во все 644 непустых
варианты каждого типа ограды. Оригинальные ресурсы и catalog.json
содержат полный состав вариантов. NPC и оружие исключены.
Клетки с встроенными собаками сохранены; npc_window и lamp_npc —
размещаемые декорации, а не NPC. Семь старых furniture ID являются
алиасами: файлы сохранены, редактор работает с каноническим объектом.

В собственных звуках отобранных объектов обнаружен Hunterlamp.
Его OGG и sounds.json приложены. Остальные выбранные объекты не имеют
привязанных собственных звуков в исходном V10; NPC звуки исключены.
Синтетические звуки или анимации для статичных объектов не создавались.

НОВОЕ В РЕДАКТОРЕ V2:
Булыжник 1×1×1 внизу сцены — эталон размера одного блока Minecraft.
Его можно скрыть галочкой и переместить полем X. Он не экспортируется.

«＋ Сборка»: добавьте несколько моделей с нужными вариантами, задайте
положение XYZ, поворот XYZ и общий масштаб каждой части. Сохраните
одним объектом. Размечайте коллизии и сидения уже у всей сборки.
В инспекторе можно выбрать часть и двигать/вращать/масштабировать её
манипулятором. Размер частей меняется равномерно, чтобы не искажать
модель; у коллизий размеры по каждой оси по-прежнему независимы.
«Редактировать части сборки» позволяет добавлять/удалять части.
После изменения частей проверьте старые коллизии и сидения: они
НЕ перемещаются вместе с частями автоматически. Сборки сохраняются
в JSON и автосохранении; можно использовать сборку внутри другой сборки.
Части фиксируются в выбранной статической позе, без живой анимации.

ДВА РАЗНЫХ ЭКСПОРТА:
1. «Готово · пакет для Codex» — заменить коллизии существующих моделей
   в исходном коде V10, согласно APPLY_IN_CODEX_RU.md.
2. «Архив для игры» — добавить НОВЫЕ размещаемые объекты, в том числе
   сборки, через отдельный мод Dreamwalker Model Packs (Fabric 1.20.1).
   В экспорт включаются размеченные или отмеченные завершёнными варианты.
   Укажите постоянный ID набора латиницей. Сохраняйте его при обновлениях.
   У каждой модели будет один предмет, а несколько её вариантов будут
   переключаться в игре. Сборка размещается целиком одним объектом.

Установите JAR из отдельного архива загрузчика и Fabric API в mods/
на клиенте и сервере. Экспортированный ZIP, НЕ распаковывая, положите
в config/dreamwalker_modelpacks/packs/ на клиенте и сервере.
Папка создаётся при первом запуске загрузчика; перезапустите игру/сервер.
Содержимое наборов должно совпадать у всех участников.
Предметы находятся в творческой вкладке импортированных моделей.
ПКМ по поверхности — поставить; ПКМ по сидению — сесть;
Shift — встать; Shift+ПКМ по объекту — следующий вариант;
удар игрока — убрать объект. /dwmodels list показывает ID,
/dwmodels give <игрок> "<ID>" выдаёт предмет (требуются права оператора).

Это энтити-декорации, а не обычные блоки сетки Minecraft: можно совмещать
с обычными блоками, но нет стандартной механики редстоуна/воды/опор.
Авторские коллизии применяются только к движению игроков; произвольные
повороты поддерживаются через OBB, а не увеличенную осевую оболочку.
Каждое место сидения рассчитано на одного игрока, независимо от других.
Новые наборы используют статичные позы и мгновенное переключение
вариантов: исходные анимации/звуки не проигрываются этим загрузчиком.
Автоматическое перешагивание на новые коллизии не реализовано: прыгайте.
Старые встроенные объекты V10 и их механика остаются без изменений.
Не удаляйте используемые миром наборы и не меняйте их ID; отсутствующие
объекты не отрисуются, но идентификаторы сохраняются в NBT мира.
Перед обновлениями загрузчика и наборов сделайте резервную копию мира.
Проверки сборки, браузера и тестового сервера приложены; визуальная
посадка и одновременная игра нескольких реальных клиентов требуют
проверки в вашем игровом окружении. Сначала используйте тестовый мир.
