# Dreamwalker Collision Studio V22

Распакуйте архив целиком и откройте `index.html` в настольном браузере. Выберите модель по её названию или числовому ID. В списке над сценой можно менять геометрический вариант и выбирать закрытую или открытую позу. Модель показывается в Original. Разметка состояния применяется к Original и ALT.

- Фиолетовый прямоугольник описывает коллизию игрока. Синий описывает место, которое модель резервирует при строительстве. Красный задаёт обводку для выбора. Жёлтый задаёт сидение. Стрелка показывает направление взгляда при посадке. Размер сидения фиксирован.
- Выберите прямоугольник в сцене или в списке. W переключает перемещение, E переключает поворот, R показывает стрелки шести граней, F вписывает сцену. При перетаскивании стрелки размера противоположная грань остаётся на месте. Для повёрнутого прямоугольника стрелки идут по его локальным осям.
- Раскройте «Настройки выбранной разметки» для числового ввода. Кнопка «Подогнать под сетку Minecraft» срезает выступы меньше половины клетки внутрь. При выступе в половину клетки или больше грань остаётся на месте. Если обе грани сходятся на одной границе, сохраняется более длинная часть объёма. При равных частях сохраняется часть в положительном направлении оси. Срез допустим при ненулевой оставшейся толщине. У повёрнутого прямоугольника подгоняются грани, параллельные плоскостям сетки.
- Для сдвига самой модели выберите «Модель» над сценой и потяните стрелку X, Y или Z. Шаг задаётся полем «Привязка». Точное смещение можно ввести в разделе «Смещение модели». Смещение сохраняется для текущего варианта, а разметка редактируется отдельно.
- «Опорная клетка» показывает золотой куб в месте установки. Перетаскивайте его стрелками по одному блоку или введите целые координаты в панели. Клетка общая для всех вариантов модели. Геометрия и разметка при этом остаются на своих местах в сцене.
- В разделе «Блоки-ориентиры» добавьте столько кубов, сколько нужно. Переключите выбор над сценой на «Ориентиры» и кликните по нужному кубу. Его можно также выбрать в списке. Стрелки и кнопки X, Y, Z перемещают его на одну ячейку Minecraft за шаг. Ориентиры видны только в текущей сцене.
- Синяя звёздочка отмечает модель, в которой уже применена разметка из предыдущего архива. Новые правки окрашивают звёздочку в красный. «Не применять изменения» исключает все варианты этой модели из пакета для Codex и окрашивает звёздочку в жёлтый. Рабочий JSON сохраняет правки вместе с отметкой исключения.
- «Готово · пакет для Codex» включает изменённые варианты моделей, у которых снята галочка исключения. Приложите полученный ZIP к чату, чтобы перенести правки в исходники.
- «Сохранить JSON» создаёт рабочий файл. «Открыть проект» объединяет его с текущими правками. При конфликте выберите «Оставить текущую» или «Заменить из JSON» для каждого варианта и нажмите «Применить выбранное». Правки без конфликтов загрузятся вместе с выбранными. Кнопка «Отмена» отменяет всю загрузку.
- Звёздочка в списке «Вариант» отмечает разметку или смещение модели, которые отличаются от исходных. При открытии модели с такими правками первым показывается изменённый вариант.
- «Копировать разметку…» заменяет коллизии, обводку и сиденья в выбранной модели и варианте. Положение копируется в тех же координатах. При переносе между моделями используются смещение и опорная клетка получателя. Ctrl+Z отменяет копирование.
- Delete удаляет выбранную разметку или ориентир. Ctrl+Z отменяет последнее действие, Ctrl+Y повторяет его. История правок общая для вариантов и режимов в текущем сеансе.

В `catalogue.json` перечислены модели и состояния, включая 90841 и декорации RP v12. Геометрия композитных блоков берётся из JAR релиза и подготовленных файлов правок. Для RP используются исходная геометрия из V4 и геометрия новых объектов и клипы из JAR релиза. Базовая разметка включает коллизии, обводку, сиденья, сдвиги модели и опорные клетки из применённого проекта. В JSON и пакете для Codex сохраняются отличия от этой разметки. Загрузка ранее применённого архива оставляет текущие правки на месте.

У 90007 широкая поза выбирается в верхнем списке «Вариант 1 · открыто». Створки в предпросмотре поворачиваются вокруг петель с тем же знаком угла, что в игре. Рабочие JSON из предыдущего редактора этого каталога открываются с прежними координатами разметки.

Закрытый предпросмотр 90266 собран из полноразмерных деталей врат с закрытыми створками.

Чтобы перенести работу из предыдущего V22, сохраните её там в JSON и откройте в новой версии. Если в старом файле одно состояние имеет разные правки Original и ALT, редактор покажет конфликт. Сохраните нужный вариант отдельно в старой версии перед переносом.

Правки удалённого окна 90952 из рабочего JSON или ZIP автоматически переходят на 93241. Первый вариант переносится в закрытую позу, второй в открытую. Если в файле есть разметка самого 93241, она имеет приоритет для совпавшей позы.

## Сборка редактора

Запустите Python 3.11 или новее. Параметр `--vanilla` принимает клиентский JAR Minecraft 1.20.1. Исходный архив V4 берётся из соседнего каталога и проверяется по SHA‑256.

```text
python build_studio.py --jar DreamWalker-v22-Bloodborne-Collisions.jar --vanilla minecraft-1.20.1.jar --output Dreamwalker-Collision-Studio-V22.zip
```

До выпуска нового игрового JAR можно передать каталог подготовленных файлов правок через `--resources`. SHA‑256 этих файлов записывается вместе с идентификатором базового JAR.
