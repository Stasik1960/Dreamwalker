# Dreamwalker Collision Studio V22

Распакуйте архив целиком и откройте `index.html` в настольном браузере. Выберите модель по её названию или числовому ID. В раскрывающемся списке над сценой выберите BASE, ALT или открытую позу двери, ворот либо ставней.

- Фиолетовый прямоугольник описывает коллизию игрока. Синий описывает место, которое модель резервирует при строительстве. Красный задаёт обводку для выбора. Жёлтый задаёт сидение. Стрелка показывает направление взгляда при посадке. Размер сидения фиксирован.
- Выберите прямоугольник и перетащите его стрелками или введите координаты справа. W переключает перемещение, E переключает поворот, R переключает размер, F вписывает сцену.
- В разделе «Модель и ориентиры» задайте смещение модели относительно сетки из блоков. При смещении модели прямоугольники можно перенастроить отдельно. Для оценки стен и потолков добавьте фантомные блоки, указав координаты их ячеек X, Y, Z. Они видны только в редакторе.
- Отметьте готовые варианты и нажмите «Готово · пакет для Codex». Приложите полученный ZIP к чату, чтобы перенести правки в исходники. «Сохранить JSON» создаёт файл для продолжения работы в редакторе.

В архиве `catalogue.json` перечислены включённые модели и варианты. Геометрия композитных блоков берётся из JAR релиза. Для RP используются исходная геометрия из V4 и клипы из JAR релиза. Текущие физические объёмы в сцене соответствуют базовой ориентации модели. У моделей без физических объёмов списки пусты.

## Сборка редактора

Запустите Python 3.11 или новее. Параметр `--vanilla` принимает клиентский JAR Minecraft 1.20.1. Исходный архив V4 берётся из соседнего каталога и проверяется по SHA‑256.

```text
python build_studio.py --jar DreamWalker-v22-Bloodborne-Builder.jar --vanilla minecraft-1.20.1.jar --output Dreamwalker-Collision-Studio-V22.zip
```
