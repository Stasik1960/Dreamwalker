# Перенос разметки из Collision Studio V22

В ZIP лежит `dreamwalker-collisions.json` со схемой версии 4 и SHA‑256 JAR, из которого получен каталог. Сверьте SHA‑256, затем сопоставьте `registryId`, `states[].key` и `selector` с соответствующей ревизией исходников. Для моделей и состояний, которых нет в файле, сохраняйте прежнюю разметку.

Поле `source.appliedLayoutsSha256` указывает на применённый проект в `bloodborne_dw/studio-layouts-v22.json`. Проверьте его SHA‑256. Объедините новый пакет с этим проектом по модели и состоянию. При наличии `anchorCell` замените опорную клетку целиком. Явное значение `[0, 0, 0]` возвращает клетку в исходную позицию.

В этом каталоге `policy.profileScope = "all"`. Один селектор состояния без `profile` задаёт одинаковые коллизии, обводку, сиденья и смещение для Original и ALT. Раздельные открытые и закрытые позы и геометрические варианты сохраняются. Если присутствует `source.modelPatchSha256`, каталог подготовлен поверх указанного JAR с локальными правками модели. Сверьте ревизию этих правок перед переносом.

Проверьте файл командой `python check_export.py dreamwalker-collisions.zip Dreamwalker-Collision-Studio-V22.zip`.

Единица измерения равна 1/16 блока Minecraft. Порядок поворотов ZYX. X направлена вправо, Y вверх, Z на юг. X у моделей GeckoLib уже зеркально отражена. Положение прямоугольника — его центр, размеры — полные длины сторон. Положение сидения — центр его верхней плоскости. Направление взгляда — вектор `front`, повёрнутый на углы сидения.

- `players` участвует только в коллизии игрока.
- `blocks` участвует только в проверке установки блоков.
- `outline` участвует только в выборе, копировании и удалении.
- `both` сохраняет совместимость со старыми проектами и включает две коллизии.
- `modelOffset` описывает смещение модели от точки установки.
- `anchorCell` — смещение опорной клетки модели от исходной в целых блоках по X, Y и Z. Оно общее для всех вариантов и оформлений. Модель со сдвинутой клеткой может идти с пустым списком `states`.
- `seats` описывает места для одного игрока, которые занимают ПКМ и освобождают клавишей приседания.

В JSON все позиции заданы в исходной системе редактора. К координатам вершин модели прибавьте `modelOffset`, затем вычтите `16 × anchorCell`. Из `center` коллизий и обводки, а также из `surfaceCenter` сидений вычтите только `16 × anchorCell`. Размеры и углы разметки при этом сохраняются. Эти вычисления выполняются перед поворотом или монтажом блока. Для пропущенных в JSON вариантов используйте их исходные данные с тем же переносом опоры. Корневой блок размещается в выбранной игроком клетке. Пересчитайте вспомогательные клетки и проверки размещения в новой системе координат.

Если переносится разметка 90266, сверяйте закрытую геометрию с предпросмотром. Редактор использует полноразмерные детали открытой позы, возвращая створки в закрытое положение.

Пакет для Codex содержит изменённые состояния моделей, включённых пользователем. Пустые списки в явно экспортированном состоянии снимают соответствующую разметку. Если получен рабочий JSON, исключения на уровне моделей указаны в `editor.excludedModels`. Изменения применяйте к новым экземплярам. У старых экземпляров сохраните геометрию, положение и состояние. Не конвертируйте мир массовой операцией. Проверьте открытые и закрытые состояния, повороты, соседние блоки, несколько игроков на разных сидениях и повторное открытие копии мира.
