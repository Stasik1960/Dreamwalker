# Dreamwalker Collision Studio · V10

Офлайн-редактор общих коллизий игроков И установки блоков, а также сидений для моделей Dreamwalker BB Fabric V10.
Встроены 87 объектов; NPC и неразмещаемые предметы исключены.

## Скачать

- [Редактор v4 со встроенными моделями](Dreamwalker-V10-Collision-Studio-v4.zip) — распакуйте весь архив и запустите `START.bat` или откройте `index.html` на ПК.
- [Модели для Blockbench с текстурами, анимациями и выбранными звуками](Dreamwalker-V10-Blockbench-Models.zip).
- [Dreamwalker Model Packs для Fabric 1.20.1](Dreamwalker-ModelPacks-Fabric-1.20.1.zip) — JAR загрузчика, исходники, инструкция и необязательный технический пример.

При просмотре ZIP на GitHub используйте кнопку скачивания / **View raw**.

## Возможности редактора

- Три режима для каждого объёма: **игроки и блоки** (зелёный), **только блоки** (синий, игрок проходит), **только игроки** (фиолетовый, блоки можно ставить внутри). Режимы можно смешивать в одной модели. Перемещение, поворот и независимый размер по XYZ; разметка отдельно для каждого варианта.
- Сидения: фиксированный размер, перемещение и поворот; несколько мест для разных игроков.
- Сборки: несколько разных моделей объединяются одним объектом. Части можно двигать, вращать и равномерно масштабировать.
- Скрываемый булыжник 1×1×1 для сравнения размеров.
- Импорт кубических Blockbench, Bedrock/GeckoLib и Minecraft Java моделей; сохранение и повторное открытие проектов.

## Два варианта экспорта

**«Готово · пакет для Codex»** создаёт ZIP с разметкой и заданием для замены коллизий существующих объектов V10 в исходном коде. Незатронутые состояния остаются без изменений. См. [инструкцию внедрения](APPLY_IN_CODEX_RU.md).

**«Архив для игры»** создаёт набор новых размещаемых объектов для отдельного загрузчика Model Packs. Установите его JAR и Fabric API для Minecraft 1.20.1 в `mods/` клиента и сервера. Положите одинаковый экспортированный ZIP, не распаковывая, в `config/dreamwalker_modelpacks/packs/` на сервере и всех клиентах. Затем перезапустите их. Предметы появятся в творческой вкладке импортированных моделей.

ПКМ по поверхности ставит объект; ПКМ по сидению садит игрока; Shift позволяет встать; Shift+ПКМ переключает вариант; удар игрока убирает объект. При обновлении набора сохраняйте его ID и заменяйте старый архив, не устанавливайте обе версии одновременно.

## Ограничения и проверки

Новые объекты — энтити-декорации, а не обычные блоки сетки Minecraft. В зависимости от режима коллизии ограничивают движение игроков и/или установку обычных BlockItem, дверей, кроватей и высоких цветов. Модели нельзя размещать поверх блоков/других новых моделей; касание границ допустимо. Сидения не резервируют объём. Команды /setblock, поршни, worldgen и сторонние инструменты, напрямую меняющие мир, не перехватываются; для встроенного строительного инструмента V10 предусмотрена инструкция внедрения в пакете Codex. Позы статичные, переключение вариантов мгновенное; исходные анимации и звуки загрузчик не проигрывает. Автоматическое перешагивание не реализовано — используйте прыжок.

Обновление: замените старый JAR на `dreamwalker-modelpacks-0.3.0.jar` на клиенте и сервере. Старые проекты JSON v1 открываются в v4; При импорте старых JSON v1 объёмы получают players, v2 — both. Выберите режимы и экспортируйте заново. Старые игровые ZIP version=1 сохраняют прежние коллизии только игроков: переэкспортируйте их, сохранив ID набора, и замените старые ZIP новыми. Редактор v2 оставлен как историческая версия, он экспортирует только player collision.

Пройдены 187 основных браузерных проверок, проверки импорта/экспорта и сборок, 5 математических проверок OBB и 4 серверных GameTest, включая движение PlayerEntity и занятие сидения. Визуальную посадку, отображение и нескольких реальных клиентов сначала проверьте в отдельном тестовом мире. Перед обновлениями сделайте резервную копию мира.

Подробности: [руководство редактора](README_RU.txt), [руководство загрузчика](LOADER_README_RU.txt), [контрольные суммы архивов](SHA256SUMS.txt).
