# Night Shift Skate

Готический скейтбординг для **Minecraft 1.20.1 / Fabric**. В версии 0.7.2 есть три самостоятельные доски с 3D-моделями в руке, на земле и во время езды: Night Shift, викторианская Iron Vespers и Grave Procession в форме гробовой плиты.

Скейт собирается из трёх сменных частей: деки, подвесок и колёс. Детали можно комбинировать на скейт-верстаке. У каждой детали свои характеристики, которые меняют разгон, максимальную скорость, поворот, высоту прыжка, накат и устойчивость на перилах.

## Установка

Скачайте [Night Shift Skate 0.7.2](../releases/Night-Shift-Skate/night-shift-skate-0.7.2.jar) и положите JAR в папку `mods`. Нужны Java 17, Fabric Loader 0.16.10 или новее и Fabric API для Minecraft 1.20.1. В сетевой игре мод нужен и серверу, и всем игрокам.

Доски можно найти в творческом инвентаре по названию или изготовить в выживании. Iron Vespers и Grave Procession крафтятся из обычной доски Night Shift с дополнительными материалами.

Для строительства скейт-парка доступны пологие и крутые рампы, кованые перила, готический парапет, покрытие и плита парка Ярнама.

## Управление

| Кнопки по умолчанию | Действие |
| --- | --- |
| ПКМ с доской в руке | Поставить её на землю |
| ПКМ по доске | Встать на неё |
| Shift + ПКМ по доске | Поднять доску с земли или сойти с неё |
| W / S | Ускориться / затормозить |
| A / D | Повернуть, а на перилах — поправить баланс |
| Зажать и отпустить пробел | Олли; дольше держите для более высокого прыжка |
| R | Трюк, выбранный текущей комбинацией |
| G | Грэб или мэнуал |
| H | Открыть или скрыть справку по комбинациям |

По умолчанию R, G и H можно переназначить в меню управления Minecraft. Доступны поп-шовит, кикфлип, хилфлип, шовит 360, вэриал-кикфлип, тре-флип, инди, мелон, ноузгрэб, тейлгрэб, мэнуал, ноуз-мэнуал, бордслайд и воллрайд.

Выполняйте трюки в прыжке и приземляйтесь после полного оборота доски. Для бордслайда запрыгните на линию из железных прутьев: доска развернётся поперёк перил и будет набирать скорость. Поправляйте баланс короткими нажатиями A/D и нажмите пробел, чтобы спрыгнуть. При потере баланса игрок получает 2 единицы урона.

Трюки и скольжение прибавляют очки к комбо. Панель по центру экрана показывает общий счёт, комбо и таймер. При остановке или через пять секунд без новых очков результат засчитывается и появляется ранг от C до SS. Во время трюка в центре появляется его английское название и награда.

## Сборка

Укажите JDK 17 в `JAVA_HOME`. Из этой папки запустите `./gradlew build` (Linux/macOS) или `.\gradlew.bat build` (Windows). Готовый игровой JAR появится в `build/libs/`. Текущая версия проекта — `0.7.2`.

Исходники двух готических досок, рисунок деки и каталог новых деталей `night_shift_gothic_parts.blend` лежат в `artwork/`. Игровые меши и текстуры уже включены в `src/main/resources/`, поэтому Blender для обычной сборки не нужен. Чтобы экспортировать две исходные доски или сгенерировать меши новых деталей в Blender 4.5, запустите нужную команду из папки мода:

```sh
blender --background --factory-startup --python tools/export_bloodborne_boards.py
blender --background --factory-startup --python tools/generate_modular_parts.py
```
