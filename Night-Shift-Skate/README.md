# Night Shift Skate

Скейтборды для **Minecraft 1.20.1 / Fabric**. В версии 0.3.0 доступны три доски: Night Shift, викторианская Iron Vespers и Grave Procession в форме гробовой плиты. Все три отображаются в 3D в руке и на земле.

## Установка

Скачайте [Night Shift Skate 0.3.0](../releases/Night-Shift-Skate/night-shift-skate-0.3.0.jar) и положите JAR в папку `mods`. Нужны Java 17, Fabric Loader 0.16.10 или новее и Fabric API для Minecraft 1.20.1. В сетевой игре мод нужен и серверу, и всем игрокам.

Доски можно найти в творческом инвентаре по названию или изготовить в выживании. Iron Vespers и Grave Procession крафтятся из обычной доски Night Shift с дополнительными материалами.

## Управление

| Кнопки по умолчанию | Действие |
| --- | --- |
| ПКМ с доской в руке | Поставить её на землю |
| ПКМ по доске | Встать на неё |
| Shift + ПКМ по доске | Поднять доску с земли или сойти с неё |
| W / S | Ускориться / затормозить |
| A / D | Повернуть, а на перилах — поправить баланс |
| Зажать и отпустить пробел | Олли; дольше держите для более высокого прыжка |
| R | Поп-шовит |
| A + R / D + R | Кикфлип / хилфлип |
| S + R | Шовит 360 |
| Shift + R | Вэриал-кикфлип |

Выполняйте трюки в прыжке и приземляйтесь после полного оборота доски. Для бордслайда запрыгните на линию из железных прутьев: доска развернётся поперёк перил и будет набирать скорость. Поправляйте баланс короткими нажатиями A/D и нажмите пробел, чтобы спрыгнуть. При потере баланса игрок получает 2 единицы урона.

Трюки и скольжение прибавляют очки к комбо. Панель по центру экрана показывает очки и оставшееся время. При остановке или через пять секунд без новых очков результат засчитывается и появляется ранг от C до SS.

## Сборка

Укажите JDK 17 в `JAVA_HOME`. Из этой папки запустите `./gradlew build` (Linux/macOS) или `.\gradlew.bat build` (Windows). Готовый игровой JAR появится в `build/libs/`.

Исходники двух готических моделей и рисунок деки лежат в `artwork/`. Игровые меши и текстуры уже включены в `src/main/resources/`, поэтому Blender для сборки не нужен. Чтобы обновить меши после правки моделей в Blender 4.5, запустите из папки мода:

```sh
blender --background --factory-startup --python tools/export_bloodborne_boards.py
```
