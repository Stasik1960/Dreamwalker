Измерено на одном Ryzen7 5800H/RTX3070 Laptop/16GiB RAM: одновременно client4G+
server4G, Java17,16 logical CPU,1280×720,fancy+AO,view6/sim4,cap60. Это условия
проверки, не гарантия минимальных требований любого ПК. Heap4G не равно process
working set/RSS; пики shared memory нельзя просто складывать. При движении был
один кадр >1s и ни одного >3s; обещания постоянных60FPS или хостинга не даются.
Старый before-map baseline не завершён; процент ускорения миграции не доказан.
