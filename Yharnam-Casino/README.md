## Карточные столы

Во вкладке «Казино Ярнама» есть покерный стол, «Чёрный Валет», игральная колода и колесо фортуны. Стол занимает площадку 3 × 2 блока. Отдельный игрок становится крупье, положив колоду правой кнопкой мыши на дальний край стола. На «Чёрном Валете» можно нажать прямо на башмак для карт. В одной колоде 52 карты, перед каждой раздачей стол их тасует.

Игрок занимает свободное место, нажав по нему фишкой в основной руке. Обычный ПКМ вносит одну фишку, Shift + ПКМ вносит весь стак. До раздачи Shift + ПКМ пустой рукой по своему месту возвращает внесённые средства. Крупье ведёт игру с дальней стороны стола и нажимает по месту колоды пустой рукой для раздачи и расчёта.

### Покер

Безлимитный техасский холдем для 2–6 игроков и крупье. Игроки вносят запас фишек на одну раздачу. Блайнды равны 1 и 2. Кнопка дилера переходит к следующему занятому месту. В центре лежат общие карты, перед каждым участником — две закрытые. **ПКМ по центру сукна** на четыре секунды показывает свои карты только их владельцу. В строке над панелью предметов также появятся их значения.

| Ход на своём месте | Действие |
| --- | --- |
| ПКМ пустой рукой | Чек или колл из фишек, лежащих на месте |
| Shift + ПКМ пустой рукой | Фолд |
| ПКМ с фишкой | Уравнять и повысить на её номинал из внесённого запаса |
| Shift + ПКМ с фишкой | Олл-ин на оставшийся запас |

Чтобы набрать произвольное повышение, нажимайте фишками по центру стола. ПКМ добавляет один номинал, Shift + ПКМ добавляет стоимость стака. Размер повышения виден на сукне. Подтвердите его пустой рукой на своём месте или сбросьте через Shift + ПКМ пустой рукой по центру. Сумма списывается из фишек, внесённых до раздачи.

Крупье открывает флоп, тёрн и ривер по завершении каждого круга торговли. При вскрытии сравниваются лучшие пять из семи карт. Для олл-инов с разными суммами стол отдельно рассчитывает основной и побочные банки. Победители с равными комбинациями делят банк, нечётная фишка уходит первому победителю после кнопки. Невостребованный остаток и выигрыши возвращаются участникам после расчёта.

### Чёрный Валет

За столом могут играть 1–7 игроков против крупье. Крупье заранее пополняет банк, нажимая по своему месту фишкой. Каждый участник вносит **чётную ставку**. Для начала раздачи банк должен покрывать выплату 3 к 2 всем поставившим. В свой ход игрок нажимает на своё место.

| Ход на своём месте | Действие |
| --- | --- |
| ПКМ пустой рукой | Взять карту |
| Shift + ПКМ пустой рукой | Остановиться |
| ПКМ с фишками | Удвоить ставку и получить последнюю карту |
| Shift + ПКМ с фишками | Разделить начальную пару одинакового ранга |

Для удвоения или разделения в руке должны быть фишки на сумму дополнительной ставки. Стол возвращает сдачу и проверяет запас крупье. Пару можно разделить один раз, разделённые тузы получают по одной карте. Крупье берёт карты до 17 и останавливается на мягких 17. Обычная победа оплачивается 1 к 1, начальный блэкджек — 3 к 2. При ничьей возвращается ставка. Страховки и сдачи руки в этом варианте нет.

Между раздачами крупье может забрать колоду и банк через Shift + ПКМ пустой рукой по своему месту. Ставки игроков, ожидающих начала, при этом возвращаются. Раздача сохраняется при выгрузке чанка. Средства игрока, который вышел, ждут следующего входа или команды `/yharnamcasino claim`. Если участник отошёл более чем на 12 блоков или вышел, после минуты бездействия крупье может пропустить его ход. Если ушёл сам крупье, другой игрок может занять его место после той же паузы. Стол рассчитывает прерванную раздачу, возвращая колоду и банк прежнему крупье.

## Колесо фортуны

Для установки нужны три блока в ширину и три в высоту. Первый ПКМ запускает шкалу силы, второй фиксирует усилие и раскручивает колесо. Дождитесь остановки и прочтите номер сектора под верхней стрелкой. На колесе 16 секторов. Их значения участники определяют сами в рамках РП. Вращение свободное, без ставок и выплат.

В [папке моделей](art/gaming-floor/) лежат исходники Blender, GLB со встроенными текстурами и предпросмотр каждой модели.

## Как играть

1. Возьмите автомат из вкладки **Казино Ярнама** в творческом режиме или скрафтите его в выживании. Для установки нужны два свободных блока по высоте. Лицевая сторона повернётся к игроку.
2. Нажмите ПКМ по автомату с фишкой в любой руке. По умолчанию он принимает только номинал 10. Автомат примет ровно одну фишку разрешённого номинала и зарезервирует её до запуска. Фишки складываются в стаки по 64. Если в кассе нет места для ставки, автомат её не примет.
3. Нажмите ПКМ по правому рычагу или по корпусу пустой рукой. Принятая фишка перейдёт в общую кассу, а барабаны остановятся слева направо. Цикл длится около 3,5 секунды при 20 тиках в секунду. Если касса успела заполниться после внесения ставки, автомат вернёт зарезервированную фишку.
4. Автомат выплачивает выигрыш фишками из той же кассы. Если её запаса не хватает, доступная часть выдаётся сразу, а на остаток автомат выписывает расписку. Если инвентарь заполнен, сервер сохраняет предметы к выдаче: их можно забрать после входа или командой `/yharnamcasino claim`. Если чанк выгрузился раньше остановки, расчёт происходит при его следующей загрузке.

До запуска можно вернуть ставку через Shift + ПКМ с пустыми руками. Через 45 секунд без запуска автомат возвращает зарезервированную фишку сам. Если инвентарь заполнен, её можно забрать через `/yharnamcasino claim`. Другой игрок не может забрать или запустить чужую ставку. Разбор автомата возвращает внесённую ставку до запуска или рассчитывает уже начатую игру по сохранённому результату.

## Касса и совладельцы

Первый владелец — игрок, который поставил автомат. Ключ распорядителя можно взять из творческой вкладки или скрафтить из одного золотого и двух железных слитков. Положите золотой слиток в правую клетку верхнего ряда рецепта, а железные — друг под другом левее, во втором и третьем рядах.

| Действие с ключом в руке | Результат |
| --- | --- |
| ПКМ по своему автомату | Открывает общую кассу на 27 ячеек и привязывает ключ к этому автомату |
| ПКМ по игроку рядом с привязанным автоматом | Даёт игроку доступ к кассе |
| Shift + ПКМ по игроку | Отзывает доступ |
| Shift + ПКМ ключом по своему автомату | Открывает настройки номиналов. Можно включить один или несколько |

Назначает совладельцев игрок, который поставил автомат. У него может быть несколько совладельцев. Каждому нужен свой ключ распорядителя для работы с кассой. Ключ запоминает автомат для назначения совладельцев. Список доступа хранится в самом автомате.

Владельцы могут пополнять кассу и забирать фишки как из обычного сундука. В неё поступают запущенные ставки, а из неё списываются выплаты за выигрыш. Автомат подбирает точную сумму из доступных номиналов и при необходимости разменяет крупную фишку. Если все ячейки заняты, остаток при размене остаётся частью запаса и превращается в видимые фишки после освобождения места. В кассе также можно хранить другие предметы, и они не влияют на выплаты.

Разобрать автомат может поставивший его игрок или администратор. Содержимое кассы возвращается установившему игроку с сохранением номиналов, количества и имён предметов. Если у него нет места или он не в сети, предметы ждут команды `/yharnamcasino claim` либо следующего входа.

## Доступ админов и ГМ

Админы и ГМ могут открыть любую кассу через Shift + ПКМ по автомату с обеими пустыми руками. Если у игрока есть собственная ставка, ожидающая запуска, первый такой клик возвращает её.

ГМский ключ есть во вкладке «Казино Ярнама». Админы и ГМ могут получить его командой `/yharnamcasino gmkey`. ПКМ ключом открывает кассу, а Shift + ПКМ открывает настройки номиналов. ГМский ключ не назначает владельца и не меняет список совладельцев. Ключ распорядителя по-прежнему позволяет взять во владение бесхозный автомат.

Мод проверяет уровень OP 2+ и те же метки ролей, что и Dreamwalker RP Chat и Profiles. Поддерживаются `rpchat_admin`, `rpchat_gm`, `profile_admin` и `profile_gm`. Доступ проверяется и при открытом хранилище.

## Расписки

При нехватке запаса автомат выдаёт доступную часть выигрыша. На недостающую сумму игрок получает РП-расписку с названием и координатами автомата, а также именем владельца, если оно известно. Предъявите расписку владельцу и договоритесь о выплате в рамках РП.

При ПКМ распиской по автомату появляется напоминание обратиться к владельцу. Это действует и для расписок из версии 1.1.0. Золотой наградной талон остаётся отдельной РП-наградой.

## Фишки и рецепты

Кассовый шкаф занимает два блока в высоту и открывается обычным ПКМ. В каждом из семи столбцов инвентаря помещается шесть стаков одного номинала. Стопки уложены горизонтально в желобках. В каждом лотке шесть желобков, а длина стопок зависит от запаса. В шкаф помещается до **2688 фишек**. Его можно взять в творческой вкладке или скрафтить из семи досок тёмного дуба и двух железных самородков. Самородки занимают левую и правую клетки среднего ряда.

У всех трёх автоматов есть декоративная версия с деревянной табличкой «Не работает». Шнур таблички висит на латунном креплении над барабанами. Декоративный автомат можно взять в творческой вкладке или скрафтить из соответствующего автомата и листа бумаги. Корпуса всех автоматов входят в геометрию чанка. У декоративных версий нет серверной логики и отдельного рендера.

Один золотой самородок обменивается на фишку номиналом 1 и обратно. Обмен делается на верстаке или в сетке крафта. Соседние номиналы можно менять в обе стороны без комиссии.

| Из мелких фишек | В крупную фишку |
| --- | --- |
| 5 × 1 | 5 |
| 2 × 5 | 10 |
| 5 × 10 | 50 |
| 2 × 50 | 100 |
| 5 × 100 | 500 |
| 2 × 500 | 1000 |

Выплата выдаётся целыми фишками с точным сохранением стоимости. Автомат по возможности пополняет имеющиеся стаки, а для новых стаков использует крупные номиналы. Наградной талон предъявляется распорядителю казино для РП-награды.

Все три автомата крафтятся по схеме ниже. `R` — красная пыль, `L` — рычаг.


| Hunter's Wager | Полированный глубинный сланец | Медный слиток | Оранжевое стекло |
| Astral Fairy | Кварцевый блок | Окисленный медный блок | Бирюзовое стекло |

## Выплаты

Сервер выбирает по одному из восьми равновероятных символов на каждом из трёх барабанов. В расчёт идёт центральная линия. Пара может стоять в любых двух окнах. Для первых трёх символов каждого автомата пара платит ×2, для остальных — ×1. Тройка рассчитывается по отдельной строке таблицы. Три разных символа дают 0.

При ставке 50 джекпот даёт выигрыш на сумму 4000 и один талон. Касса выдаёт доступную часть выигрыша фишками, а оставшуюся сумму записывает в расписку. Вероятность талона — 1 из 512 на каждом автомате. Талон не имеет фиксированной стоимости в фишках.

## Сборка

Для сборки используйте JDK 21. Готовые текстуры и модели уже входят в ресурсы проекта. Выходной JAR совместим с Java 17.

```powershell
.\gradlew.bat build
.\gradlew.bat runGametest
```

Модели столов и колеса для Minecraft собирает `python tools/compile_gaming_floor.py` из экспортов GLB с помощью NumPy и Pillow. У игровой колоды свой ресурс рубашки, а общий атлас содержит 52 лицевые стороны. Скрипты ресурсов используют Pillow. `python tools/compile_machine_meshes.py` пересобирает модели автоматов из `art/` или соседней папки `bloodborne_slots_3d`. `python tools/make_casino_items.py` пересобирает фишки, талон, расписку, оба ключа и рецепты. Для шкафа запустите `python tools/make_chip_cabinet.py`, затем `blender -b --python tools/build_chip_cabinet_blender.py`, чтобы обновить `.blend` и предпросмотр.
