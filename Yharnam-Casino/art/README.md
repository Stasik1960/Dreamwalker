# Автоматы Ярнама

Три модели для казино в Minecraft. **Hunter's Wager** напоминает машину из мастерской охотника, **Astral Fairy** построен как готическая часовня, а **Crimson Guard** стилизован под реликварий. У каждого свои корпус, вывеска и полоса из восьми символов.

Откройте `bloodborne_slots.blend` в Blender и нажмите пробел. Рычаг опустится, после чего три барабана прокрутятся и остановятся по очереди. Тот же демонстрационный клип `pull_and_spin` встроен в каждый GLB. В проектах Blockbench у рычага и барабанов есть отдельные группы.

Модели занимают основание 1 × 1 блок и помещаются в высоту двух блоков. Лицевая сторона смотрит вдоль −Y в Blender и вдоль +Z в GLB и Blockbench. В папке `models/` лежат GLB и редактируемые `.bbmodel`, а в `textures/` хранятся PNG с поверхностями, атласами, вывесками и барабанами.

Узлы `lever`, `reel_01`, `reel_02` и `reel_03` вращаются вокруг локальной оси X. Порядок восьми символов сверху вниз записан в `textures/reel_symbols.json`. При нулевых поворотах на барабанах видны индексы 0, 1 и 2 слева направо. Для выбора символа с индексом `k` поверните барабан на `(начальный индекс − k) × 45°` вокруг +X с точностью до полного оборота. Подключение блоков и игровых правил к Minecraft остаётся отдельным этапом.

## Пересборка

```text
python tools/make_textures.py
python tools/make_surfaces.py
blender --background --python-exit-code 1 --python tools/build_slots.py
python tools/make_blockbench.py
python tools/finish_pack.py
```
