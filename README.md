## Начать играть

1. Подготовьте Minecraft 1.20.1, Java 17, Fabric Loader и Fabric API для 1.20.1.
2. Выберите нужные моды в [каталоге сборок](releases/README.md). Все проекты сразу устанавливать необязательно.
3. Следуйте README выбранного мода: зависимости и требования клиента/сервера различаются.
4. При обновлении замените прежний JAR этого мода, не оставляя две версии рядом.

Для связки ролевого чата используйте **RP Chat 0.1.16 + DW Magic Connect 0.4.3 + DW Languages 0.1.0**.
RP Chat UI добавляет интерфейс и не заменяет серверную логику RP Chat.

**Bloodborne rc.1:** карта сконвертирована и проверена офлайн, но запуск с перезапуском выделенного сервера и визуальная приёмка ещё не подтверждены.
Repair TEST-сборки относятся к отдельной ветке и не входят в `main`. Старые карты и новые JAR нельзя считать взаимозаменяемыми.
**Danny’s AoT:** опубликован тестовый порт; офлайн-проверки не подтверждают всю игровую совместимость.

## Структура репозитория

- Папки модов — независимые Gradle-проекты с собственными README.
- [releases/](releases/README.md) — каталог готовых JAR и исторических выпусков.
- [Bloodborne-Blocks/docs/](Bloodborne-Blocks/docs/RELEASE-STATUS.md) — текущий статус, проверки и материалы конвертации.
- [История Bloodborne](Bloodborne-Blocks/docs/history/README.md) — прежние этапы; не руководство по установке текущего кандидата.
- [.github/workflows/](.github/workflows) — автоматические сборки и проверки.

Инструкции без локальных путей разработчика: [CONTRIBUTING.md](CONTRIBUTING.md).
Крупные входные архивы и часть сборок хранятся через Git LFS.
Авторство и условия использования указаны в каждом проекте; наличие мода в этом репозитории не меняет его лицензию.
