# Dreamwalker

Шесть самостоятельных модов для **Minecraft 1.20.1 / Fabric / Java 17**: ролевой чат, интерфейс чата, магическая связь, языки персонажей, бильярд и архитектурный набор Bloodborne. Дополнительно доступен тестовый неофициальный порт Danny’s AoT для той же версии игры.

Версии в таблице относятся к текущим выпускам. Исходники каждого мода находятся в отдельной папке; готовые JAR перечислены ниже.

### MC-Pool

Игра в пул через общий интерфейс стола. Есть настройка силы удара, отображение кия, сглаживание движения шаров и звуки столкновений. Перед первым ударом новой партии можно выбрать цветные или одноцветные шары. **Правила остаются правилами пула** — это оформление, а не отдельный режим русской пирамиды. Разрушение любой части удаляет весь стол.

### RP Chat и RP Chat UI

RP Chat управляет доставкой и содержанием сообщений; RP Chat UI отвечает за окно чата и инструменты ввода. Радиусы и роли задаются сервером.

| Ввод | Действие |
| --- | --- |
| `=текст`, `==текст`, `===текст` | Тихая речь, шёпот, едва слышная речь |
| `!текст`, `!!текст`, `!!!текст` | Громкая речь, крик, усиленный крик |
| `*села на стул` или `*села на стул*` | Ролевое действие со светло-серым текстом и цветным ником |
| `#В долину пришла зима` или `№В долину пришла зима` | Жёлтое повествование с тремя звёздочками |
| `d20`, `д20`, `5d20+3`, `/roll d20`, `/r d20` | Броски кубиков; в результате используется латинская `d` |
| `_текст` | OOC-сообщение |
| `-текст` | Закрытый GM-чат |
| `/listen 100` | Для GM/Admin: чтение чата строго в радиусе 100 блоков |
| `/rpchat help` | Справка по чату |

Поддерживаются кубики от d2 до d100, до 100 кубиков за бросок и модификатор результата. `/listen` может и расширять, и сужать радиус; дальние сообщения за стандартной дистанцией помечаются расстоянием и тёмно-серым цветом. По умолчанию стандартный радиус — 18 блоков.

В UI есть адаптация к масштабу GUI, ограничение отрисовки поля ввода, форматирование текста и деревянные темы. Можно копировать тело сообщения без ника, сохранять сообщения в избранное и выбрать, закрывать ли чат после отправки. Поддержан Enter на цифровой клавиатуре. Полный набор длинных сообщений требует согласованной серверной части; стандартный лимит — 512 символов.

### DW Magic Connect

Команда администратора `/MConnect` делает предмет в руке рацией, `/MConnect remove` удаляет её свойства. Два циферблата задают одну частоту; настройки сохраняются автоматически. Нижний кристалл управляет питанием, боковая руна — громкой связью, клавиши слева — радиусом **1–18 блоков**, по умолчанию 10.

Обычный режим передаёт речь владельца с рацией в руке. Громкая связь также улавливает речь вокруг устройства и работает из инвентаря онлайн-игрока или загруженной рамки. Сундуки не поддерживаются. Радиус приёма вокруг устройства применяется и в обычном режиме. Держатель видит частоту сообщения, окружающие — `[Мистический голос]`.

Передаётся только обычная IC-речь: действия, дайсы, повествование, OOC, GM-чат и личные сообщения исключены. Анимированные свечение и дымка относятся к открытому интерфейсу; это не источники света в мире.

### DW Languages

Серверный мод: клиентам устанавливать его не нужно. `/lang list` показывает языки, `/lang orc` или отдельное сообщение `+orc` выбирает язык, `/lang off` возвращает общий. Знающие язык получают оригинал, остальные — преобразованную речь. Знание проверяется отдельно для каждого слушателя, в том числе через рации.

Администратор управляет знаниями через `/lang add`, `/lang del`, `/lang reload`. Языки находятся в `config/dw_languages/languages/`, знания игроков — в папке мира `dw_languages/players.json`. Поддерживаются роли RP Chat и права LuckPerms; Fabric Permissions API включён в JAR. Подробности: [гайд по настройке языков](DW_Languages/LANGUAGE-GUIDE.md).

### Bloodborne Architecture

Текущая [2.1.0-beta.1](releases/Bloodborne-Blocks/2.1.0-beta.1/README.md) содержит исправления после «Агонии», проверенную галерею и ALT-комплект. Конвертированные копии старого города опубликованы как **UNRESOLVED**, с отчётами несовместимых ID; это не готовые игровые миры. Графическая приёмка ещё не выполнена.

#### Историческая ветка 2.0.1

Строительный набор сохраняет **503 прежних ID** и добавляет палитру секций, занимающих одну клетку. Кладка, ограды, карнизы и лестничные секции разделены по сетке; большие двери, деревья и мебель остаются цельными. Мод **не генерирует город**: отдельно подготовлена переработанная копия предоставленного мира Ether.

У мягкой растительности нет столкновений. Новая секция использует не больше четырёх простых коробок столкновения, одну рамку и не имеет тикающей block entity. Текстурированные торцы закрывают разрезанные модели; плоской графике добавлена толщина. Предметы ограничены по размеру для рук и инвентаря. Сохранены открывание больших дверей, сидение на лавке и подъём по лестницам.

Готовая карта не требует команд обновления по чанкам; одной замены JAR для разделения старой карты недостаточно. Последний архив карты — **Ether 2.0.2-positions**, совместимый с JAR **2.0.1**: удалены 4 905 барьеров и восстановлено исходное положение смещённых объектов. В этом историческом релизе мир с данными игроков выдавался локально. Для нынешней beta опубликованы отдельно обозначенные UNRESOLVED-копии и отчёты. [Инструкция](Bloodborne-Blocks/README.md), [восстановление расположения и ограничения](Bloodborne-Blocks/docs/MAP-POSITIONS-2.0.2-RU.md). Minecraft локально не запускался; FPS/TPS не измерены.

### Danny’s AoT 2.4.3-backport.2

Неофициальный перенос предоставленной версии 2.4.3 с Fabric 1.21.1 на 1.20.1 / Java 17. В единый JAR включены GeckoLib 4.8.4, AAA Particles 2.2.3 и перенесённая Player Animation Library. Fabric API устанавливается отдельно. Исправлены ошибка запуска камеры и связанные несовместимые mixin-обработчики. Прошли сборка, 812 офлайн-проверок и применение 133 mixin-вставок к байткоду Minecraft; игровой запуск и совместимость с остальными модами ещё не подтверждены. [Установка, лицензия и ограничения](releases/Danny-AOT/README.md). [Исходники и сборка](Danny-AOT-Backport/README.md), включая порт библиотеки анимаций, Gradle wrapper и офлайн-проверки.

## Установка и сборка

Для всего набора: Java 17, Minecraft 1.20.1, Fabric Loader 0.16.10+ и Fabric API для 1.20.1; Bloodborne использует Fabric API 0.92.9+1.20.1. Заменяйте прежний JAR того же мода, не оставляя дубликаты. Bloodborne требует отключения исходного Bloodborne resource pack и старого `bloodborne_transparency_fix`.

Каждая папка — отдельный Gradle-проект. Для первых пяти проектов используется Gradle 8.10.2. Из корня репозитория:

```sh
gradle -p RP-Chat build
gradle -p RP-Chat-UI build
gradle -p MC-Pool build
gradle -p DW_Languages build
gradle -p DW_Magic_Connect build
```

Языки и рации используют соседний проект RP-Chat через composite build. Bloodborne поставляется со своим wrapper Gradle 8.8:

```powershell
cd Bloodborne-Blocks
.\gradlew.bat build
```

Результаты — в `build/libs/` каждого проекта; для игры нужны обычные JAR без `-sources`.

Для Danny’s AoT используйте JDK 21 и вложенный wrapper Gradle 8.12.1: сначала соберите `player-animation-backport`, затем основной мод. Выходные классы остаются совместимыми с Java 17. [Команды сборки](Danny-AOT-Backport/README.md#авторство-и-сборка-из-исходников).

Авторство и лицензии моделей, текстур и исходников указаны внутри соответствующих проектов.
