# Dreamwalker: продолжить native-grid city с этого checkpoint

Это переносимый снимок незавершённой работы от **22 октября 2026**, а не готовая оптимизированная карта. Пользователь попросил сохранить всё в GitHub для продолжения на другом ПК и в новом чате.

**Начать новому агенту:** прочитать [HANDOFF-RU.md](HANDOFF-RU.md), затем [исходное обновлённое задание](TASK/START-RU.txt) целиком и три документа в [handoff/](handoff/). Скачать файлы [релиза checkpoint](https://github.com/Stasik1960/Dreamwalker/releases/tag/native-grid-city-resume-20261022), сверить SHA256 по `bundle-manifest.json`, восстановить данные через [restore_bundle.py](restore_bundle.py). Только после этого продолжать существующий план. Не создавать новую конвертацию или исследование с нуля.

В `source/` доступны для просмотра текущие Java/Python/ресурсы/Gradle. **Полный фактический снимок** — в файлах релиза: все рабочие исходники, результаты и неудачные попытки, обе карты пилота, исходная полная карта blocks.2, текущий план, исходный SQLite с кэшем города, журналы, геометрия, каталоги и точные launch/build зависимости. Файлы дедуплицированы в ZIP-тома; manifest восстанавливает оригинальные байты и времена изменения. Учётные данные, токены и профили браузера не переносятся.

Для нового чата достаточно дать эту ссылку и написать:

> Продолжи работу с checkpoint этого репозитория. Полностью прочти README, HANDOFF-RU.md и TASK/START-RU.txt, восстанови и проверь файлы релиза, создай ровно трёх указанных субагентов и продолжай до полного результата. Сначала заверши сверку ранее согласованных цельных сборок и адресную проверку двери; не повторяй пройденные проверки и конвертацию города с нуля. Исторические FAIL/OOM не переименовывай в PASS.

Точный прогресс и ограничения находятся в HANDOFF, а хэши всех переданных файлов — в manifest релиза. Обычный GitHub `Download ZIP` содержит только видимую часть репозитория; **крупные данные релиза обязательны**.
