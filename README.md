# Dreamwalker

Исходники пяти отдельных модов для Minecraft 1.20.1 на Fabric:

| Папка | Мод | Назначение |
| --- | --- | --- |
| [MC-Pool](MC-Pool/) | MC-Pool (Pool Billiards) | Бильярдный стол и игра в пул-восьмёрку |
| [RP-Chat](RP-Chat/) | RP Chat | Ролевой чат, команды и серверные настройки |
| [RP-Chat-UI](RP-Chat-UI/) | RP Chat UI | Изменённый интерфейс чата и серверные функции |
| [DW_Magic_Connect](DW_Magic_Connect/) | DW Magic Connect | Магические рации на произвольных предметах с интеграцией в обычный IC-чат RP Chat |
| [DW_Languages](DW_Languages/) | DW Languages | Языки персонажей, JSON-настройки, интеграция с RP Chat и магическими рациями |

Каждая папка содержит самостоятельный Gradle-проект и свой README с подробностями.

Поставленные JAR-файлы и их SHA-256: [releases/](releases/).
