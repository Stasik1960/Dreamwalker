# Восстановление интерьера и зелени Bloodborne

Источник — [архив Ether-Bloodborne-2.0.2 из истории Dreamwalker](https://github.com/Stasik1960/Dreamwalker/blob/codex/bloodborne-beta-world-20260925/Bloodborne-Blocks/reference-inputs/latest-modded-world.zip). SHA-256 архива — `c517dfeb52c4d13bdbe90e02a93ac00416354eb89313a9d1377f24823af6d0e9`. Координаты на старой карте получаются прибавлением `(-554, +8, +793)` к текущим. Смещение проверено по стенам и лестницам здания и по окружению участка с деревьями.

- Интерьер возле `171 60 -970` включает обстановку обоих этажей. Сохраняются данные контейнеров Handcrafted, направление и внешний вид поддерживаемых блоков Yuushya. Основные замены для отсутствующих модов — тёмный дуб и тропическое дерево для досок Biomes O’ Plenty, настенные фонари Yuushya и ванильные свечи с исходным состоянием. Защищённые многоблочные конструкции и три предмета текущей обстановки с совместными владельцами сохранены.
- Возле `27 -2 -1097` добавлено 480 ячеек зелени в пустые позиции, две занятые ячейки остались без изменений. Листва сохранена как постоянная. Три сегмента стволов восстановлены как дубовые брёвна по соответствующим состояниям карты до переименования блоков. На плитах использованы существующие декоративные трава и папоротник DreamWalker, которые сохраняются на каменной поверхности.
- Записаны 2 802 ячейки интерьера и 68 блочных сущностей Handcrafted. Скрипт перечитывает все записанные состояния и NBT. Данные чанков вне 11 изменённых побайтово совпадают с исходными. Результат повторного прогона фиксируется в JSON, включая замены и защищённые позиции.

## Повторное применение

Запустите из корня репозитория с Python 3.10 или новее, указав копию мира, старый архив, выгрузку состояний из целевой сборки клиента, актуальный JAR с каталогами мира и путь для отчёта.

```text
python DW-City-Visuals/tools/historic_restoration/restore_historic_sites.py WORLD DONOR_ZIP REGISTRY_TSV DREAMWALKER_JAR REPORT_JSON
```

Каждая строка выгрузки начинается со строки состояния блока, например `minecraft:oak_log[axis=y]`. Дополнительные значения отделяются табуляцией. По умолчанию скрипт формирует отчёт. С `--apply` он также записывает регионы и сохраняет их резервные копии рядом с отчётом. После записи требуется пересчитать свет в изменённых чанках и рядом с ними.

Для публикации можно упаковать проверенное сохранение с `python DW-City-Visuals/tools/historic_restoration/package_bloodborne_world.py WORLD OUTPUT.zip`. Архив включает карту и данные её блоков. Личные сохранения, чат и настройки персонажей остаются в локальной копии.
