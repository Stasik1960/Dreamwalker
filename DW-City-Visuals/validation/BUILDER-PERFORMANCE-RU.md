# Профилирование запуска DreamWalker v22

Minecraft 1.20.1, Java 17, Fabric Loader 0.18.2, 51 JAR из указанной клиентской папки, предел heap 6 ГиБ. Профиль создавался отдельно от основной установки. Использовались настройки нового тестового профиля без шейдеров. Исходный JAR сверён с опубликованным SHA‑256. Более ранний Fabric Loader 0.17.2 отклонил сборку из-за зависимостей Farmer’s Delight и Porting Lib.

## Исходная сборка RGB Relief + BB Half

В первом прогоне Fabric сообщил о загрузке через 5,75 с, первая перезагрузка ресурсов началась через 146,84 с, событие `CLIENT_STARTED` появилось примерно через 150 с. JVM остановлена по тайм-ауту через 180 с. Пиковый рабочий набор процесса до остановки составил 5,88 ГиБ, пиковая выделенная память процесса составила 6,81 ГиБ.

Из 9 605 сэмплов Java 7 779, или 81%, содержат кадр DreamWalker. Отдельный снимок стека сервера показывает длительное построение переходов между состояниями компактных блоков в `CompactStateTransitions`. Это совпадает с длительной фазой между началом регистрации DreamWalker и первой загрузкой ресурсов.

JFR относит сэмпл к первому известному классу мода в стеке. Вес выделений показывает накопленный объём за период, включая затем освобождённые объекты. Shallow — размер объектов классов мода после снятия гистограммы. Массивы, стандартные коллекции и другие классы JVM составили большую часть живых данных, около 1,92 ГиБ вне атрибуции. Эти числа не измеряют полный вклад мода в удерживаемую память и память GPU.

## Пробный прогон новой сборки

В прогоне промежуточного JAR с полной папкой модов первая загрузка ресурсов началась через 172,06 с, `CLIENT_STARTED` через 175,44 с. ModernFix сообщил о завершении запуска через 414,48 с после дополнительной перезагрузки ресурсов. Пиковый рабочий набор составил 7,60 ГиБ, пиковая выделенная память процесса составила 8,47 ГиБ. Во время этого прогона запускались два тестовых сервера. Эти измерения подтверждают прохождение инициализации и не позволяют оценить разницу во времени запуска между версиями.
