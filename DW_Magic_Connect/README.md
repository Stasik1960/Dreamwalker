# DW Magic Connect (Fabric 1.20.1)

Отдельный Fabric-мод, который превращает помеченные администратором предметы в магические рации и ретранслирует только обычные IC-сообщения RP Chat.

## Версия 0.2.0

- Новый интерфейс: тёмный астральный диск, золотая окантовка и кристаллы, без подставки. Текст и интерактивные элементы рисуются отдельно от текстуры; размер учитывает масштаб GUI.
- Три вкладки каналов. Каждый канал задаётся парой кодов A/B, в каждом поле от 1 до 3 символов: цифры, латинские и русские буквы. Регистр не учитывается; пробелы и специальные символы запрещены. Оба пустых поля отключают дополнительный канал.
- Все настроенные каналы принимают сообщения. Кнопка «Сделать разговорным» выбирает единственный канал передачи; остальные два остаются только для приёма. Переключение вкладки само по себе не меняет разговорный канал.
- Изменения вступают в силу после «Сохранить». ESC отменяет изменения. Настройки вкладок сохраняются при изменении размера окна.
- Старые частоты 0–999 переносятся в первый канал. Старые четырёхзначные коды требуют ручной перенастройки: автоматическое обрезание создало бы совпадения чужих каналов.
- Обновите мод раций до 0.2.0 на сервере и клиентах; RP Chat 0.1.13 остаётся совместимым. Новый сетевой формат отделён от версии 0.1.0.

## Требования

- Minecraft 1.20.1
- Java 17
- Fabric Loader 0.16.10+
- Fabric API 0.92.8+1.20.1
- RP Chat 0.1.13 или новее

`DW Magic Connect` и `RP Chat` остаются двумя отдельными модами и устанавливаются двумя `.jar`-файлами. Зависимость `rpchat >=0.1.13` также объявлена в `fabric.mod.json`, поэтому Fabric не запустит мод без совместимой версии RP Chat.

## Сборка

Проект использует Gradle composite build: `settings.gradle` подключает соседний
`../RP-Chat` и подставляет его исходный проект для compile-time зависимости
`com.coraxberg:rp-chat`. Предварительно собранный JAR и абсолютные пути не нужны;
RP Chat при этом не встраивается в JAR DW Magic Connect.

Чтобы получить оба готовых мода, из корня репозитория последовательно соберите RP Chat:

```powershell
cd RP-Chat
gradle build
```

Затем соберите DW Magic Connect:

```powershell
cd ..\DW_Magic_Connect
gradle build
```

Результат сборки RP Chat:

```text
../RP-Chat/build/libs/rp-chat-0.1.13.jar
```

Результат сборки нового мода:

```text
build/libs/dw-magic-connect-0.2.0.jar
```

Если в проектах ещё нет Gradle Wrapper, его можно создать установленным Gradle:

```powershell
gradle -b bootstrap-wrapper.gradle wrapper
```

## Использование

- Возьмите предмет в основную или вторую руку.
- Выполните `/MConnect` (требуется уровень прав 2), чтобы записать данные рации в NBT самого `ItemStack`.
- Нажмите ПКМ помеченным предметом, настройте два компонента частоты, включите рацию и сохраните настройки.
- Выполните `/MConnect remove`, чтобы удалить с предмета свойства рации.

Серверная настройка радиуса ретрансляции создаётся в `config/dw_magic_connect.json`. Значение по умолчанию — `15` блоков. Клиент отправляет серверу только желаемые значения интерфейса; сервер повторно проверяет диапазон, открытую сессию, руку и конкретный предмет перед изменением NBT.

Ретрансляция подписана на публичное событие обычного IC local chat из RP Chat. GM, OOC, личные сообщения, команды и системные сообщения этим событием не публикуются и в радио не попадают.
