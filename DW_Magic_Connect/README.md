# DW Magic Connect (Fabric 1.20.1)

Отдельный Fabric-мод, который превращает помеченные администратором предметы в магические рации и ретранслирует только обычные IC-сообщения RP Chat.

## Версия 0.3.0 — Часы Луны и Солнца

- Два циферблата вместо кодов A/B. У каждого независимая часовая стрелка (12 положений) и минутная (60 положений). Верхнее деление — нулевое. Частота совпадает, только если совпадают все четыре положения; всего 518 400 комбинаций.
- Тяните за кончик нужной стрелки левой кнопкой мыши. Стрелки привязываются к ближайшему делению, включая переход через верхнюю точку. Короткая часовая стрелка толще, длинная минутная тоньше; отдельные захваты позволяют выбрать обе при наложении. Захват сохраняется за пределами циферблата до отпускания кнопки.
- Клавиатура: Tab выбирает циферблат, пробел переключает стрелку, клавиши со стрелками поворачивают на одно деление.
- Сохранены три канала: приём на всех настроенных, передача на одном выбранном. Переключение вкладки не меняет разговорный канал. Первый захват стрелки активирует пустой канал; остальные стрелки начинают с верхнего деления. «Сброс» очищает выбранный канал.
- Старые буквенные и числовые частоты намеренно сбрасываются, рация выключается. Требуется настроить её заново. Данные предмета вне DWMagicConnect и идентификатор рации сохраняются.
- «Сохранить» применяет настройки, Escape отменяет изменения. Изменение размера окна сохраняет правки всех вкладок. Сервер проверяет четыре положения, выбранный канал и сессию конкретного предмета (срок сессии — 2 минуты).
- Более мягкие цвета фона и кнопок. Циферблаты, деления и стрелки рисуются кодом поверх существующего астрального фона. Числовой код и заголовок «Магическая связь» на экране не выводятся.
- Установите 0.3.0 на клиент и сервер. Сетевые идентификаторы v3 отделяют новый формат от старых клиентов. RP Chat 0.1.13 остаётся совместимым.

## Требования

- Minecraft 1.20.1
- Java 17
- Fabric Loader 0.16.10+
- Fabric API 0.92.8+1.20.1
- RP Chat 0.1.13 или новее

`DW Magic Connect` и `RP Chat` остаются двумя отдельными модами и устанавливаются двумя `.jar`-файлами. Зависимость `rpchat >=0.1.13` также объявлена в `fabric.mod.json`, поэтому Fabric не запустит мод без совместимой версии RP Chat.

## Сборка

Проект использует Gradle composite build: `settings.gradle` подключает соседний
`../RP-Chat` и подставляет его исходный проект для compile-time зависимости
`com.coraxberg:rp-chat`. Предварительно собранный JAR и абсолютные пути не нужны;
RP Chat при этом не встраивается в JAR DW Magic Connect.

Чтобы получить оба готовых мода, из корня репозитория последовательно соберите RP Chat:

```powershell
cd RP-Chat
gradle build
```

Затем соберите DW Magic Connect:

```powershell
cd ..\DW_Magic_Connect
gradle build
```

Результат сборки RP Chat:

```text
../RP-Chat/build/libs/rp-chat-0.1.13.jar
```

Результат сборки нового мода:

```text
build/libs/dw-magic-connect-0.3.0.jar
```

Если в проектах ещё нет Gradle Wrapper, его можно создать установленным Gradle:

```powershell
gradle -b bootstrap-wrapper.gradle wrapper
```

## Использование

- Возьмите предмет в основную или вторую руку.
- Выполните `/MConnect` (требуется уровень прав 2), чтобы записать данные рации в NBT самого `ItemStack`.
- Нажмите ПКМ помеченным предметом, настройте четыре стрелки двух часов, включите рацию и сохраните настройки.
- Выполните `/MConnect remove`, чтобы удалить с предмета свойства рации.

Серверная настройка радиуса ретрансляции создаётся в `config/dw_magic_connect.json`. Значение по умолчанию — `15` блоков. Клиент отправляет серверу только желаемые положения стрелок и настройки каналов; сервер повторно проверяет диапазон, открытую сессию, руку и конкретный предмет перед изменением NBT.

Ретрансляция подписана на публичное событие обычного IC local chat из RP Chat. GM, OOC, личные сообщения, команды и системные сообщения этим событием не публикуются и в радио не попадают.

Запрос генерации: «Square transparent fantasy communicator UI background: front-on navy astronomical disk, antique gold engraved concentric rim, blue crystals, crescent moon and faint stars; central area dark and clear for actual controls; no text, numbers, pedestal, stand or environment». Один статический фон, без анимированных частиц.

## Проверки 0.3.0

`gradle build` включает `radioContractCheck`: совпадение четырёх стрелок, диапазоны, NBT, сброс старых кодов, три канала приёма и один передачи, выключение, геометрия захвата перекрывающихся стрелок, привязка делений и границы GUI.

GitHub Actions (`Magic Connect build`) собирает мод на Java 17 / Gradle 8.10.2 и публикует JAR как артефакт. В этой среде локальная загрузка Gradle недоступна; фактический результат сборки следует смотреть в Actions. Minecraft с клиентом и сервером здесь не запускался.
