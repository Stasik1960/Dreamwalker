# DW Magic Connect 0.4.2 — Fabric 1.20.1

Магическая рация передаёт только обычную IC-речь из RP Chat. Требуются Java 17, Fabric Loader 0.16.10+, Fabric API и RP Chat 0.1.15+. Установите одинаковую версию DW Magic Connect на сервере и клиентах.

## Управление

- `/MConnect` с предметом в руке превращает его в рацию (права администратора 2). `/MConnect remove` снимает свойства рации.
- ПКМ открывает инструмент. Два циферблата задают единственную частоту четырьмя положениями стрелок. Настройки сохраняются автоматически во время настройки, после отпускания стрелки и перед закрытием окна. Escape закрывает окно, не отменяя изменения.
- Нижний синий кристалл включает и выключает устройство. На ненастроенном устройстве первое включение устанавливает 12:00 — 12:00.
- Правый боковой рычажок переключает громкую связь; во включённом положении он утоплен и подсвечен.
- Две боковые клавиши слева меняют радиус слышимости и улавливания от 1 до 18 блоков. По умолчанию — 10.
- Перетаскивайте кончики любых стрелок сколько угодно раз подряд. Tab выбирает элемент; на часах пробел выбирает стрелку, клавиши направления поворачивают её. На кристалле и переключателях Enter/пробел активируют управление.
- Удалены вкладки каналов, сброс и кнопка сохранения. Старый выбранный разговорный канал переносится в единственную частоту, остальные удаляются из NBT. Состояние питания и данные предмета сохраняются. Старые кодовые частоты до версии часов несовместимы и сбрасываются.

## Передача речи

Обычный режим работает с включённым предметом в руке и передаёт речь владельца. Громкая связь дополнительно улавливает обычную речь вокруг предмета, включая владельца, и работает из инвентаря онлайн-игрока или из загруженной обычной/светящейся рамки. Радиус измеряется в трёх измерениях от местоположения игрока или рамки. Приём озвучивается в пределах настроенного радиуса вокруг принимающего предмета.

Сундуки и другие контейнеры в этой версии не поддерживаются. Выгруженные рамки не работают и не загружают чанки. Глобальная настройка радиуса из старого `config/dw_magic_connect.json` больше не применяется: радиус хранится в каждом предмете.

Для держателя принимающей рации сообщения помечаются временем частоты, например `[08:10 - 12:40]`; для окружающих — `[Мистический голос]`. Несколько принимающих устройств не дублируют одну радиопередачу одному игроку. Радиосообщения не ретранслируются повторно. Дайсы, действия, ГМ-чат, OOC, личные и системные сообщения не вызывают событие передачи речи.

## Оформление

Сохранён исходный фон `src/main/resources/assets/dw_magic_connect/textures/gui/arcane_dial.png`, созданный image_gen по пользовательскому референсу. Удалено прежнее приглушение цвета; циферблаты получили более насыщенные синие и золотые акценты. При включении кристаллы и отдельные звёзды плавно подсвечиваются. Свечение отрисовывается только в открытом интерфейсе, без мировых частиц и источников света.

## Сборка и проверка

Проект использует Gradle composite build с соседним `../RP-Chat`; эта зависимость не включается внутрь JAR. Сначала выполните `gradle build` в RP-Chat, затем `gradle check build` в DW_Magic_Connect, используя Java 17 / Gradle 8.10.2. Результат: `build/libs/dw-magic-connect-0.4.2.jar`.

Автоматические проверки покрывают состояние и миграцию NBT, диапазоны настройки, сетевой формат, геометрию часов и границы интерфейса. Minecraft не запускается по просьбе владельца; проверка интерфейса и сетевого поведения непосредственно в игре остаётся необходимой.

В версии 0.4.2 боковые кнопки встроены в золотые оправы под луной и солнцем; справа — руна резонанса. Подписи статуса и радиуса убраны (радиус доступен в подсказках). При включении все кристаллы получают голубую дымку, луна и солнце — ореолы; при выключении FX полностью отключены. Кнопки плавно утапливаются. Сохранённый радиус переносится без изменений, по умолчанию — 10, максимум — 18.


### Визуальная доработка 0.4.2

Полностью удалено затемнение фона и циферблатов по состоянию питания. FX отрисовываются отдельным верхним слоем с аддитивным смешиванием, без проверки глубины и отсечения граней; после FX состояние рендера восстанавливается. При выключении этот слой отсутствует, базовый UI остаётся прежней яркости.

Новый прозрачный атлас `textures/gui/arcane_controls.png` создан image_gen по пользовательскому референсу: две золотые стрелки с огранёнными синими вставками, общая оправа клавиш +/− и отдельная оправа руны громкой связи. Стрелки поворачиваются вокруг спрайтового шарнира; центры драгоценных вставок совпадают с прежними точками захвата. Изображения луны/солнца внутри часов убраны, как на референсе; внешние медальоны сохранены. Радиус 1–18, одиночный канал и автоматическое сохранение не изменены.

Сборка и проверки данных автоматизированы. Запуск Minecraft не выполняется по просьбе владельца. Браузерный просмотр локального HTML-превью заблокирован политикой инструмента; фактическое визуальное поведение FX требует проверки в игре.
